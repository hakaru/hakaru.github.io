TenSync

Ett tidtagningsspel på 10 sekunder med synkroniserad start på flera enheter.

Vad är TenSync?

TenSync är ett minimalistiskt tidtagningsspel. Tryck på START och tryck sedan på STOP exakt vid 10,00 sekunder. Ju närmare du kommer, desto högre blir din precision.

Det speciella: när andra iPhones som kör TenSync finns på samma Wi-Fi-nätverk hittar de varandra automatiskt och startar varje omgång i exakt samma ögonblick, synkroniserat inom ±2 ms. Varje enhet mäter sitt eget STOP självständigt. Tävla med vänner i samma rum utan installation, utan konton, utan servrar.

Så spelar du

  1. Tryck på START för att börja. Tidtagningen startar omedelbart.
  2. När du tror att 10 sekunder har gått, tryck på STOP. Båda knapparna reagerar vid nedtryckning (ingen släppfördröjning).
  3. Du ser din förflutna tid, avvikelsen från 10,00 s och en precisionsprocent.
  4. Om du inte stoppar inom 11 sekunder slutar omgången som FAILED.
  5. Tryck på RETRY för att spela igen.

Synkläge

Om andra iPhones som kör TenSync finns på samma Wi-Fi visar rubriken en Wi-Fi-ikon och ett antal anslutna enheter. När de är anslutna:

  • När du trycker på START på vilken enhet som helst sänds en synkroniserad start. Alla anslutna enheter börjar omgången cirka 0,5 sekunder senare, i exakt samma ögonblick.
  • Varje enhets STOP mäts självständigt. Resultaten delas inte mellan enheter.
  • iOS frågar om behörighet till "Lokalt nätverk" vid första start. Tillåt det för att synk ska fungera.

Tickljud

Ett valfritt tick spelas varje sekund medan tidtagningen pågår, med ett betonat slag vid t=0, för att hjälpa dig att hålla rytmen. Slå på eller av det i Inställningar. Den fysiska ljud av-knappen tystar det alltid.

Bästa resultat

Den minsta absoluta avvikelsen över alla dina försök visas i rubriken som BEST x.xx. Misslyckade omgångar och oavgjorda uppdaterar inte Bästa. Bästa resultat sparas lokalt på din enhet.

Integritet

TenSync använder Firebase (Analytics + Crashlytics) för anonymiserad användnings- och kraschdiagnostik. Inga annonser, inga annonsidentifierare, ingen spårning. Se integritetspolicyn för detaljer. Vi samlar inte in personlig information, lagrar inte data på våra servrar och kräver inget konto.
