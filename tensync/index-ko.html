TenSync

여러 기기가 동시에 시작하는 10초 타이밍 게임.

TenSync란?

TenSync는 미니멀한 타이밍 게임입니다. START를 탭한 뒤, 정확히 10.00초에 STOP을 탭하세요. 가까울수록 정확도가 높아집니다.

반전이 있습니다. 같은 Wi-Fi 네트워크에 TenSync를 실행 중인 다른 iPhone이 있으면, 서로 자동으로 발견하고 ±2 ms 이내로 동기화되어 매 라운드를 정확히 같은 순간에 시작합니다. 각 기기는 자신의 STOP을 독립적으로 측정합니다. 설정도, 계정도, 서버도 없이 같은 방의 친구와 실력 대결을 즐기세요.

플레이 방법

  1. START를 탭해 시작합니다. 타이머가 즉시 작동합니다.
  2. 10초가 지났다고 생각될 때 STOP을 탭하세요. 두 버튼 모두 터치 다운 시점에 반응합니다(릴리즈 지연 없음).
  3. 경과 시간, 10.00초로부터의 편차, 정확도 비율이 표시됩니다.
  4. 11초 안에 멈추지 않으면 라운드는 FAILED로 종료됩니다.
  5. RETRY를 탭해 다시 플레이하세요.

싱크 모드

같은 Wi-Fi에서 TenSync를 실행 중인 다른 iPhone이 있으면, 헤더에 Wi-Fi 아이콘과 피어 수가 표시됩니다. 연결되면:

  • 어떤 기기에서든 START를 탭하면 동기화된 시작 신호가 브로드캐스트됩니다. 연결된 모든 기기가 약 0.5초 후, 정확히 같은 순간에 라운드를 시작합니다.
  • 각 기기의 STOP은 독립적으로 측정됩니다. 결과는 기기 간에 공유되지 않습니다.
  • iOS는 첫 실행 시 "로컬 네트워크" 권한을 요청합니다. 동기화가 작동하려면 허용해 주세요.

틱 사운드

실행 중 1초마다 옵션 틱 사운드가 울리고, t=0에 다운비트가 들리어 리듬 유지에 도움을 줍니다. 설정에서 켜고 끌 수 있습니다. 하드웨어 무음 스위치는 항상 이 소리를 음소거합니다.

최고 기록

모든 시도 중 절댓값 편차가 가장 작은 값이 헤더에 BEST x.xx로 표시됩니다. 실패한 라운드와 동률은 BEST를 갱신하지 않습니다. BEST는 기기에 로컬로 저장됩니다.

개인정보 보호

TenSync는 익명화된 사용 통계와 충돌 진단을 위해 Firebase(Analytics + Crashlytics)를 사용합니다. 광고 없음, 광고 식별자 없음, 추적 없음. 자세한 내용은 개인정보 처리방침을 참고하세요. 개인정보를 수집하지 않으며, 자체 서버에 데이터를 저장하지 않고, 계정도 필요하지 않습니다.
