版本、系統需求與說明範圍

MyEQ 是位於選單列的等化器，可處理 Mac 播放的音訊。它會跟隨系統預設輸出，因此可用於音樂、影片、瀏覽器和遊戲，不必在各個 App 中分別設定 EQ。

  • 需要 macOS 14.2 或以上版本。請從 Mac App Store 安裝 MyEQ。
  • 本手冊說明已公開發行的 0.3.0 (build 225)。自訂 EQ 編輯和使用者預設儲存功能於 0.2.0 加入；曲線拖曳功能於 0.3.0 加入。如果看不到這些控制項，請更新 App。
  • 本手冊提供 11 種語言。App 介面本身僅提供英文和日文；為方便您找到對應按鈕，本手冊保留英文按鈕名稱。

MyEQ 是處理系統輸出的 App，並非 AU/VST 外掛或錄音工具。本手冊以 App Store 版本為準，不包含之後在本機開發過程中所做的變更。

首次啟動與音訊權限

  1. 連接耳機或揚聲器，並在 macOS 的 System Settings → Sound → Output 中選取裝置。以舒適的音量播放您熟悉的音訊。
  2. 從「應用程式」開啟 MyEQ。按一下選單列中的波形圖示；MyEQ 通常不會顯示 Dock 圖示。
  3. 允許 macOS 提出的系統音訊錄製要求。MyEQ 需要存取正在播放的音訊才能進行處理，但不會儲存錄音。
  4. 如果面板顯示 Waiting for permission，請按一下 Open System Settings。在 Privacy & Security → Screen & System Audio Recording 中允許 MyEQ。分類名稱可能因 macOS 版本而異。返回 MyEQ，按一下 Retry；如果 macOS 要求重新開啟 MyEQ，請依照指示操作。
  5. 開啟 Enable audio processing，確認狀態為執行中，並核對 Current output。按一下 Choose Preset，選擇合適的預設。

您不需要另外安裝虛擬音訊驅動程式，也不需要登入帳號。如果找不到圖示，請查看螢幕右側的選單列區域。

Running 表示音訊路徑已啟用。Bypassed 表示處理功能已關閉。如果顯示 Stopped、Waiting for permission 或 Safe bypass，請查看面板中的說明；僅憑開關已開啟，無法確認 EQ 正在生效。

每次啟動時，音訊處理預設開啟，Maximizer 預設關閉。這兩個開關的狀態不會保留到下次啟動，但已儲存的預設和裝置指派會保留。

為各個輸出選擇預設

  1. 指派預設之前，先確認 Current output。
  2. 開啟 Choose Preset。在 Search presets 中輸入型號或已儲存的預設名稱；清除搜尋文字即可查看可用清單。
  3. 按一下搜尋結果，該預設會立即指派給這個輸出裝置；Close 只會關閉選擇視窗。
  4. 日後重新連接同一個輸出時，MyEQ 會恢復其指派。其他輸出會保留各自的指派。

Clear Assignment 會清除目前裝置的指派，而不會刪除預設本身。清除後，MyEQ 會恢復自動選擇。手動指派的預設優先於自動推薦。

沒有指派時，支援的 Mac16,12 內建揚聲器會使用 Clear；其他內建揚聲器會使用暫用的揚聲器預設。耳機、Bluetooth、外接音訊介面及未知輸出則會使用 Neutral 作為後備。請自行選擇符合耳機型號的校正；MyEQ 不會自動辨識確切的耳機型號。裝置指派只儲存在這台 Mac 上。

開始編輯與試聽變更

選擇 Edit EQ，即可從目前選取的預設開始編輯；選擇 New Preset，則從沒有任何頻段的平坦 EQ 開始。專用編輯器的視窗大小可以調整。再次開啟時，會將同一個視窗帶到最前方，並保留尚未儲存的草稿。

  1. 在 Preset name 輸入容易辨識的名稱。
  2. 按一下 Add Band。新增頻段的初始設定為 Peak、1000 Hz、0 dB、Q 1。包含停用的頻段在內，最多可以有 16 個頻段。
  3. 調整曲線或數值欄位。當處理功能已啟用、音訊權限已允許、音訊路徑正在執行，而且目前輸出可用時，您會立即聽到變更。
  4. 若要保留結果，請儲存。按下 Cancel 或關閉編輯器，會結束未儲存的試聽，並恢復選取的預設。

切換輸出裝置，或停止／重新啟動音訊路徑，都會結束試聽。草稿仍會保留，但編輯器會提示試聽已停止，並停用指派給目前輸出的功能。請先在不新增指派的情況下儲存，再於目標輸出選取該預設，重新開啟編輯器以繼續試聽。

判讀與編輯 EQ 曲線

  • 每個編號控制點代表一個頻段。左右拖曳可調整頻率，上下拖曳可調整增益。Q 和濾波器類型則在下方控制項中變更。
  • 選取控制點後，畫面會移到該頻段的數值列。若控制點重疊，請按一下目標列中的 Band N。
  • 停用的頻段以空心控制點表示。拖曳該點會修改數值，但不會啟用頻段。
  • 粗線是所有已啟用 EQ 頻段的合成響應；細虛線則是目前選取頻段的響應。

這是計算得出的 EQ 響應，不是即時頻譜分析器。它不包含自動前級增益、Maximizer、多頻段動態處理或低音強化。曲線較高，並不能直接告訴您最終的播放響度。

計算使用輸出的取樣率。Reference: 48 kHz 表示無法取得實際取樣率。輸出無法重現的頻率會以陰影標示；頻段也可能顯示其有效頻率受限的訊息。編輯器允許輸入的頻率範圍，與目前輸出實際可用的範圍並不相同。

圖表的垂直顯示範圍為 −24 至 +24 dB，但多個頻段合成後可能超出此範圍。響應到達圖表邊緣，不代表總響應或輸出被限制在 ±24 dB。

頻段類型、數值與停用方式

可編輯的 EQ 設定
設定範圍或選項意義
Frequency20–20000 HzPeak 的中心頻率，或擱架濾波器的轉折區域。較低數值影響低音，較高數值影響高音。
Gain−24 至 +24 dB正值提升，負值衰減。可使用欄位、曲線或增益滑桿調整；滑桿以 0.1 dB 為步進單位。
Q0.1–30控制寬度或共振程度。對 Peak 而言，Q 越高，影響的區域越窄。高 Q 的擱架濾波器可能在轉折附近產生共振。
Filter typePeak / Low Shelf / High ShelfPeak 調整某個頻率周圍的區域。Low Shelf 調整轉折以下的頻率；High Shelf 則調整轉折以上的頻率。
Enabled開啟 / 關閉只略過這個頻段，並保留其數值。停用的頻段仍計入 16 個頻段的上限。
Remove Band垃圾桶按鈕從草稿中移除該頻段。如果想回到已儲存的預設，請取消整次編輯。

無效或超出範圍的數值文字會反白標示，並阻止儲存。請在每個標示的欄位中輸入有效數值。建議從小幅調整開始；窄範圍的衰減通常比大幅提升更容易判斷。

輸入小數時請使用小數點，例如 -3.5 dB 或 Q 0.7。0.3.0 的這些欄位不接受以逗號作為小數分隔符號。

儲存、複製與指派自訂預設

  • 預設名稱去除前後空白後，長度必須為 1–80 個字元。
  • 編輯內建預設或從頭建立時，Save 會建立新的使用者預設，不會覆寫內建預設。
  • 編輯自己已儲存的預設時，Save 會更新該預設。Save a Copy 則會另建一份預設，並保留原本的預設。
  • Assign to current output 會將儲存結果套用到這個裝置。若未勾選，新建立的預設只會儲存到資料庫中，不會建立該輸出的指派。

既有指派仍會參照被覆寫的預設。如果您更新已指派給某個裝置的使用者預設，即使沒有勾選「Assign to current output」，該裝置仍會使用更新後的設定。若要保留原本的聲音，請使用 Save a Copy。

結束並重新啟動 MyEQ 後，已儲存的預設和輸出指派仍會保留。未儲存的草稿必須在儲存成功後，才會成為資料庫中的預設。請在 Choose Preset 中搜尋儲存時使用的名稱。

0.3.0 版本沒有預設匯入／匯出、雲端同步或刪除已儲存預設的介面。清除指派並不等於刪除。

EQ、自動前級增益與 Maximizer

EQ 會改變頻率平衡。當設定包含提升時，自動前級增益會降低電平。Maximizer 是獨立的響度處理與限幅階段，由主面板中的開關控制，不會改變頻段數值。

0.3.0 版本沒有獨立的多頻段動態處理或低音強化控制項，內建預設也不會啟用這些處理階段。自訂編輯器會修改 EQ 頻段；主面板的 Maximizer 開關仍具有優先權。New Preset 從 Neutral 開始。

在 0.3.0 中，大幅提升仍可能造成失真。自動前級增益未能完整計入重疊的提升或高 Q 擱架濾波器的共振。如果聲音刺耳或發生削波，請降低提升量或 Q；不要將自動前級增益視為防止所有過載的保證。

為了有效比較，請保持相同音源與輸出，並切換 Enable audio processing。以接近的感知音量聆聽，避免一味認為「比較大聲」就是比較好。若要完全停止 MyEQ，請選擇 Quit。

音訊權限、本機儲存與隱私

MyEQ 使用 macOS 的系統音訊權限來即時處理聲音。它不會儲存錄音、建立音訊檔案、收集分析資料，或透過網路傳送音訊與其他資料。這段說明適用於 App；支援網站有其自身的網站行為。

您的自訂預設與輸出指派會在本機儲存於 App 的 Application Support 區域。App Store 版本會將資料存放在其容器內。音訊處理權限並不代表允許上傳您的聲音。

您可以在 macOS 的 System Settings 中撤銷系統音訊存取權。之後 MyEQ 將無法再處理系統音訊。Licenses 按鈕會顯示內建第三方資料的授權與出處，其中包括以 AutoEq 為基礎的預設。詳細資訊請參閱隱私權（英文）。

沒有聲音，或顯示 Safe bypass閱讀顯示的原因。在 macOS 中確認輸出與音量。結束 MyEQ，檢查一般播放是否正常，再重新開啟並確認權限。

聲音刺耳或失真減少大幅提升、頻段重疊或過高的 Q。請參閱處理章節中關於 0.3.0 自動前級增益的限制。
