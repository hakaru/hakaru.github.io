버전, 시스템 요구 사항 및 설명 범위

MyEQ는 Mac에서 재생하는 오디오에 적용되는 메뉴 막대 이퀄라이저입니다. 시스템의 기본 출력을 따라가므로 각 앱에서 EQ를 따로 설정하지 않아도 음악, 동영상, 브라우저, 게임에 사용할 수 있습니다.

  • macOS 14.2 이상이 필요합니다. Mac App Store에서 MyEQ를 설치하세요.
  • 이 설명서는 공개된 0.3.0 (build 225) 버전을 다룹니다. 사용자 EQ 편집과 사용자 프리셋 저장은 0.2.0에, 곡선 드래그는 0.3.0에 추가되었습니다. 해당 컨트롤이 보이지 않으면 앱을 업데이트하세요.
  • 설명서는 11개 언어로 제공됩니다. 앱 인터페이스는 영어와 일본어로만 제공되며, 실제 버튼을 쉽게 찾을 수 있도록 이 설명서에서는 영어 버튼 이름을 그대로 사용합니다.

MyEQ는 시스템 출력에 적용되는 앱이며, AU/VST 플러그인이나 오디오 녹음기가 아닙니다. 이 설명서는 App Store 빌드를 기준으로 하며, 이후 로컬 개발 과정에서 이루어진 변경 사항은 포함하지 않습니다.

처음 실행하기 및 오디오 권한 허용

  1. 헤드폰이나 스피커를 연결하고 macOS의 System Settings → Sound → Output에서 선택하세요. 익숙한 오디오를 편안한 음량으로 재생하세요.
  2. 응용 프로그램에서 MyEQ를 여세요. 메뉴 막대의 파형 아이콘을 클릭하세요. MyEQ는 일반적으로 Dock 아이콘을 표시하지 않습니다.
  3. macOS가 시스템 오디오 녹음 권한을 요청하면 허용하세요. MyEQ는 재생 중인 오디오를 처리하기 위해 접근 권한이 필요하며, 녹음 파일을 저장하지는 않습니다.
  4. 패널에 Waiting for permission이 표시되면 Open System Settings를 클릭하세요. Privacy & Security → Screen & System Audio Recording에서 MyEQ를 허용하세요. macOS 버전에 따라 항목 이름이 다를 수 있습니다. MyEQ로 돌아와 Retry를 클릭하세요. macOS가 다시 열도록 요청하면 MyEQ를 다시 여세요.
  5. Enable audio processing을 켜고 실행 상태인지 확인한 다음 Current output을 확인하세요. Choose Preset을 클릭하고 적합한 프리셋을 선택하세요.

별도의 가상 오디오 드라이버나 로그인 계정은 필요하지 않습니다. 아이콘을 찾을 수 없다면 화면 오른쪽의 메뉴 막대를 확인하세요.

Running은 오디오 경로가 활성 상태라는 뜻입니다. Bypassed는 처리가 꺼져 있다는 뜻입니다. Stopped, Waiting for permission 또는 Safe bypass가 표시되면 패널의 설명을 확인해야 합니다. 스위치가 켜져 있다는 것만으로 EQ가 적용되고 있다고 판단할 수는 없습니다.

앱을 실행할 때마다 오디오 처리는 켜진 상태로, Maximizer는 꺼진 상태로 시작합니다. 이 두 스위치의 상태는 다음 실행 때 유지되지 않지만, 저장한 프리셋과 기기별 지정은 유지됩니다.

출력별 프리셋 선택

  1. 프리셋을 지정하기 전에 Current output을 확인하세요.
  2. Choose Preset을 여세요. Search presets에 모델명이나 저장한 프리셋 이름을 입력하세요. 검색어를 지우면 사용 가능한 목록이 표시됩니다.
  3. 검색 결과를 클릭하세요. 해당 출력 기기에 즉시 지정됩니다. Close는 선택 창만 닫습니다.
  4. 나중에 같은 출력을 다시 연결하면 MyEQ가 지정된 프리셋을 복원합니다. 다른 출력은 각자 지정된 프리셋을 유지합니다.

Clear Assignment는 현재 기기에 대한 지정만 해제하며, 프리셋 자체를 삭제하지 않습니다. 해제 후 MyEQ는 자동 선택으로 돌아갑니다. 수동으로 지정한 프리셋은 자동 추천보다 우선합니다.

지정된 프리셋이 없으면 지원 대상인 Mac16,12의 내장 스피커에는 Clear가 사용되고, 다른 내장 스피커에는 임시 스피커 프리셋이 사용됩니다. 헤드폰, Bluetooth, 외장 인터페이스 및 알 수 없는 출력에는 Neutral이 사용됩니다. 헤드폰에 맞는 보정은 직접 선택하세요. MyEQ는 정확한 헤드폰 모델을 자동으로 식별하지 않습니다. 기기별 지정은 이 Mac에만 저장됩니다.

지원 대상인 M4 MacBook Air의 내장 스피커에서 지정을 해제하면 Clear로 돌아갑니다. 스피커 프로파일은 다른 Mac이나 출력에서도 검색 결과에 나타나며 수동으로 지정할 수 있습니다. 프로파일의 조정과 자동 추천은 Mac16,12의 내장 스피커를 대상으로 합니다. 수동으로 선택할 수 있다고 해서 다른 모든 스피커를 보정한다는 뜻은 아닙니다. 다른 장비에는 자신만의 EQ를 만들 수 있습니다.

Neutral은 자동으로 사용되는 대체값이며, 프리셋 검색 목록의 항목이 아닙니다. 선택 가능한 플랫 프리셋을 만들려면 New Preset을 사용하고 밴드가 없는 상태로 저장하세요.

편집 시작 및 변경 사항 미리 듣기

선택된 프리셋을 바탕으로 시작하려면 Edit EQ를, 밴드가 없는 플랫 EQ로 시작하려면 New Preset을 선택하세요. 전용 편집기 창은 크기를 조절할 수 있습니다. 다시 열면 동일한 창이 앞으로 나타나며 저장하지 않은 초안도 유지됩니다.

  1. Preset name에 알아보기 쉬운 이름을 입력하세요.
  2. Add Band를 클릭하세요. 새 밴드의 초기값은 Peak, 1000 Hz, 0 dB, Q 1입니다. 비활성화된 밴드를 포함하여 최대 16개 밴드를 사용할 수 있습니다.
  3. 곡선이나 숫자 필드를 조절하세요. 처리가 켜져 있고, 오디오 권한이 허용되어 있으며, 오디오 경로가 실행 중이고 현재 출력을 사용할 수 있으면 변경 사항이 즉시 들립니다.
  4. 결과를 유지하려면 저장하세요. Cancel을 누르거나 편집기를 닫으면 저장하지 않은 미리 듣기가 끝나고 선택된 프리셋으로 돌아갑니다.

출력 기기를 바꾸거나 오디오 경로를 중지/재시작하면 미리 듣기가 끝납니다. 초안은 유지되지만, 편집기에 미리 듣기가 중지되었다고 표시되고 현재 출력에 지정하는 기능이 비활성화됩니다. 새로 지정하지 않고 저장한 다음 원하는 출력에서 해당 프리셋을 선택하고 편집기를 다시 열어 미리 듣기를 재개하세요.

EQ 곡선 읽기 및 편집

  • 번호가 붙은 각 점은 하나의 밴드를 나타냅니다. 좌우로 드래그하면 주파수가, 위아래로 드래그하면 게인이 바뀝니다. Q와 필터 유형은 아래 컨트롤에서 변경합니다.
  • 점을 선택하면 해당 밴드의 숫자 행이 보이도록 이동합니다. 점이 겹치면 원하는 행의 Band N을 클릭하세요.
  • 비활성화된 밴드는 테두리만 있는 점으로 표시됩니다. 이 점을 드래그하면 값은 바뀌지만 밴드가 활성화되지는 않습니다.
  • 굵은 선은 활성화된 EQ 밴드들의 합산 응답이고, 가는 점선은 선택된 밴드의 응답입니다.

이 그래프는 계산된 EQ 응답이며, 실시간 스펙트럼 분석기가 아닙니다. 자동 프리앰프, Maximizer, 멀티밴드 다이내믹스 또는 베이스 강화는 포함하지 않습니다. 곡선이 높다고 해서 최종 재생 음량을 바로 알 수 있는 것은 아닙니다.

계산에는 출력 샘플 레이트가 사용됩니다. Reference: 48 kHz는 실제 샘플 레이트를 알 수 없다는 뜻입니다. 출력에서 재현할 수 없는 주파수는 음영으로 표시되며, 밴드에 실효 주파수가 제한된다는 메시지가 나타날 수 있습니다. 편집기에서 입력할 수 있는 주파수 범위와 현재 출력에서 사용할 수 있는 범위는 서로 다릅니다.

그래프의 세로 표시 범위는 −24~+24 dB이지만, 여러 밴드가 합쳐지면 이 표시 범위를 넘어설 수 있습니다. 응답이 그래프 가장자리에 닿는다고 해서 전체 응답이나 출력이 ±24 dB로 제한된다는 뜻은 아닙니다.

밴드 유형, 값 및 비활성화

편집 가능한 EQ 설정
설정범위 또는 선택지의미
Frequency20–20000 HzPeak의 중심 주파수 또는 셸프 필터의 전환 영역입니다. 낮은 값은 저음에, 높은 값은 고음에 영향을 줍니다.
Gain−24~+24 dB양수는 증폭, 음수는 감쇠를 뜻합니다. 필드, 곡선 또는 게인 슬라이더로 조절하세요. 슬라이더는 0.1 dB 단위로 움직입니다.
Q0.1–30폭이나 공진을 조절합니다. Peak에서는 Q가 높을수록 더 좁은 영역에 영향을 줍니다. Q가 높은 셸프 필터는 전환 영역 부근에서 공진할 수 있습니다.
Filter typePeak / Low Shelf / High ShelfPeak는 특정 주파수 주변의 영역을 조절합니다. Low Shelf는 전환 주파수 아래를, High Shelf는 그 위를 조절합니다.
Enabled켜기 / 끄기값을 유지하면서 이 밴드만 우회합니다. 비활성화된 밴드도 16개 밴드 제한에 포함됩니다.
Remove Band휴지통 버튼초안에서 밴드를 제거합니다. 저장된 프리셋으로 돌아가려면 편집 전체를 취소하세요.

잘못되었거나 범위를 벗어난 숫자 입력은 강조 표시되며, 이 상태에서는 저장할 수 없습니다. 표시된 각 필드에 유효한 값을 입력하세요. 작은 변화부터 시작하세요. 큰 폭의 증폭보다 좁은 영역의 감쇠가 판단하기 쉬운 경우가 많습니다.

소수 입력에는 마침표를 사용하세요. 예를 들어 -3.5 dB 또는 Q 0.7과 같이 입력합니다. 0.3.0에서는 이 필드에 쉼표를 소수 구분 기호로 사용할 수 없습니다.

사용자 프리셋 저장, 복사 및 지정

  • 프리셋 이름은 앞뒤 공백을 제거한 뒤 1–80자여야 합니다.
  • 기본 제공 프리셋을 편집하거나 새로 시작한 경우, Save는 새 사용자 프리셋을 만듭니다. 기본 제공 프리셋은 덮어쓰지 않습니다.
  • 저장해 둔 사용자 프리셋을 편집하는 경우, Save는 해당 프리셋을 업데이트합니다. Save a Copy는 원본을 유지하면서 별도의 프리셋을 만듭니다.
  • Assign to current output은 저장 결과를 현재 기기에 적용합니다. 선택하지 않으면 새로 만든 프리셋은 현재 출력에 지정되지 않은 채 라이브러리에 저장됩니다.

기존 지정은 덮어쓴 프리셋을 계속 참조합니다. 이미 기기에 지정된 사용자 프리셋을 업데이트하면, “Assign to current output”을 선택하지 않아도 해당 기기에 업데이트된 설정이 반영됩니다. 원래 소리를 유지하려면 Save a Copy를 사용하세요.

저장한 프리셋과 출력별 지정은 MyEQ를 종료하고 다시 실행해도 유지됩니다. 저장하지 않은 초안은 저장에 성공하기 전까지 라이브러리 프리셋이 되지 않습니다. Choose Preset에서 저장한 이름을 검색하세요.

0.3.0 버전에는 프리셋 가져오기/내보내기, 클라우드 동기화 또는 저장된 프리셋을 삭제하는 인터페이스가 없습니다. 지정 해제는 삭제가 아닙니다.

EQ, 자동 프리앰프 및 Maximizer

EQ는 주파수 균형을 바꿉니다. 자동 프리앰프는 증폭이 있을 때 레벨을 낮춥니다. Maximizer는 메인 패널의 스위치로 제어하는 별도의 음량 보정 및 리미팅 단계이며, 밴드 값을 바꾸지 않습니다.

0.3.0 버전에는 별도의 멀티밴드 다이내믹스나 베이스 강화 컨트롤이 없으며, 기본 제공 프리셋도 이 처리 단계를 활성화하지 않습니다. 사용자 편집기는 EQ 밴드를 변경하며, 메인 Maximizer 스위치의 설정이 계속 우선합니다. New Preset은 Neutral에서 시작합니다.

0.3.0에서는 큰 폭으로 증폭하면 여전히 왜곡이 발생할 수 있습니다. 자동 프리앰프는 서로 겹치는 증폭이나 Q가 높은 셸프 필터의 공진을 완전히 반영하지 못합니다. 소리가 거칠거나 클리핑이 발생하면 증폭량이나 Q를 낮추세요. 자동 프리앰프가 모든 과부하를 방지한다고 생각해서는 안 됩니다.

제대로 비교하려면 같은 음원과 출력을 유지하면서 Enable audio processing을 켜고 끄세요. “더 큰 소리”를 무조건 더 좋게 판단하지 않도록 체감 음량을 비슷하게 맞춰 들어보세요. MyEQ를 완전히 종료하려면 Quit을 선택하세요.

오디오 권한, 로컬 저장 및 개인정보 보호

MyEQ는 macOS의 시스템 오디오 권한을 사용해 소리를 실시간으로 처리합니다. 녹음을 저장하거나, 오디오 파일을 만들거나, 분석 데이터를 수집하거나, 오디오 또는 기타 데이터를 네트워크로 전송하지 않습니다. 이는 앱에 대한 설명이며, 지원 웹사이트의 동작은 별개입니다.

사용자 프리셋과 출력별 지정은 앱의 Application Support 영역에 로컬로 저장됩니다. App Store 버전에서는 앱 컨테이너 안에 저장됩니다. 오디오 처리 권한은 소리를 업로드할 수 있는 권한이 아닙니다.

macOS의 System Settings에서 시스템 오디오 접근 권한을 취소할 수 있습니다. 그러면 MyEQ는 더 이상 시스템 오디오를 처리할 수 없습니다. Licenses 버튼은 AutoEq 기반 프리셋을 포함하여 기본 제공되는 타사 자료의 저작자 표시를 보여줍니다. 자세한 내용은 개인정보 처리방침 (영어)을 참조하세요.
