Version, requirements and scope

MyEQ is a menu-bar equalizer for the audio your Mac plays. It follows the system’s default output, so you can use it with music, videos, browsers and games without setting an EQ in each app.

  • Requires macOS 14.2 or later. Install MyEQ from the Mac App Store.
  • This manual covers the published 0.3.0 (build 225). Custom EQ editing and saved user presets were added in 0.2.0; curve dragging was added in 0.3.0. Update if these controls are missing.
  • The manual is available in 11 languages. The app interface itself is available in English and Japanese; English button names are kept here so you can locate them.

MyEQ is a system-output app, not an AU/VST plug-in or an audio recorder. This manual describes the App Store build; later local development changes are not included.

First launch and audio permission

  1. Connect your headphones or speakers and choose them in macOS System Settings → Sound → Output. Start some familiar audio at a comfortable volume.
  2. Open MyEQ from Applications. Click the waveform icon in the menu bar; MyEQ does not normally show a Dock icon.
  3. Allow the macOS request to record system audio. MyEQ needs access to the playing audio to process it; it does not save a recording.
  4. If the panel shows Waiting for permission, click Open System Settings. Under Privacy & Security → Screen & System Audio Recording, allow MyEQ. The category name can vary with macOS. Return to MyEQ and click Retry; reopen MyEQ if macOS asks you to.
  5. Turn on Enable audio processing, check that the status is running, and confirm Current output. Click Choose Preset and select a suitable preset.

You do not need a separate virtual audio driver or a login account. If you cannot find the icon, check the menu-bar area on the right of the screen.

The menu-bar panel

Main controls

MaximizerEnables the loudness/limiting stage. Its on/off state is controlled here even while editing a preset.

Current presetShows the selected preset and why it was chosen: an assignment, a recommendation for this Mac, or a default for the output type.

Running means the audio path is active. Bypassed means processing is switched off. Stopped, Waiting for permission or Safe bypass require checking the explanation shown in the panel; an enabled switch alone does not establish that EQ is being applied.

On each launch, audio processing starts enabled and Maximizer starts off. These two switch positions are not saved between launches; your saved presets and device assignments are retained.

Choose a preset for each output

  1. Check Current output before making an assignment.
  2. Open Choose Preset. Enter a model name or your saved preset name in Search presets; clear the search to see the available list.
  3. Click a result. It is assigned immediately to this output device; Close only closes the picker.
  4. Reconnect the same output later and MyEQ restores its assignment. Other outputs keep their own assignments.

Clear Assignment removes the current device’s assignment, not the preset itself. MyEQ then returns to its automatic choice. A manually assigned preset takes precedence over an automatic recommendation.

Without an assignment, the supported Mac16,12 built-in speakers use Clear; other built-in speakers use a temporary speaker preset. Headphones, Bluetooth, external interfaces and unknown outputs fall back to Neutral. Choose the matching headphone correction yourself; MyEQ does not automatically identify the exact headphone model. Device assignments are local to this Mac.

Bundled presets and device matching

Preset groups
GroupUse
Apple headphone correctionsAutoEq-derived presets for AirPods Pro (2nd generation), AirPods Max (USB-C), AirPods 4 (ANC) and EarPods. Match the model and variant; these are not a searchable catalogue of every headphone.
M4 MacBook Air speaker voicingsClear, Bass Boost, Vocal and Night are tuned for the built-in speakers of Mac model Mac16,12. They are not universal corrections for every MacBook Air or external speaker.
Automatic defaults / NeutralWhen there is no explicit assignment, MyEQ chooses a model or output-type default, or falls back to Neutral. Neutral has no EQ bands; turn Maximizer off as well when you want to compare with an unshaped signal.

On the supported M4 MacBook Air’s built-in speakers, clearing an assignment returns to Clear. The speaker profiles can also appear in searches and be assigned manually on other Macs or outputs. Their tuning and automatic recommendation target the Mac16,12 built-in speakers; manual availability does not mean they correct every other speaker. You can create your own EQ for other equipment.

Neutral is an automatic fallback, not an item in the preset search list. To make a selectable flat preset, use New Preset and save it with no bands.

Start editing and preview changes

Choose Edit EQ to start from the selected preset, or New Preset for a flat EQ with no bands. The dedicated editor can be resized. Opening it again brings the same window forward and keeps the unsaved draft.

  1. Enter a descriptive Preset name.
  2. Click Add Band. A new band starts as Peak, 1000 Hz, 0 dB, Q 1. You can have up to 16 bands, including disabled bands.
  3. Adjust the curve or the numeric fields. Changes are heard immediately when processing is enabled, audio permission is allowed, the audio path is running, and the current output is available.
  4. Save when you want to keep the result. Cancel or closing the editor ends the unsaved preview and restores the selected preset.

Changing the output device or stopping/restarting the audio path ends the preview. Your draft remains available, but the editor reports that preview has stopped and disables assigning it to the current output. Save it without a new assignment, select it on the intended output, and reopen the editor to resume previewing.

Read and edit the EQ curve

  • Each numbered point represents a band. Drag left/right for frequency and up/down for gain. Q and filter type are changed in the controls below.
  • Selecting a point brings its numeric row into view. If points overlap, click Band N in the desired row.
  • A disabled band has an outlined point. Dragging that point edits its values but does not enable it.
  • The thick line is the combined response of enabled EQ bands; the thin dashed line is the selected band’s response.

This is a calculated EQ response, not a live spectrum analyzer. It does not include automatic preamp, Maximizer, multiband dynamics or bass enhancement. A taller curve does not directly tell you the final playback loudness.

The calculation uses the output sample rate. Reference: 48 kHz means the actual rate is unavailable. Frequencies the output cannot reproduce are shaded; a band may show a message that its effective frequency is limited. The editor’s allowed frequency range and the current output’s usable range are different.

The graph shows −24 to +24 dB vertically, but several bands can combine to exceed that display range. A response reaching the edge is not evidence that the total response or output is limited to ±24 dB.

Band types, values and disabling

Editable EQ settings
SettingRange or choicesMeaning
Frequency20–20000 HzThe center frequency for Peak, or the transition region for a shelf. Low values affect bass; high values affect treble.
Gain−24 to +24 dBPositive values boost and negative values cut. Use the field, curve or gain slider; the slider moves in 0.1 dB steps.
Q0.1–30Controls the width or resonance. For Peak, higher Q affects a narrower region. High-Q shelves can resonate around their transition.
Filter typePeak / Low Shelf / High ShelfPeak shapes a region around a frequency. Low Shelf shapes frequencies below its transition; High Shelf shapes those above.
EnabledOn / OffBypasses just this band while keeping its values. Disabled bands still count toward the 16-band limit.
Remove BandTrash buttonRemoves the band from the draft. Cancel the entire edit if you want to return to the saved preset.

Invalid or out-of-range numeric text is highlighted and prevents saving. Enter a valid value in each marked field. Begin with small changes; a narrow cut is often easier to judge than a large boost.

Use a period for decimal input, for example -3.5 dB or Q 0.7. A comma decimal separator is not accepted by these fields in 0.3.0.

Save, copy and assign custom presets

  • A preset name must contain 1–80 characters after trimming leading and trailing spaces.
  • Save creates a new user preset when editing a bundled preset or starting fresh. Bundled presets are not overwritten.
  • When editing your own saved preset, Save updates it. Save a Copy creates a separate preset and keeps the original.
  • Assign to current output applies the saved result to this device. If unchecked, a newly created preset is saved to the library without creating that assignment.

Existing assignments still refer to an overwritten preset. If you update a user preset already assigned to a device, that device receives the updated settings even if “Assign to current output” is unchecked. Use Save a Copy to preserve the original sound.

Saved presets and output assignments survive quitting and restarting MyEQ. An unsaved draft does not become a library preset until saving succeeds. Search for the saved name in Choose Preset.

Version 0.3.0 has no preset import/export, cloud sync or saved-preset deletion interface. Clearing an assignment is not deletion.

EQ, automatic preamp and Maximizer

The EQ changes frequency balance. Automatic preamp reduces level when boosts are present. Maximizer is a separate loudness/limiting stage controlled by the switch in the main panel; it does not change the band values.

Version 0.3.0 has no separate multiband dynamics or bass-enhancement controls, and the bundled presets do not activate those stages. The custom editor changes the EQ bands; the main Maximizer switch continues to take precedence. New Preset starts from Neutral.

Large boosts can still distort in 0.3.0. Its automatic preamp does not fully account for overlapping boosts or high-Q shelf resonances. Reduce boosts or Q if the result sounds harsh or clipped; do not treat automatic preamp as a guarantee against every overload.

For a useful comparison, keep the same source and output and toggle Enable audio processing. Listen at similar perceived levels so that “louder” does not automatically win. To stop MyEQ completely, choose Quit.

Audio permission, local storage and privacy

MyEQ uses macOS system-audio permission to process sound in real time. It does not store recordings, create audio files, collect analytics, or send audio or other data over the network. This describes the app; the support website has its own website behavior.

Your custom presets and output assignments are saved locally in the app’s Application Support area, inside its container for the App Store version. An audio-processing permission is not permission to upload your sound.

You can revoke system-audio access in macOS System Settings. MyEQ will no longer be able to process the system audio. The Licenses button shows credits for bundled third-party material, including AutoEq-derived presets. See the privacy policy for details.

Troubleshooting and support

Common symptoms
SymptomCheck or action
No menu-bar iconOpen MyEQ from Applications and look for the waveform at the right of the menu bar. A missing Dock icon is normal.
Permission is still requestedCheck MyEQ in Screen & System Audio Recording, return to the panel and click Retry. Follow any macOS request to reopen the app.
The sound does not changeCheck the running status, Enable audio processing, Current output and selected preset. Neutral with Maximizer off is intentionally flat. Make sure your playback uses the system default output.
No sound, or Safe bypassRead the displayed reason. Verify the output and volume in macOS. Quit MyEQ to check whether ordinary playback works, then reopen it and recheck permission.
Edits are no longer audibleThe output or audio path may have changed. Preserve the draft by saving, choose it on the desired output and reopen the editor. Check the preview-status message.
Save is disabled or failsUse a 1–80-character name and valid band values. Read the error message. A storage error means the draft has not necessarily been saved; keep the window open while checking it.
A preset is missingClear the search text. The bundled catalogue contains four headphone corrections and four M4 MacBook Air voicings, not every model. For a missing custom preset, check whether saving succeeded and whether a storage error is shown.
Harshness or distortionReduce large boosts, overlapping bands or high Q. See the 0.3.0 automatic-preamp limitation in the processing chapter.

For support, include the MyEQ version, macOS version, output device, preset name, panel status or error, and steps to reproduce the problem. A screenshot of the panel or editor is helpful. Contact hakaruapps-contact@hakaru.net.
