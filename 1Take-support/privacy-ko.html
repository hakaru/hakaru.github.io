1Take

iOS 전문 오디오 레코더

개인정보 처리방침

최종 업데이트: 2026년 1월 24일

소개

1Take("당사", "우리" 또는 "앱")는 귀하의 개인정보 보호에 최선을 다합니다. 본 개인정보 처리방침은 귀하가 iOS 애플리케이션을 사용할 때 정보를 처리하는 방법을 설명합니다.

요약

1Take는 앱의 안정성 향상과 사용자 경험 개선을 위해 익명 진단 데이터를 수집합니다. 귀하의 모든 오디오 녹음은 귀하의 기기에만 로컬로 저장되며 어떠한 서버에도 업로드되지 않습니다.

오디오 녹음

1Take로 생성한 모든 오디오 녹음은:

  • 귀하의 기기에만 로컬로 저장됩니다
  • 어떠한 서버에도 업로드되지 않습니다
  • 귀하만 접근할 수 있습니다
  • 파일 앱 또는 공유 시트를 통해 내보낼 수 있습니다

수집하는 데이터

1Take는 Google이 제공하는 서비스인 Firebase를 사용하여 익명 진단 데이터를 수집합니다. 이를 통해 앱의 안정성을 개선하고 앱 사용 방식을 이해할 수 있습니다.

충돌 데이터 (Firebase Crashlytics)

앱이 충돌하면 자동으로 다음을 수집합니다:

  • 기기 유형 및 iOS 버전
  • 앱 버전 및 빌드 번호
  • 충돌 로그 및 스택 추적
  • 충돌 시 메모리 및 디스크 사용량

사용 통계 (Firebase Analytics)

다음을 포함한 익명 사용 데이터를 수집합니다:

  • 앱 실행 횟수 및 세션 시간
  • 기능 사용 패턴
  • 기기 유형 및 iOS 버전
  • 익명 기기 식별자 (귀하의 신원과 연결되지 않음)

데이터 수집 요약

데이터 유형 목적 귀하와 연결
충돌 데이터 앱 기능 아니오
성능 데이터 앱 기능 아니오
사용 데이터 분석 아니오
기기 ID 분석 아니오

수집하지 않는 데이터

  • 귀하의 오디오 녹음 또는 생성한 콘텐츠
  • 개인 정보 (이름, 이메일 등)
  • 위치 데이터
  • 연락처 또는 캘린더 데이터
  • 광고 목적의 데이터

추적 및 광고

당사는 광고 목적으로 귀하를 추적하지 않습니다. 1Take는:

  • 광고 식별자(IDFA)를 사용하지 않습니다
  • 광고주와 데이터를 공유하지 않습니다
  • 다른 앱이나 웹사이트에서 귀하를 추적하지 않습니다
  • 앱 추적 투명성 권한이 필요하지 않습니다

마이크 접근

1Take는 오디오를 녹음하기 위해 마이크 접근이 필요합니다. 이 권한은:

  • 오디오 녹음 기능에만 사용됩니다
  • 귀하가 녹음을 명시적으로 시작할 때만 활성화됩니다
  • 언제든지 iOS 설정에서 제어할 수 있습니다

제3자 서비스

1Take는 다음 제3자 서비스를 사용합니다:

  • Firebase Crashlytics - 충돌 보고 및 진단
  • Firebase Analytics - 익명 사용 통계

이러한 서비스는 Google이 제공합니다. 자세한 내용은 Firebase 개인정보 처리방침을 참조하십시오.

데이터 보존

충돌 및 분석 데이터는 Firebase의 표준 보존 정책에 따라 보존됩니다. 이 데이터는 익명이며 귀하를 식별하는 데 사용할 수 없습니다.

데이터 삭제

앱의 녹음 탭에서 언제든지 녹음을 삭제할 수 있습니다. 앱을 제거하면 기기에서 모든 로컬 데이터가 삭제됩니다.

아동 개인정보 보호

1Take는 13세 미만 아동의 개인 정보를 의도적으로 수집하지 않습니다. 당사가 수집하는 익명 진단 데이터는 개별 사용자와 연결되지 않습니다.

본 방침의 변경

당사는 수시로 본 개인정보 처리방침을 업데이트할 수 있습니다. 이 페이지에 새로운 개인정보 처리방침을 게시하고 "최종 업데이트" 날짜를 변경함으로써 변경 사항을 알려드립니다.
