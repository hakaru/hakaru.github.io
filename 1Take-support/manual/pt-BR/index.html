Primeiros passos

Primeiro acesso

Ao abrir o 1Take pela primeira vez, será solicitado acesso ao microfone. Isso é necessário para que o app grave áudio.

Visão geral da tela principal

A tela principal consiste em:

  • Medidor de nível: Exibe níveis de áudio em tempo real (toque para alternar entre VU/GR/Espectro/LUFS)
  • Botão de gravação: Iniciar/parar gravação (centro)
  • Knob TRIM: Ajustar ganho de entrada (esquerda)
  • Knob THRESH: Ajustar limiar do gate (direita)
  • Seletor de preset: Escolher perfil de som (topo)

Noções básicas de gravação

Iniciar uma gravação

  1. Toque no botão Gravar para iniciar
  2. O botão fica vermelho e um timer aparece
  3. Toque novamente para parar e salvar

Análise de gravação

O 1Take v1.3.0 introduz análise automática de qualidade de gravação usando algoritmos padrão de broadcast (ITU-R BS.1770-4).

Otimização automática com IA

Após cada gravação, o 1Take analisa automaticamente o áudio e ajusta as configurações do preset. Tudo é executado no dispositivo — sem necessidade de conexão à internet.

Gratuito vs Pro

Todos os usuários podem ver os resultados da análise. Aplicar ajustes automaticamente requer Pro.

Sincronização na nuvem

O 1Take pode fazer upload automático das gravações para armazenamento na nuvem. A sincronização é gratuita para todos os usuários.

Marcação de localização GPS

O 1Take captura sua localização ao iniciar a gravação, para você lembrar onde cada take foi feita.

Presets

O 1Take inclui três presets elaborados com inspiração em equipamentos de áudio lendários:

Studio (estilo LA-2A)

  • Ideal para: Voz, violão, podcasts
  • Caráter: Compressão quente e suave
  • Expansão estéreo: OFF

Studio+ (estilo 1176)

  • Ideal para: Bateria, guitarra elétrica, performances energéticas
  • Caráter: Compressão potente e agressiva com ataque rápido
  • Expansão estéreo: OFF

Live (estilo VCA)

  • Ideal para: Apresentações ao vivo, ensaios com alto volume
  • Caráter: Compressão limpa e transparente
  • Expansão estéreo: ON

Cadeia de processamento de sinal

Entrada → Trim → Gate → EQ → Comp A → Comp B → Saturação → Estéreo → Maximizer → Saída

Gravação pré-roll

Nunca perca uma boa take! O pré-roll armazena continuamente o áudio em buffer para capturar momentos que ocorreram antes de pressionar gravar.

Gravação automática

A gravação automática inicia e para a gravação com base nos níveis de áudio.

Medidores

Toque no display do medidor para alternar entre quatro modos: VU, GR, Espectro e LUFS.

Marcadores

Marcadores do usuário

Adicionados manualmente tocando no botão Marcador durante a gravação.

Marcadores de clipping (CLIP)

Adicionados automaticamente quando o áudio clipa (excede 0 dBFS).

Marcadores Over (OVER)

Adicionados automaticamente quando True Peak excede -1 dBTP.

Biblioteca de gravações

Acesse suas gravações tocando no ícone de lista.

Configurações

Desempenho

Tamanho do buffer: Controla o equilíbrio entre latência e estabilidade. Recomendado: 4096.

Formato de arquivo

  • WAV (16 bits): Qualidade padrão, arquivos menores
  • WAV (24 bits): Qualidade superior (Pro)
  • BWF (16/24 bits): Broadcast Wave com timecode (Pro)

Recursos Pro

Atualize para Pro para desbloquear:

  • Aplicação automática de IA — Aplicar ajustes de otimização automaticamente
  • Pré-roll ampliado — Buffer de até 30 segundos
  • Presets personalizados — Acesso completo a todos os parâmetros
  • Formato BWF — Broadcast Wave com timecode incorporado
  • Gravação 24 bits — Maior profundidade de bits
  • Gravação direta MP3/AAC — Gravar diretamente em formatos comprimidos
