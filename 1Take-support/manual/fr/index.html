Démarrage

Premiers pas

Lors du premier lancement de 1Take, vous serez invité à accorder l'accès au microphone. Cela est nécessaire pour que l'application puisse enregistrer de l'audio.

Présentation de l'écran principal

L'écran principal comprend :

  • Vumètre : Affiche les niveaux audio en temps réel (appuyez pour basculer entre VU/GR/Spectre/LUFS)
  • Bouton d'enregistrement : Démarrer/arrêter l'enregistrement (centre)
  • Bouton TRIM : Ajuster le gain d'entrée (gauche)
  • Bouton THRESH : Ajuster le seuil de gate (droite)
  • Sélecteur de préréglages : Choisir votre profil sonore (haut)

Bases de l'enregistrement

Démarrer un enregistrement

  1. Appuyez sur le bouton Enregistrer pour démarrer
  2. Le bouton devient rouge et un minuteur s'affiche
  3. Appuyez à nouveau pour arrêter et sauvegarder

Ajouter des marqueurs

Pendant l'enregistrement, appuyez sur le bouton Marqueur pour ajouter un marqueur à la position actuelle. Cela vous aide à retrouver les moments importants.

Alerte d'arrêt d'enregistrement

Lorsque vous arrêtez l'enregistrement, une alerte indique :

  • Durée : Durée totale de l'enregistrement
  • Intégrité : Pourcentage de données audio capturées avec succès (visez 100%)

Analyse d'enregistrement

1Take v1.3.0 introduit l'analyse automatique de qualité d'enregistrement utilisant des algorithmes de diffusion standard (ITU-R BS.1770-4).

Ce qui est analysé

Après chaque enregistrement, 1Take évalue automatiquement :

  • Niveau de crête (dBFS) : Valeur d'échantillon maximale (-6 à -12 dBFS est idéal)
  • Niveau RMS (dBFS) : Niveau sonore moyen dans le temps
  • Facteur de crête (dB) : Plage dynamique (crête moins RMS)
  • LUFS : Sonie perçue (cible -14 à -16 LUFS pour le streaming)
  • True Peak (dBTP) : Niveau de crête inter-échantillons (garder en dessous de -1 dBTP)
  • Plage de sonie (LRA) : Variation statistique de la sonie

Valeurs de référence

MétriquePlage idéaleNotes
Crête-12 à -6 dBFSLaisser de la réserve
LUFS-16 à -14 LUFSStandard streaming
True PeakEn dessous de -1 dBTPÉvite l'écrêtage
Facteur de crête8-14 dBDynamique équilibrée

Optimisation automatique par IA

Après chaque enregistrement, 1Take analyse automatiquement votre audio et ajuste les paramètres de votre préréglage pour améliorer la prochaine prise. Tout s'exécute sur l'appareil — aucune connexion Internet requise.

Fonctionnement

  1. Arrêtez un enregistrement (doit durer au moins 5 secondes)
  2. 1Take analyse la sonie, les crêtes, le plancher de bruit, la dynamique et l'équilibre des fréquences
  3. Si des problèmes sont détectés, l'application ajuste les paramètres de votre préréglage actuel
  4. Une bannière indique le nombre de paramètres optimisés

Appuyez sur la bannière pour voir chaque ajustement avec les valeurs avant/après et la raison (ex. : « Écrêtage détecté — Trim d'entrée : −6 dB → −9 dB »).

Ce qui est ajusté

Problème détectéAjustement
Écrêtage (True Peak > −1 dBTP)Trim d'entrée réduit
Trop silencieux (LUFS < −24)Trim d'entrée et gain préliminaire du limiteur augmentés
Plancher de bruit élevéGate activé avec seuil approprié
Plage dynamique largeTaux de compression augmenté
Accumulation de basses fréquencesFiltre coupe-bas activé
Manque de brillanceGain de l'étagère haute augmenté
Chutes de bufferTaille du buffer augmentée

Un garde de dérive empêche tout paramètre de changer de plus de ±12 dB par rapport à sa valeur par défaut, et une règle anti-oscillation empêche le même paramètre d'être ajusté dans des directions opposées lors d'enregistrements consécutifs.

Gratuit vs Pro

Tous les utilisateurs peuvent voir les résultats d'analyse et les ajustements qui seraient effectués. L'application automatique des ajustements nécessite Pro. Les utilisateurs gratuits voient une invite de mise à niveau en appuyant sur la bannière d'optimisation.

Les utilisateurs Pro peuvent également appuyer sur Annuler tout dans la feuille de détails pour annuler tous les changements d'une session.

Pour désactiver entièrement l'optimisation IA, désactivez Optimisation auto dans les Paramètres.

Synchronisation cloud

1Take peut télécharger automatiquement les enregistrements vers le stockage cloud après chaque prise. La synchronisation cloud est gratuite pour tous les utilisateurs.

Fournisseurs pris en charge

FournisseurAuthentificationNotes
iCloud DriveApple ID systèmeAucune connexion requise. Les enregistrements apparaissent dans le Finder sur Mac.
Google DriveOAuth (Safari)Stocké dans un dossier 1Take dédié.
DropboxOAuth avec PKCEStocké dans Apps/1Take.
Backblaze B2Clé APISaisir l'ID de clé, la clé, le nom du bucket et un préfixe de chemin optionnel.

Vous pouvez activer plusieurs fournisseurs simultanément. Les enregistrements sont téléchargés vers tous les fournisseurs activés en parallèle.

Configuration

  1. Ouvrez Paramètres → Sync cloud
  2. Appuyez sur le fournisseur à configurer
  3. Authentifiez-vous (iCloud Drive ne nécessite pas de connexion)
  4. Activez le fournisseur

Paramètres de synchronisation

  • Sync automatique : Activé, les enregistrements se téléchargent automatiquement après chaque prise
  • Wi-Fi uniquement : Activé (par défaut), les téléchargements se font uniquement en Wi-Fi

État de synchronisation

Chaque enregistrement dans la bibliothèque affiche une icône d'état de sync :

  • Nuage avec flèche : Téléchargement en attente
  • Spinner : Téléchargement en cours
  • Coche verte : Synchronisé avec tous les fournisseurs
  • Point d'exclamation rouge : Échec du téléchargement (appuyez pour réessayer)

Si vous êtes hors ligne quand un enregistrement se termine, 1Take réessaie automatiquement lors du rétablissement de la connexion.

Géolocalisation GPS

1Take capture votre emplacement au début de l'enregistrement, pour vous souvenir où chaque prise a été réalisée.

Fonctionnement

  • Au démarrage de l'enregistrement, 1Take demande un fix GPS unique (précision 100m)
  • L'emplacement est sauvegardé avec l'enregistrement
  • Un nom de lieu géocodé inversement (ex. : « Montmartre, Paris ») apparaît dans la liste et le détail des enregistrements

La géolocalisation nécessite l'autorisation « Lors de l'utilisation ». Si l'autorisation est refusée ou si un fix GPS est indisponible, l'enregistrement continue normalement sans données de localisation.

Préréglages

1Take inclut trois préréglages soigneusement élaborés, inspirés d'équipements audio légendaires :

Studio (style LA-2A)

  • Idéal pour : Voix, guitare acoustique, podcasts
  • Caractère : Compression chaude et douce avec des qualités tube
  • Élargissement stéréo : OFF

Studio+ (style 1176)

  • Idéal pour : Batterie, guitare électrique, performances énergiques
  • Caractère : Compression percutante et agressive avec attaque rapide
  • Élargissement stéréo : OFF

Live (style VCA)

  • Idéal pour : Performances live, répétitions à fort volume
  • Caractère : Compression propre et transparente sans distorsion
  • Élargissement stéréo : ON (largeur améliorée)

Personnaliser les préréglages (Pro)

Les utilisateurs Pro peuvent personnaliser les paramètres de chaque préréglage, notamment Gate, EQ, Compresseurs, Saturation, Élargissement stéréo et Maximizer.

Chaîne de traitement du signal

1Take traite l'audio via une chaîne de signal professionnelle en temps réel :

Entrée → Trim → Gate → EQ → Comp A → Comp B → Saturation → Stéréo → Maximizer → Sortie

Trim d'entrée

Ajuste le gain numérique avant traitement. Utilisez le bouton TRIM sur l'écran principal.

Gate de bruit

Coupe le bruit de fond entre les phrases. Ajustez le seuil avec le bouton THRESH.

EQ paramétrique 5 bandes

Façonnez votre son avec cinq bandes entièrement réglables. Chaque bande offre :

  • Fréquence : Sélection de la fréquence centrale
  • Gain : Amplification ou atténuation (±12 dB)
  • Q : Contrôle de la largeur de bande (étroit à large)

Compresseur 2 étages

  • Comp A : Compresseur rapide pour capturer les crêtes
  • Comp B : Compresseur plus lent pour ajouter densité et « colle »

Saturation

Ajoute une chaleur harmonique subtile (distorsion style analogique).

Élargissement stéréo

Améliore la largeur stéréo pour une image sonore plus ample.

Maximizer

Limiteur de dernière étape qui empêche l'écrêtage numérique. Plafond fixé à -1,0 dBFS pour la sécurité.

Enregistrement pré-roll

Ne ratez plus jamais une bonne prise ! Le pré-roll met en mémoire tampon en continu l'audio pour capturer les moments qui se sont produits avant que vous n'appuyiez sur enregistrer.

Fonctionnement

  1. Activez le pré-roll dans les Paramètres
  2. Définissez la durée souhaitée (5-30 secondes, étendu avec Pro)
  3. Au démarrage de l'enregistrement, le tampon est inclus

Vous improvisiez et avez joué quelque chose d'incroyable. Même si vous appuyez sur enregistrer 10 secondes plus tard, le pré-roll capture ces 10 secondes !

Enregistrement automatique

L'enregistrement automatique démarre et arrête l'enregistrement en fonction des niveaux audio.

Calibration intelligente (nouveau dans v1.3.0)

  1. Appuyez sur le bouton Auto dans les paramètres d'enregistrement automatique
  2. 1Take mesure votre plancher de bruit ambiant
  3. Les seuils sont calculés automatiquement avec des marges optimales
  4. Un contrôle d'hystérésis empêche les faux déclenchements

Utilisation

  1. Maintenez enfoncé le bouton d'enregistrement pour entrer en mode enregistrement automatique
  2. Le badge « AUTO » apparaît
  3. L'enregistrement démarre automatiquement quand un son est détecté
  4. L'enregistrement s'arrête après la durée de silence spécifiée
  5. Appuyez sur le bouton d'enregistrement pour quitter le mode auto

Mètres

Appuyez sur l'affichage du mètre pour faire défiler quatre modes :

Vumètre VU

Mètre analogique classique avec constante de temps 300 ms. L'aiguille montre le niveau moyen, avec indicateur de maintien de crête.

  • Zone verte : Niveaux sûrs
  • Zone jaune : Niveaux élevés
  • Zone rouge : Proche de l'écrêtage

Mètre GR (réduction de gain)

Indique la quantité de compression appliquée.

  • Mètre gauche : Réduction de gain Comp A
  • Mètre droit : Réduction de gain Comp B

Analyseur de spectre

Affichage de fréquences en temps réel montrant le contenu spectral de votre audio.

Mètre LUFS

Mètre de sonie professionnel suivant la norme ITU-R BS.1770-4.

  • Aiguille : Sonie momentanée (400 ms)
  • Marqueur cyan : Sonie à court terme (3 s)
  • Marqueur jaune : Sonie intégrée (enregistrement entier)
  • TP (True Peak) : Niveau de crête inter-échantillons

Niveaux de référence : -24 LUFS (Diffusion), -14 LUFS (Streaming : Spotify, YouTube, Apple Music)

Marqueurs

Marqueurs utilisateur

Ajoutés manuellement en appuyant sur le bouton Marqueur pendant l'enregistrement.

Marqueurs d'écrêtage (CLIP)

Ajoutés automatiquement quand l'audio écrête (dépasse 0 dBFS).

Marqueurs Over (OVER)

Ajoutés automatiquement quand le True Peak dépasse -1 dBTP.

Marqueurs de chute de buffer

Ajoutés automatiquement si des données audio sont perdues en raison de problèmes de performances système.

Bibliothèque d'enregistrements

Accédez à vos enregistrements en appuyant sur l'icône de liste.

Informations d'enregistrement

Chaque enregistrement affiche : Titre, Durée, Date/Heure, Préréglage FX utilisé, Pourcentage d'intégrité audio, Nombre de marqueurs, Emplacement GPS et État de synchronisation cloud.

Supprimer des enregistrements

Les enregistrements supprimés sont déplacés vers Supprimés récemment dans l'app Fichiers iOS et peuvent être récupérés pendant 30 jours. Notez que la restauration d'un fichier dans Fichiers récupère le fichier audio mais ne le rajoute pas à la liste 1Take.

Export

Formats d'export

FormatDescription
OriginalConserver le fichier dans son format enregistré (WAV, BWF, MP3 ou AAC)
MP3Convertir en MP3 (128/192/256/320 kbps)
AACConvertir en AAC (.m4a) (128/192/256/320 kbps)

La conversion d'export est gratuite pour tous les utilisateurs. Les utilisateurs Pro peuvent également enregistrer directement au format MP3 ou AAC.

Export par lot

Sélectionnez plusieurs enregistrements dans la bibliothèque, puis appuyez sur Exporter. Tous les enregistrements sélectionnés sont convertis avec un format et un débit communs. La progression est affichée en temps réel et la conversion continue en arrière-plan si vous quittez l'application.

Formats d'export Pro

  • BWF (16/24 bits) : Broadcast Wave Format avec timecode intégré pour l'intégration DAW
  • WAV 24 bits : Profondeur de bits plus élevée pour la post-production professionnelle

Paramètres

Performance

Taille du buffer : Contrôle le compromis latence/stabilité du traitement audio. Recommandé : 4096 pour la plupart des utilisateurs.

Format de fichier

  • WAV (16 bits) : Qualité standard, fichiers plus petits
  • WAV (24 bits) : Qualité supérieure, fichiers plus grands (Pro)
  • BWF (16 bits) : Broadcast Wave avec timecode (Pro)
  • BWF (24 bits) : Format professionnel pour intégration DAW (Pro)

Sync cloud

Configurez les fournisseurs de stockage cloud, activez/désactivez la synchronisation automatique et le mode Wi-Fi uniquement. Voir la section Sync cloud pour les détails.

Optimisation auto

Activez ou désactivez l'optimisation automatique par IA. Quand activée, 1Take analyse chaque enregistrement et suggère (ou applique, pour les utilisateurs Pro) des ajustements de paramètres. Voir la section Optimisation automatique par IA pour les détails.

Garder l'écran allumé

Activez cette option pour empêcher votre appareil de se mettre en veille pendant les longues sessions d'enregistrement.

Fonctionnalités Pro

Passez à Pro pour débloquer :

  • Application automatique IA — Appliquer automatiquement les ajustements d'optimisation IA après chaque enregistrement
  • Pré-roll étendu — Augmenter le tampon pré-roll de 10 à 30 secondes
  • Préréglages personnalisés — Accès complet pour ajuster tous les paramètres de chaque préréglage
  • Format BWF — Broadcast Wave Format avec timecode intégré
  • Enregistrement 24 bits — Profondeur de bits plus élevée pour la post-production professionnelle
  • Enregistrement direct MP3/AAC — Enregistrer directement aux formats compressés

Conseils et astuces

Pour une meilleure qualité d'enregistrement

  1. Régler les niveaux correctement : Visez des crêtes autour de -12 à -6 dB sur le vumètre VU
  2. Utiliser le pré-roll : Gardez-le activé pour ne jamais rater les moments spontanés
  3. Choisir le bon préréglage : Faites correspondre votre source au caractère du préréglage
  4. Surveiller avec des écouteurs : Utilisez des écouteurs filaires pour entendre le son traité

Dépannage

Intégrité audio inférieure à 100% : Augmentez la taille du buffer dans les Paramètres, fermez d'autres applications.

Le son est distordu : Réduisez le Trim d'entrée.

L'enregistrement ne démarre pas : Vérifiez les autorisations du microphone dans les Réglages iOS.
