1Take

Professionell ljudinspelning för iOS

1Take Användarmanual

Kom igång

Första start

När du öppnar 1Take första gången ombeds du ge mikrofonåtkomst. Det krävs för att appen ska kunna spela in ljud.

Översikt huvudskärm

Huvudskärmen består av:

  • Nivåmätare: Visar ljudnivåer i realtid (tryck för att växla mellan VU/GR/Spektrum/LUFS)
  • Inspelningsknapp: Starta/stoppa inspelning (mitten)
  • TRIM-ratt: Justera ingångsförstärkning (vänster)
  • THRESH-ratt: Justera gate-tröskel (höger)
  • Förvalsselektor: Välj ljudprofil (uppe)

Inspelningsgrunder

Starta en inspelning

  1. Tryck på Spela in för att starta
  2. Knappen blir röd och en timer visas
  3. Tryck igen för att stoppa och spara

Inspelningsanalys

1Take v1.3.0 introducerar automatisk inspelningskvalitetsanalys med sändningsstandard-algoritmer (ITU-R BS.1770-4).

AI-autooptimering

Efter varje inspelning analyserar 1Take automatiskt ditt ljud och justerar förvalsinställningarna. Allt körs på enheten — ingen internetanslutning krävs.

Gratis vs Pro

Alla användare kan se analysresultaten. Att automatiskt tillämpa justeringar kräver Pro.

Molnsynkronisering

1Take kan automatiskt ladda upp inspelningar till molnlagring. Molnsynk är gratis för alla användare.

GPS-platstagning

1Take registrerar din plats när inspelningen startar, så du kan komma ihåg var varje take gjordes.

Förval

1Take innehåller tre noggrant utformade förval inspirerade av legendarisk audioutrustning:

Studio (LA-2A-stil)

  • Lämplig för: Sång, akustisk gitarr, podcasts
  • Karaktär: Varm, mjuk kompression
  • Stereoutbredning: AV

Studio+ (1176-stil)

  • Lämplig för: Trummor, elgitarr, energiska framträdanden
  • Karaktär: Kraftfull, aggressiv kompression med snabb attack
  • Stereoutbredning: AV

Live (VCA-stil)

  • Lämplig för: Liveframträdanden, högvolymrep
  • Karaktär: Ren, transparent kompression utan distorsion
  • Stereoutbredning: PÅ

Signalbearbetningskedja

Ingång → Trim → Gate → EQ → Comp A → Comp B → Mättnad → Stereo → Maximizer → Utgång

Pre-roll-inspelning

Missa aldrig ett bra take! Pre-roll buffrar kontinuerligt ljud för att fånga moment som hände innan du tryckte på inspelning.

Automatisk inspelning

Automatisk inspelning startar och stoppar inspelning baserat på ljudnivåer.

Mätare

Tryck på mätarskärmen för att växla mellan fyra lägen: VU, GR, Spektrum och LUFS.

Markeringar

Användarmarkeringar

Läggs till manuellt genom att trycka på Markering-knappen under inspelning.

Klipp-markeringar (CLIP)

Läggs till automatiskt när ljud klipper (överstiger 0 dBFS).

Over-markeringar (OVER)

Läggs till automatiskt när True Peak överstiger -1 dBTP.

Få åtkomst till dina inspelningar via listikonen.

Inställningar

Prestanda

Buffertstorlek: Styr avvägningen mellan latens och stabilitet. Rekommenderat: 4096.

Filformat

  • WAV (16-bit): Standardkvalitet, mindre filer
  • WAV (24-bit): Högre kvalitet (Pro)
  • BWF (16/24-bit): Broadcast Wave med tidskod (Pro)

Pro-funktioner

Uppgradera till Pro för att låsa upp:

  • AI auto-tillämpning — Tillämpa AI-optimeringar automatiskt efter varje inspelning
  • Utökad pre-roll — Buffert upp till 30 sekunder
  • Anpassade förval — Full åtkomst till alla parametrar
  • BWF-format — Broadcast Wave med inbäddad tidskod
  • 24-bitarsinspelning — Högre bitdjup
  • Direkt MP3/AAC-inspelning — Spela in direkt till komprimerade format
