1Take

iOS용 전문 오디오 녹음기

1Take 사용자 매뉴얼

시작하기

첫 실행

1Take를 처음 열면 마이크 접근 권한을 요청합니다. 앱이 오디오를 녹음하려면 필요합니다.

메인 화면 개요

메인 화면은 다음으로 구성됩니다:

  • 레벨 미터: 실시간 오디오 레벨 표시 (탭하여 VU/GR/스펙트럼/LUFS 전환)
  • 녹음 버튼: 녹음 시작/정지 (중앙)
  • TRIM 노브: 입력 게인 조정 (왼쪽)
  • THRESH 노브: 게이트 임계값 조정 (오른쪽)
  • 프리셋 선택기: 사운드 프로파일 선택 (상단)

녹음 기초

녹음 시작

  1. 녹음 버튼을 탭하여 시작
  2. 버튼이 빨간색으로 바뀌고 타이머가 표시됩니다
  3. 다시 탭하여 정지 및 저장

마커 추가

녹음 중에 마커 버튼을 탭하면 현재 위치에 마커가 추가됩니다.

녹음 분석

1Take v1.3.0은 방송 표준 알고리즘(ITU-R BS.1770-4)을 사용한 자동 녹음 품질 분석을 도입합니다.

분석 항목

  • 피크 레벨 (dBFS): 최대 샘플 값 (-6 ~ -12 dBFS가 이상적)
  • RMS 레벨 (dBFS): 시간 평균 음량
  • 크레스트 팩터 (dB): 다이나믹 레인지 (피크 빼기 RMS)
  • LUFS: 지각된 음량 (스트리밍 목표: -14 ~ -16 LUFS)
  • True Peak (dBTP): 샘플 간 피크 레벨 (-1 dBTP 미만 유지)
  • 라우드니스 레인지 (LRA): 통계적 음량 변동

AI 자동 최적화

각 녹음 후 1Take는 자동으로 오디오를 분석하고 프리셋 설정을 조정합니다. 모든 처리는 기기에서 실행되며 인터넷 연결이 필요하지 않습니다.

작동 방식

  1. 녹음 정지 (최소 5초 이상)
  2. 1Take가 음량, 피크, 노이즈 플로어, 다이나믹 레인지, 주파수 밸런스를 분석
  3. 문제가 감지되면 현재 프리셋 설정을 조정
  4. 최적화된 설정 수를 표시하는 배너가 나타남

무료 vs Pro

모든 사용자가 분석 결과를 볼 수 있습니다. 자동으로 조정을 적용하려면 Pro가 필요합니다.

클라우드 동기화

1Take는 매 녹음 후 자동으로 클라우드 스토리지에 업로드할 수 있습니다. 클라우드 동기화는 모든 사용자에게 무료입니다.

GPS 위치 태깅

1Take는 녹음 시작 시 위치를 캡처하여 각 녹음이 어디서 이루어졌는지 기억합니다.

프리셋

1Take는 전설적인 오디오 장비를 모델로 한 세 가지 프리셋을 제공합니다:

Studio (LA-2A 스타일)

  • 최적 용도: 보컬, 어쿠스틱 기타, 팟캐스트
  • 특성: 따뜻하고 부드러운 압축, 튜브 같은 질감
  • 스테레오 확산: OFF

Studio+ (1176 스타일)

  • 최적 용도: 드럼, 일렉 기타, 에너지 넘치는 퍼포먼스
  • 특성: 강펀치감 있고 공격적인 압축, 빠른 어택
  • 스테레오 확산: OFF

Live (VCA 스타일)

  • 최적 용도: 라이브 공연, 큰 소리 리허설
  • 특성: 깨끗하고 투명한 압축, 왜곡 없음
  • 스테레오 확산: ON (확장된 폭)

신호 처리 체인

1Take는 실시간으로 전문 신호 체인을 통해 오디오를 처리합니다:

입력 → Trim → Gate → EQ → Comp A → Comp B → 새츄레이션 → 스테레오 → Maximizer → 출력

프리롤 녹음

좋은 테이크를 절대 놓치지 마세요! 프리롤은 지속적으로 오디오를 버퍼링하여 녹음 버튼을 누르기 전에 발생한 순간도 캡처합니다.

자동 녹음

자동 녹음은 오디오 레벨에 따라 녹음을 자동으로 시작하고 정지합니다.

미터

미터 디스플레이를 탭하여 VU, GR, 스펙트럼, LUFS 네 가지 모드 중에서 순환합니다.

마커

사용자 마커

녹음 중 마커 버튼을 탭하여 수동으로 추가합니다.

클립 마커 (CLIP)

오디오가 클리핑(0 dBFS 초과)될 때 자동으로 추가됩니다.

오버 마커 (OVER)

True Peak이 -1 dBTP를 초과할 때 자동으로 추가됩니다.

녹음 라이브러리

목록 아이콘을 탭하여 녹음에 접근합니다.

내보내기

내보내기 형식

형식설명
원본녹음된 형식으로 파일 유지 (WAV, BWF, MP3, AAC)
MP3MP3로 변환 (128/192/256/320 kbps)
AACAAC(.m4a)로 변환 (128/192/256/320 kbps)

설정

성능

버퍼 크기: 오디오 처리 지연 vs 안정성 균형 제어. 권장값: 대부분 사용자에게 4096.

파일 형식

  • WAV (16비트): 표준 품질, 작은 파일
  • WAV (24비트): 높은 품질 (Pro)
  • BWF (16/24비트): 타임코드 포함 Broadcast Wave (Pro)

Pro 기능

Pro로 업그레이드하여 잠금 해제:

  • AI 자동 적용 — 매 녹음 후 AI 최적화 조정 자동 적용
  • 확장 프리롤 — 프리롤 버퍼를 10초에서 30초로 확장
  • 커스텀 프리셋 — 모든 파라미터 완전 접근
  • BWF 형식 — 타임코드 내장 Broadcast Wave Format
  • 24비트 녹음 — 더 높은 비트 심도
  • 직접 MP3/AAC 녹음 — 압축 형식으로 직접 녹음
