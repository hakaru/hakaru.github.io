開始使用

首次啟動

首次開啟 1Take 時，系統會請求麥克風使用權限。這是應用程式進行錄音所必需的。

主畫面概覽

主畫面包含：

  • 電平表：即時顯示音訊電平（點選切換 VU/GR/頻譜/LUFS）
  • 錄音按鈕：開始/停止錄音（中央）
  • TRIM 旋鈕：調整輸入增益（左側）
  • THRESH 旋鈕：調整閘門閾值（右側）
  • 預設選擇器：選擇音色設定（頂部）

錄音基礎

開始錄音

  1. 點選錄音按鈕開始
  2. 按鈕變為紅色，計時器顯示
  3. 再次點選以停止並儲存

添加標記點

錄音期間，點選標記按鈕在當前位置添加標記點。

錄音分析

1Take v1.3.0 引入使用廣播標準演算法（ITU-R BS.1770-4）的自動錄音品質分析。

分析內容

  • 峰值電平 (dBFS)：最大取樣值（-6 至 -12 dBFS 為理想）
  • RMS 電平 (dBFS)：時間平均音量
  • 峰值因數 (dB)：動態範圍（峰值減 RMS）
  • LUFS：感知響度（串流目標 -14 至 -16 LUFS）
  • True Peak (dBTP)：取樣間峰值電平（保持在 -1 dBTP 以下）
  • 響度範圍 (LRA)：統計響度變化

AI 自動最佳化

每次錄音後，1Take 自動分析您的音訊並調整預設設定。所有處理在裝置上完成 — 無需網路連線。

運作方式

  1. 停止錄音（必須至少 5 秒）
  2. 1Take 分析響度、峰值、噪音底層、動態範圍和頻率平衡
  3. 若偵測到問題，應用程式調整當前預設設定
  4. 橫幅顯示最佳化的設定數量

免費版 vs Pro

所有使用者可查看分析結果。自動套用調整需要 Pro。

雲端同步

1Take 可在每次錄音後自動上傳至雲端儲存。雲端同步對所有使用者免費。

支援的服務商

服務商認證方式備註
iCloud Drive系統 Apple ID無需登入。錄音在 Mac Finder 中顯示。
Google DriveOAuth (Safari)儲存在專用 1Take 資料夾。
DropboxPKCE OAuth儲存在 Apps/1Take。
Backblaze B2API 金鑰輸入金鑰 ID、金鑰、儲存桶名稱及選填路徑前綴。

GPS 位置標記

1Take 在開始錄音時擷取您的位置，讓您記住每次錄音的地點。

預設音效

1Take 提供三種以傳奇音訊設備為靈感精心設計的預設：

Studio（LA-2A 風格）

  • 適合：人聲、木吉他、Podcast
  • 特色：溫暖、柔順的壓縮，具管機質感
  • 立體聲擴展：關

Studio+（1176 風格）

  • 適合：鼓組、電吉他、充滿活力的演奏
  • 特色：有力、積極的壓縮，快速起音
  • 立體聲擴展：關

Live（VCA 風格）

  • 適合：現場演出、大音量排練
  • 特色：乾淨、透明的壓縮，不失真
  • 立體聲擴展：開（增強寬度）

訊號處理鏈

1Take 以即時方式透過專業訊號鏈處理音訊：

輸入 → Trim → Gate → EQ → Comp A → Comp B → 飽和 → 立體聲 → Maximizer → 輸出

預錄功能

再也不會錯過精彩的一拍！預錄持續緩衝音訊，讓您捕捉按下錄音前發生的精彩時刻。

自動錄音

自動錄音根據音訊電平自動開始和停止錄音。

電平表

點選電平表顯示，在四種模式間切換：VU、GR、頻譜和 LUFS。

標記點

使用者標記

錄音期間點選標記按鈕手動添加。

削波標記（CLIP）

音訊削波（超過 0 dBFS）時自動添加。

Over 標記（OVER）

True Peak 超過 -1 dBTP 時自動添加。

錄音資料庫

點選清單圖示存取您的錄音。

匯出

匯出格式

格式說明
原始格式保留錄音格式（WAV、BWF、MP3 或 AAC）
MP3轉換為 MP3（128/192/256/320 kbps）
AAC轉換為 AAC（.m4a）（128/192/256/320 kbps）

設定

效能

緩衝區大小：控制音訊處理延遲與穩定性的平衡。建議：大多數使用者選 4096。

檔案格式

  • WAV（16 位元）：標準品質，檔案較小
  • WAV（24 位元）：更高品質（Pro）
  • BWF（16/24 位元）：含時間碼的 Broadcast Wave（Pro）

Pro 功能

升級至 Pro 以解鎖：

  • AI 自動套用 — 每次錄音後自動套用 AI 最佳化調整
  • 延長預錄 — 緩衝區從 10 秒增至 30 秒
  • 自訂預設 — 完整存取所有參數
  • BWF 格式 — 含嵌入時間碼的 Broadcast Wave Format
  • 24 位元錄音 — 更高位元深度
  • 直接 MP3/AAC 錄音 — 直接以壓縮格式錄音
