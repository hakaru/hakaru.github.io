Cloud Sync: auto-back-up naar iCloud, Google Drive, Dropbox en Backblaze B2

29 maart 2026

1Take v1.4 introduceert Cloud Sync — automatische back-up van elke opname naar je gekozen cloudprovider. Dit artikel legt uit hoe je elke provider instelt.

iCloud Drive

iCloud Drive is de eenvoudigste optie — geen aanmelding vereist.

  1. Open 1Take → Instellingen → Cloud Sync
  2. Schakel iCloud Drive in
  3. Klaar — opnamen worden automatisch geüpload naar iCloud Drive/1Take/

Je hebt een actief iCloud-account en voldoende opslagruimte nodig. Bestanden zijn direct beschikbaar op alle Apple-apparaten met hetzelfde Apple-account.

Google Drive

  1. Open 1Take → Instellingen → Cloud Sync → Google Drive
  2. Tik op "Verbinden met Google Drive"
  3. Log in met je Google-account in de Safari-webweergave
  4. Verleen 1Take toestemming om bestanden te uploaden
  5. Optioneel: selecteer een specifieke map in je Drive

Opnamen worden geüpload naar de geselecteerde map (standaard: Mijn Drive/1Take/).

Dropbox

  1. Open 1Take → Instellingen → Cloud Sync → Dropbox
  2. Tik op "Verbinden met Dropbox"
  3. Autoriseer via het Dropbox OAuth-scherm

Opnamen worden geüpload naar /Apps/1Take/ in je Dropbox.

Backblaze B2

B2 vereist handmatige sleutelinvoer — het gebruik geen OAuth.

  1. Maak een bucket aan op backblaze.com (stel in op "Privé")
  2. Maak een Application Key aan met lees- en schrijftoegang
  3. Open 1Take → Instellingen → Cloud Sync → Backblaze B2
  4. Voer Key ID, Application Key en Bucket Name in
  5. Tik op "Verbinden en testen"

Meerdere providers tegelijk

Je kunt alle vier providers gelijktijdig inschakelen. Elke opname wordt naar alle geconfigureerde providers geüpload. Dit is handig als je iCloud wilt voor direct toegang en B2 als goedkoop archiefback-up.

Uploadstatus

In de opnamelijst zie je een wolkicoon naast elke opname die wacht op upload of die is gesynchroniseerd. Tik op het icoon voor de uploadstatus per provider.
