クラウド同期：iCloud・Google Drive・Dropbox・Backblaze B2への自動バックアップ

2026年3月29日
Support サポート Manual マニュアル Privacy プライバシー Blog ブログ Changelog 更新履歴

概要

1Take v1.4 ではクラウド同期機能が追加されました。録音を停止した瞬間に、ファイルを自動でクラウドストレージへアップロードするバックアップシステムです。この機能は無料ユーザーを含むすべてのユーザーが利用できます。PRO サブスクリプションは必要ありません。

対応クラウドサービスは iCloud Drive、Google Drive、Dropbox、Backblaze B2 の 4 種類です。1 つだけ有効にすることも、複数を同時に有効にすることも可能です。

対応プロバイダー

プロバイダー 説明
iCloud Drive Mac の Finder や Windows の iCloud for Windows からファイルに直接アクセス可能
Google Drive Google Drive 内の専用 1Take フォルダにアップロード
Dropbox Dropbox の Apps/1Take フォルダにアップロード
Backblaze B2 指定したバケットとパスにアップロード。大容量アーカイブに最適

iCloud Drive とデスクトップからのアクセス

iCloud Drive 同期を有効にすると、録音ファイルは iCloud Drive 内の 1Take フォルダに保存されます。同じ Apple アカウントでサインインしている Mac では、このフォルダが Finder の「iCloud Drive」に自動的に表示されます。Windows では、Microsoft Store から iCloud for Windows をインストールすることで同様にアクセスできます。

追加のソフトウェアは不要で、デスクトップから録音ファイルを直接開いたり、名前を変更したり、整理したりすることが可能です。

動作の仕組み

クラウド同期は設定後に手間なく動作します。プロバイダーを有効にして認証を完了すれば、あとは 1Take がすべてバックグラウンドで処理します。

  1. 録音を終了してストップボタンをタップする。
  2. 1Take が有効なすべてのプロバイダーへのアップロードをキューに追加する。
  3. アップロードが自動的に開始される（デフォルトは Wi-Fi のみ。設定でモバイル通信を許可することも可能）。
  4. 録音ライブラリの各ファイルにクラウドアイコンが表示され、アップロード状況を確認できる。
  5. アップロード完了後、各プロバイダーのアイコンがチェックマークに変わる。

オフラインなどの理由でアップロードが完了しなかった場合、接続が回復した際に自動でリトライします。

プロバイダーごとのリトライ設定

各クラウドプロバイダーには独自のリトライ設定があります。設定 → クラウド同期 から以下を変更できます。

  • 最大リトライ回数 — 失敗と判定するまでに何回アップロードを試みるか
  • リトライ間隔 — 再試行までの待機時間（1 分から 1 時間の範囲で設定可能）
  • モバイル通信でのアップロード — プロバイダーごとにモバイル通信でのアップロードを許可するか個別に設定可能

たとえば iCloud Drive はモバイル通信でのアップロードを許可しつつ、転送量が大きくなりやすい Backblaze B2 は Wi-Fi のみに制限する、といった使い分けができます。

アップロード履歴

各録音ファイルのアップロード履歴を確認できます。ライブラリでファイルをタップしてクラウドアイコンをタップすると、すべてのアップロード試行のログが表示されます。ログにはタイムスタンプ、プロバイダー名、結果（成功または失敗）、失敗時のエラーメッセージが含まれます。

特定のファイルが特定のプロバイダーに届いていない原因の調査や、リトライが保留中かどうかの確認に役立ちます。

クラウド同期の設定手順

ほとんどのプロバイダーは 1 分以内にセットアップが完了します。

  1. 1Take の設定を開く。
  2. クラウド同期をタップする。
  3. 有効にしたいプロバイダーをタップする。
  4. プロバイダーのトグルをオンにして、認証の案内に従う。
  5. iCloud Drive の場合は認証不要。既存の Apple アカウントがそのまま使われる。
  6. Google Drive と Dropbox の場合は、Safari で標準的な OAuth サインインフローが表示される。
  7. Backblaze B2 の場合は、Application Key ID、Application Key、バケット名、およびオプションのパスプレフィックスを入力する。

認証が完了するとすぐにプロバイダーが有効になります。まだアップロードされていない録音ファイルはバックグラウンドでアップロードが開始されます。

すべてのユーザーに無料で提供

クラウド同期は無料プランを含む 1Take のすべてのバージョンで利用できます。どのプロバイダーの有効化にも、機能のどの部分にも、PRO サブスクリプションは必要ありません。クラウドストレージの料金は各プロバイダーの料金体系に依存し、1Take が別途課金することはありません。
