Cloud Sync: Backup Automatico su iCloud, Google Drive, Dropbox e Backblaze B2

29 marzo 2026

Panoramica

v1.4 aggiunge Cloud Sync: quando fermi una registrazione, 1Take la carica automaticamente nel cloud. Nessun abbonamento aggiuntivo necessario — funziona per tutti.

Puoi usare iCloud Drive, Google Drive, Dropbox o Backblaze B2. Abilita tutti quelli che vuoi contemporaneamente.

Quale Provider Scegliere

ProviderNote
iCloud DriveMigliore se usi un Mac. Le registrazioni appaiono in Finder automaticamente — nessun software aggiuntivo.
Google DriveVa in una cartella 1Take dedicata. Buona scelta se Google Drive è già il tuo storage principale.
DropboxCarica in Apps/1Take nel tuo Dropbox. Facile condivisione con collaboratori.
Backblaze B2Specifichi il bucket e il percorso. L'opzione più economica se memorizzi molta audio a lungo termine.

Per la maggior parte delle persone, iCloud Drive è la scelta ovvia se si è nell'ecosistema Apple. Se stai già pagando per lo storage Google Drive, funziona altrettanto bene. Backblaze B2 è per chi sa di volerlo — richiede l'inserimento di chiavi API, ma lo storage costa una frazione degli altri.

iCloud Drive e Accesso dal Desktop

Con iCloud Drive abilitato, le registrazioni vanno nella cartella 1Take dentro iCloud Drive. Su un Mac connesso allo stesso Account Apple, quella cartella appare automaticamente in Finder. Su Windows, installa iCloud for Windows dal Microsoft Store e funziona allo stesso modo.

Puoi aprire, rinominare e organizzare le registrazioni direttamente dal tuo desktop.

Come Funziona

Una volta configurato un provider, non devi più pensarci.

  1. Ferma una registrazione.
  2. 1Take mette in coda il file per il caricamento su ogni provider abilitato.
  3. Il caricamento inizia automaticamente — Wi-Fi per impostazione predefinita, o dati mobili se lo hai permesso nelle Impostazioni.
  4. Una piccola icona cloud nella libreria mostra lo stato del caricamento per file.
  5. Quando un provider riceve il file, l'icona cambia in un segno di spunta.

Se sei offline quando fermi la registrazione, 1Take riprova quando torna la connessione.

Impostazioni di Nuovo Tentativo per Provider

In Impostazioni → Cloud Sync, ogni provider ha i propri controlli per i nuovi tentativi:

  • Numero massimo di tentativi prima di contrassegnare un file come fallito
  • Intervallo di nuovo tentativo (da 1 minuto a 1 ora)
  • Se i caricamenti su dati mobili sono consentiti per quel provider

Utile se vuoi che iCloud Drive carichi tramite dati mobili ma mantenga Backblaze B2 solo su Wi-Fi. I trasferimenti B2 tendono ad essere più grandi, quindi potresti non volerli consumare il tuo piano dati.

Cronologia Caricamenti

Tocca una registrazione nella libreria, poi tocca l'icona cloud. Vedrai un registro di ogni tentativo di caricamento: timestamp, provider, risultato e qualsiasi messaggio di errore. Se un file non ha raggiunto un provider specifico, qui scopri perché.

Configurazione

La maggior parte dei provider richiede meno di un minuto:

  1. Apri Impostazioni in 1Take.
  2. Tocca Cloud Sync.
  3. Tocca il provider che vuoi.
  4. Attivalo e segui il prompt di autenticazione.
  5. iCloud Drive — nessuna autenticazione necessaria, usa il tuo Account Apple esistente.
  6. Google Drive e Dropbox — accesso OAuth standard in Safari.
  7. Backblaze B2 — inserisci il tuo Application Key ID, Application Key, nome bucket e un prefisso di percorso opzionale.

Una volta autenticato, il provider è attivo immediatamente. Le registrazioni che non sono ancora state caricate inizieranno a essere caricate in background.

Costo

Cloud Sync è gratuito in 1Take. Nessun piano PRO richiesto. Quello che paghi dipende dal provider cloud che usi — 1Take non applica nessun costo aggiuntivo oltre a quello.
