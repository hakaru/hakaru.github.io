GPS Location Tagging: Remember Where Every Recording Was Made

March 29, 2026

Overview

1Take v1.4 introduces GPS location tagging. When you start a recording, 1Take automatically captures your current location and converts it into a human-readable place name — the name of a neighborhood, district, or city — which then appears alongside the recording in your library.

For musicians who rehearse at a studio, perform at different venues, or capture field recordings outdoors, this means every take is automatically tied to where it happened.

How It Works

Location capture happens automatically at the moment you tap the record button. There is nothing to configure and no manual step required.

  1. You tap the record button.
  2. 1Take requests your location at coarse accuracy — approximately 100 meters. This is intentionally imprecise; the goal is a place name, not a precise coordinate.
  3. iOS performs reverse geocoding to translate the coordinate into a readable name such as "Shibuya, Tokyo" or "Brooklyn, New York."
  4. That name is stored in the recording's markers.json file alongside other metadata.
  5. The place name appears in the recording list and in the recording detail view.

Coarse Accuracy and Privacy

1Take uses the coarse location mode provided by iOS, which limits precision to roughly 100 meters. This is accurate enough to identify a neighborhood or venue but not accurate enough to pinpoint a specific room or address. No precise GPS coordinates are stored.

This design means the feature is useful for context — "I recorded this at the Osaka venue last Thursday" — while keeping your exact whereabouts private.

Permission and Opt-Out

The first time you record after updating to v1.4, iOS will show a permission prompt asking whether 1Take may access your location. You can:

  • Allow once — location is captured for this recording only; you will be asked again next time.
  • Allow while using the app — location is captured for each recording without further prompts.
  • Don't allow — location tagging is disabled. Recording continues normally with no location information attached.

Declining location permission has no effect on any other feature. Recording quality, duration, AI optimization, and cloud sync all work exactly the same with or without location access.

You can change this permission at any time in Settings > Privacy & Security > Location Services > 1Take.

Where Location Data Is Stored

The place name is written to the markers.json file that lives alongside each recording. This is the same file that stores markers, notes, and other recording metadata. If you access your recordings through the Files app or via cloud sync, you can read the location data directly from that file.

The location appears in two places within 1Take:

  • Recording list — shown as a small label below the recording name, alongside the date and duration.
  • Recording detail view — shown in the metadata section together with file size, sample rate, and other details.
