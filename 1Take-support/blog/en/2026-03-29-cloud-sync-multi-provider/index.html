Cloud Sync: Auto-Backup to iCloud, Google Drive, Dropbox, and Backblaze B2

March 29, 2026

Overview

1Take v1.4 introduces Cloud Sync, a new automatic backup system that uploads your recordings to the cloud as soon as you finish recording. This feature is available to all users at no extra cost — it is not gated behind a PRO subscription.

Four cloud storage providers are supported: iCloud Drive, Google Drive, Dropbox, and Backblaze B2. You can enable one, several, or all of them simultaneously.

Supported Providers

Provider Notes
iCloud Drive Files appear in Finder on Mac and File Explorer on Windows via iCloud for Windows
Google Drive Uploads to a dedicated 1Take folder in your Google Drive
Dropbox Uploads to Apps/1Take in your Dropbox
Backblaze B2 Uploads to the bucket and path you specify; ideal for large archives

iCloud Drive and Desktop Access

When iCloud Drive sync is enabled, your recordings are stored in the 1Take folder inside iCloud Drive. On a Mac signed in to the same Apple Account, this folder appears automatically in Finder under iCloud Drive. On Windows, the same files are accessible after installing iCloud for Windows from the Microsoft Store.

This means you can open, rename, and organize your recordings directly from your desktop without any additional software.

How It Works

Cloud Sync is designed to be hands-off. Once you enable a provider and authenticate, 1Take handles everything in the background.

  1. You finish a recording and tap Stop.
  2. 1Take immediately queues the file for upload to each enabled provider.
  3. The upload begins automatically — over Wi-Fi by default, or over cellular if you have allowed it in Settings.
  4. A small cloud indicator in the Recordings Library shows the upload status for each file.
  5. Once uploaded, the status changes to a checkmark for each provider that has received the file.

If the upload cannot complete — for example because you are offline — 1Take retries automatically when a connection becomes available.

Per-Provider Retry Controls

Each cloud provider has its own retry settings. In Settings → Cloud Sync, you can configure:

  • Maximum retries — how many times 1Take will attempt to upload a file before marking it as failed
  • Retry interval — the delay between retry attempts (from 1 minute to 1 hour)
  • Cellular uploads — whether uploads are allowed over a cellular connection for each provider individually

This lets you, for example, allow iCloud Drive to upload over cellular while restricting Backblaze B2 to Wi-Fi only, since B2 uploads may involve larger transfer volumes.

Upload History

A full upload history is available for each recording. Tap any recording in the library, then tap the cloud icon to see a log of every upload attempt: the timestamp, the provider, the result (success or failure), and the error message if applicable.

This history makes it straightforward to diagnose why a particular file did not reach a specific provider and whether a retry is still pending.

Setting Up Cloud Sync

Setup takes under a minute for most providers:

  1. Open Settings in 1Take.
  2. Tap Cloud Sync.
  3. Tap the provider you want to enable.
  4. Toggle the provider on and follow the authentication prompt.
  5. For iCloud Drive, no authentication is needed — it uses your existing Apple Account.
  6. For Google Drive and Dropbox, you will be taken through the standard OAuth sign-in flow in Safari.
  7. For Backblaze B2, enter your Application Key ID, Application Key, bucket name, and an optional path prefix.

Once authenticated, the provider is active immediately. Any recordings that were not yet uploaded will begin uploading in the background.

Free for All Users

Cloud Sync is available in every version of 1Take, including the free tier. No PRO subscription is required to enable any provider or to use any aspect of the feature. Your cloud storage costs are determined by each provider's own pricing, not by 1Take.
