雲端同步：自動備份至 iCloud、Google 雲端硬碟、Dropbox 和 Backblaze B2

2026年3月29日

1Take v1.4 新增了雲端同步功能。錄音結束後，檔案會自動上傳至你選擇的雲端儲存服務，無需手動操作。

支援的雲端服務

服務最適合儲存位置
iCloud DriveMac 用戶在 Finder 中直接顯示
Google 雲端硬碟跨平台1Take 專屬資料夾
Dropbox既有 Dropbox 用戶Apps/1Take
Backblaze B2大量音訊檔案需設定 API 金鑰，費用最低

運作方式

停止錄音後，檔案會立即加入上傳佇列。連線可用時自動上傳，圖書館清單中的雲端圖示會即時顯示上傳狀態。若離線，重新連線時會自動重試。

上傳狀態圖示

  • 等待中：已排入佇列，尚未上傳
  • 上傳中：正在傳輸
  • 完成：已成功備份至雲端
  • 失敗：遇到錯誤，將自動重試

設定步驟

  1. 前往「設定」→「雲端同步」
  2. 選擇雲端服務提供商
  3. 依照提示完成驗證（Google Drive 和 Dropbox 使用 OAuth）
  4. Backblaze B2 需輸入 Application Key ID、Application Key 和儲存桶名稱
  5. 啟用「自動同步」開關

進階設定

每個服務均可獨立設定最大重試次數、重試間隔，以及是否允許行動網路上傳。上傳歷史記錄可在「設定」→「雲端同步」→「上傳記錄」中查看。

費用

雲端同步功能本身包含在 1Take 中，無額外費用。各雲端服務的儲存費用依各家方案而定。若需儲存大量音訊檔案，Backblaze B2 是最具成本效益的選擇（約 $0.006/GB/月）。
