1Take

iOS용 전문 오디오 녹음기

변경 이력

1Take의 모든 주요 변경 사항이 여기에 기록됩니다.

[1.4.1] - 2026-04-01

AI 최적화 Pro 전용화 및 중요 버그 수정.

추가됨

  • AI 최적화 Pro 전용 - AI 자동 최적화 결과 적용에 이제 Pro가 필요합니다. 무료 사용자는 분석 결과를 볼 수 있지만 조정이 적용되지 않습니다
  • 적용되지 않은 분석이 이력을 오염시키지 않도록 최적화 이력에 wasApplied 플래그 추가

수정됨

  • 무음 녹음에서 AI 최적화가 컴프레서 임계값을 복구 불가능한 값으로 설정하는 문제 수정
  • 클라우드 동기화를 위한 OAuth 인증 세션 지속성 및 토큰 URL 인코딩 수정
  • 간헐적인 업로드 실패를 유발하는 클라우드 동기화 타이밍 엣지 케이스 수정

[1.3.2] - 2026-03-23

안정성 개선 및 복구 가능한 삭제.

추가됨

  • 복구 가능한 녹음 삭제 - 삭제된 녹음이 파일 앱의 "최근 삭제된 항목"으로 이동하며 30일간 복구할 수 있습니다

수정됨

  • 세션 중단 시 재귀 호출로 인한 오디오 재생 중 드문 충돌 수정
  • 오디오 하드웨어가 준비되기 전에 녹음 버튼을 탭할 때 발생하는 드문 충돌 수정
  • 재생 중 전화 통화 및 Siri 활성화 후 복구 개선
  • Swift 6 엄격한 동시성 검사 완전 준수

[1.3.2] - 2026-03-08

MP3/AAC 내보내기, 일괄 내보내기 및 Pro 기능 개선.

추가됨

  • MP3/AAC 내보내기 (Pro) - 쉬운 공유를 위해 압축 형식으로 녹음 내보내기
  • 일괄 내보내기 (Pro) - 여러 녹음을 한 번에 내보내기
  • 고품질 내보내기 (Pro) - 최대 오디오 품질을 위한 24비트 WAV/BWF 내보내기
  • 잠긴 기능에서 한 번의 탭으로 접근하는 Pro 기능 검색 개선

[1.3.0] - 2026-02-03

녹음 분석, 지능형 자동 캘리브레이션, 5밴드 EQ 및 성능 최적화.

추가됨

  • 녹음 분석 시스템
    • 녹음 후 자동 오디오 품질 평가
    • 피크 레벨, RMS 레벨, 크레스트 팩터, LUFS 분석
    • 다이나믹 레인지 평가
    • 권장 사항이 포함된 녹음 품질 보고서
  • 자동 녹음 지능형 캘리브레이션
    • 주변 소음을 기반으로 한 자동 임계값 계산
    • 안정적인 트리거링을 위한 히스테리시스 제어
    • Auto 버튼을 통한 원터치 설정
    • 배경 소음 측정
  • 5밴드 파라메트릭 EQ
    • 전문 수준의 5밴드 파라메트릭 이퀄라이저
    • 밴드별 주파수, 게인, Q(대역폭) 제어
    • 드래그 가능한 제어점이 있는 시각적 주파수 응답 곡선
  • 절전 방지 설정 - "화면 켜두기" 옵션
  • 향상된 마이크 인식

변경됨

  • "Analyze" 버튼을 "Auto"로 이름 변경 (자동 녹음 캘리브레이션)
  • 녹음 품질 분석이 녹음 중지 후 자동으로 실행
  • 마커 시스템 단순화: 수동 Good/Bad/Memo 마커 제거 (자동 CLIP/OVER 마커 유지)
  • 4밴드 EQ를 5밴드 파라메트릭 EQ로 업그레이드

수정됨

  • 장시간 녹음 충돌 수정
  • 오디오 엔진 오류 처리 및 복구 개선
  • 오디오 경로 변경 시 리소스 정리 개선
  • 잠금 없는 원자로 스레드 안전한 오디오 처리

성능

  • 실시간 오디오 콜백에서 NSLock 사용 제거
  • 잠금 없는 동시성을 위한 Swift Atomics 도입
  • VU 발리스틱을 오디오 스레드에서 계산 (지연 없음)

[1.2.0] - 2026-01-24

전문적인 LUFS 미터링, 향상된 Pro 기능 및 Firebase 통합.

추가됨

  • LUFS 미터링 (ITU-R BS.1770-4)
    • 순간 (400ms), 단기 (3s), 통합 라우드니스
    • 4배 오버샘플링으로 True Peak 측정
    • 미터를 탭하여 전환: VU → GR → LUFS → VU
  • Pro 기능 (인앱 구매)
    • 전문 워크플로를 위한 24비트 WAV/BWF 내보내기
    • 전체 파라미터 제어가 가능한 맞춤 오디오 프리셋
    • 내장 메타데이터가 포함된 BWF (Broadcast Wave Format)
  • BWF 형식 지원

수정됨

  • 재시도 로직을 통한 오디오 경로 변경 복구
  • USB-C 마이크 연결 해제 처리 개선
  • LUFS 분석기 스레드 안전성

[1.1.0] - 2026-01-22

Arm 모드, Pre-roll 및 스펙트럼 분석기.

추가됨

  • Arm 모드 - 순환 버퍼로 대기 상태에 들어가는 ARM 버튼
  • Pre-roll 녹음 - 녹음 버튼 이전 5초의 오디오 캡처
  • 실시간 스펙트럼 분석기 - 32밴드 로그 스케일의 FFT 기반
  • GR (게인 감소) 미터 - VU 미터를 탭하여 전환
  • 입력 소스 배지 - 현재 입력 소스 표시
  • 인앱 도움말 시스템 - 영어/일본어 지역화된 10개 이상의 도움말 주제

변경됨

  • 메인 내비게이션에서 스펙트럼 탭 제거 (현재 2개 탭: 녹음, 녹음 목록)
  • 피크 리셋을 5초 고정 간격으로 변경

수정됨

  • 스테레오 녹음이 이제 올바르게 작동
  • 녹음 중 경로 변경: 안전한 중지 + 파일 닫기

[1.0.0] - 2026-01-21

최초 출시.

추가됨

  • 고품질 오디오 녹음 (WAV 16비트 PCM, 48kHz)
  • 지원 기기에서 스테레오 녹음
  • 전문적인 신호 체인: 노이즈 게이트 → EQ → 컴프레서 → 리미터

  • 스마트 컨텍스트 마커 (GOOD, BAD, MEMO, CLIP)
  • 햅틱 피드백이 있는 Clip Guard
  • Share Sheet 내보내기를 통한 녹음 관리
  • 영어 및 일본어 지역화
