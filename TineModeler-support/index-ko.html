TineModeler

물리 모델링 신시사이저 — Fender Rhodes 재현

TineModeler 지원 페이지에 오신 것을 환영합니다.

TineModeler는 샘플 없이 오직 물리 모델만으로 Fender Rhodes 일렉트릭 피아노 사운드를 재현하는 신시사이저입니다.

기능

물리 모델링

Rhodes 사운드의 모든 요소를 수학적 모델로 실시간 생성합니다: 틴(tine) 진동(오일러-베르누이 빔), 해머 타격(헤르츠 접촉력), 전자기 픽업(패러데이 법칙), 펠트 댐퍼 시뮬레이션.

AUv3 플러그인

GarageBand, Logic Pro, Cubasis 및 기타 AUv3 호환 호스트에서 Audio Unit 플러그인으로 사용하세요.

실시간 파라미터 (Pro)

픽업 위치, 자기장 세기, 해머 강도 등을 조정하여 샘플 기반 악기로는 불가능한 사운드 메이킹을 실현합니다.

가벼운 동작

Apple Silicon에서 효율적으로 작동합니다. 대용량 샘플 라이브러리 다운로드 불필요.

에디션

에디션 플랫폼 가격 기능
Free iPhone / iPad 무료 Fender Rhodes 사운드 1종, 건반 + AUv3
Pro iPhone / iPad 앱 내 구매 파라미터 편집, 다수 프리셋
Full Mac $49 (출시가) / $79 전체 파라미터, Logic Pro AUv3 플러그인
