開始之前

Tonrad 是可獨立運作的音輪風琴，適用於執行 iOS/iPadOS 18 或以上版本的 iPhone 和 iPad。請將裝置橫放：此 App 僅支援橫向操作。三個畫面分別是 HOME、DRAWBARS 和 SET。App 介面提供日文及英文；本手冊提供 11 種語言。

請確認您的版本。截至 2026 年 11 月 15 日，App Store 上的版本為 0.1.0。本手冊也說明 0.2.0 更新內容。標示 0.2.0 的功能無法在 0.1.0 中使用。螢幕截圖顯示的是 0.1.0。

沒有預設音色、錄音、帳號、廣告或 App 內購買。Tonrad 無法作為 Audio Unit 外掛運作。App Store 版本沒有 PRESET 和 TUNE 畫面。

演奏第一個音

  1. 將裝置橫放並開啟 Tonrad，先將裝置音量設為舒適的程度。
  2. 在 HOME 上演奏最上方標示 UPPER 的鍵盤。初始拉桿設定已可發聲，不需要外接鍵盤。
  3. 若音量太小，將右側的 EXP 滑桿往上移。若仍沒有聲音，請檢查 SET → AUDIO → OUTPUT 及畫面上顯示的輸出裝置。
  4. 點一下 DRAWBARS。若想試試簡單的音色，將 UPPER 的 8′ 拉桿設為 8，其餘八支 UPPER 拉桿設為 0，並將 PERC 設為 OFF。回到 HOME 演奏。
  5. 加入 UPPER 的 16′ 和 5⅓′ 拉桿，再試試 ROTARY → SLOW / FAST。

LOWER 和 PEDAL 各有自己的拉桿。提高 UPPER 拉桿的音量並不會讓其他鍵盤發聲。

HOME：鍵盤與表情控制

三列鍵盤分別是 UPPER、LOWER 和 PEDAL。按下琴鍵即可發聲，放開便停止。在琴鍵上滑動手指會切換音符，也可以同時用多根手指演奏。

螢幕較小時，每層手鍵盤上方的細條會顯示目前可見的音域。點一下或水平拖曳細條，即可顯示更低或更高的音。這只會移動可見的琴鍵範圍，不會改變調音。較寬的螢幕能顯示完整的手鍵盤，因此音域細條會消失。腳踏鍵盤仍以獨立的一列顯示。

EXP 是整部風琴的表情控制。往上拖曳會變大聲，往下則變小聲；單點一下並不會直接跳到該位置的音量。連點兩下 EXP 可恢復最大值。每次啟動 App 都會從最大值開始，位置不會儲存。演奏時可用它做出音量起伏；整體輸出音量則使用 SET → OUTPUT 調整。

DRAWBARS：塑造音色

將拉桿往下拖曳可提高音量，往上則降低音量。每支拉桿有 0–8 的位置：0 為無聲，8 為最大。UPPER 和 LOWER 各有九支拉桿，PEDAL 有兩支。

組別拉桿，由左至右
UPPER / LOWER16′ · 5⅓′ · 8′ · 4′ · 2⅔′ · 2′ · 1⅗′ · 1⅓′ · 1′
PEDAL16′ · 8′

8′ 拉桿提供所彈音符的音高，16′ 加入低一個八度的音，4′ 則加入高一個八度的音。標示較短或分數音栓長度的拉桿會加入較高的泛音。搭配各拉桿的音量即可塑造音色。

可先將 UPPER 設為 8 8 8 0 0 0 0 0 0。這些數字表示由左至右的拉桿位置，是供您手動設定的範例，並非可以選取的預設音色。若加入更多成分後音量太大，請降低 OUTPUT。

打擊音：為 UPPER 加入起音重音

打擊音會在上層鍵盤加入逐漸衰減的起音重音。控制項位於拉桿上方：

  • PERC — ON / OFF: 開啟或關閉打擊音。
  • VOLUME — SOFT / NORMAL: 選擇打擊音的音量。
  • DECAY — FAST / SLOW: 選擇打擊音衰減的速度。
  • HARMONIC — 2ND / 3RD: 選擇第二或第三泛音。

放開所有 UPPER 琴鍵後再次演奏，才會重新觸發打擊音。按住琴鍵進行連奏時，不會每個音都重新觸發。PERC 為 ON 時，UPPER 的 1′ 拉桿會變暗且不發聲；其位置會保留，關閉打擊音後即可恢復使用。

顫音與合唱

VIB UPPER 和 VIB LOWER 分別為 UPPER 及 LOWER/PEDAL 開啟效果。請從 V1, V2, V3, C1, C2, C3 選擇一個共用模式。

V 模式加入顫音；C 模式將原音與顫音訊號混合，產生合唱效果。三個數字代表不同的深度。選擇模式不會自動開啟處於 OFF 的鍵盤效果開關。VIB LOWER 也會影響 PEDAL。打擊音不會經過此顫音效果。

旋轉揚聲器與彈簧殘響

在 HOME 點一下大型 ROTARY 控制項，即可在 SLOW 和 FAST 之間切換。速度會逐漸加快或減慢，不會瞬間跳變。

  • 0.1.0: 獨立的 SPEAKER ON / OFF 按鈕設為 OFF 時，會旁通整個旋轉揚聲器。
  • 0.2.0: ROTOR ON / OFF 會停止或啟動旋轉，同時保留揚聲器的音色。若要旁通整個揚聲器，請開啟 SET → AUDIO → SPEAKER OFF。關閉該開關即可再次聽到揚聲器的效果。

在 DRAWBARS 中，PEDAL 右側的 REV 拉桿可控制彈簧殘響。範圍為 0–8，0 代表關閉。可先從 2 開始，再依喜好調整。殘響與旋轉揚聲器彼此獨立。

SET：輸出、PANIC 與音訊資訊

AUDIO 顯示目前的輸出裝置與 OUTPUT 滑桿。請用此滑桿調整整體音量。連點兩下 OUTPUT 的名稱／數值區域可恢復預設值。滑桿本身不會回應這個重設手勢。

PANIC 會停止所有正在發聲的音符。若拔除鍵盤或更改音訊連接後，有音符持續發聲，可使用此按鈕。

NUMBERS 顯示取樣率、緩衝區大小、處理計數器等音訊資訊。這些是讀值，而非音訊設定控制項。RESET 會重設主機的診斷測量值，不會重設音色或已儲存的設定。ENGINE DROPS 和 REPAIRS 會保留到音訊引擎重新啟動為止。

隱私權政策連結會在瀏覽器中開啟網站。0.2.0 的 SET 也包含下方說明的 MIDI 設定，可能需要捲動才能看到全部內容。

USB MIDI 鍵盤 — 0.2.0

  1. 使用合適的資料傳輸線或轉接器，將 USB MIDI 鍵盤連接至 iPhone 或 iPad。耗電較高的裝置可能需要使用有獨立供電的集線器。
  2. 開啟 SET → MIDI，檢查已連接裝置清單。
  3. 預設情況下，UPPER 使用 CH 1 傳送，LOWER 使用 CH 2，PEDAL 使用 CH 3。
  4. 如有需要，可在 SET 設定各聲部的接收通道。各通道會保持不同：選擇已由另一聲部使用的通道時，兩者的通道配置會互換。
  5. 使用 OCT，可將下方說明的分區移調 −3 至 +3 個八度。此設定適用於從 UPPER 輸入通道分派的音符，不適用於螢幕鍵盤或直接從 LOWER/PEDAL 通道輸入的音符。

Tonrad 會接收 iOS 提供的 MIDI 輸入。App 內沒有 Bluetooth MIDI 配對畫面。0.2.0 可在您查看其他 App 時繼續處理音訊和 MIDI。0.1.0 不接收 MIDI 輸入，切換到背景時會停止音訊。

一台鍵盤，三個分區 — 0.2.0

使用一台鍵盤時，請從指派給 UPPER 的通道傳送。頂端的長條會將該輸入分成 BASS / LOWER / UPPER。兩個分界都在最左端時，全部音域都會送往 UPPER。

  1. 從長條左端向右拖曳，建立 LOWER/UPPER 分界。
  2. 將仍在左端的分界向右拖曳，建立 BASS 分區。排列順序為 BASS、LOWER、UPPER。
  3. 在分區上垂直拖曳可調整其八度，也可以使用 SET 中對應的 OCT 控制項。這些八度移調適用於 UPPER 輸入通道的音符。

SET 中的 Fold notes into range（將音符折返至音域內）會將超出聲部可演奏音域的 MIDI 音符，以八度為單位移回範圍內，並保留相同音名。直接從 LOWER/PEDAL 通道輸入的音符也適用。變更會從下一次按鍵開始生效。

Add a pedal tap to left-hand bass（在左手低音疊加短促的腳踏音）會將 BASS 分區送往 LOWER，並加入同音名的短促腳踏音。BASS 分界以下的 LOWER 音符也適用。使用前請先將該分界移離最左端。可用 PEDAL 拉桿塑造疊加音的音色，並在 SET 的 Tap length（短促腳踏音長度）調整長度。變更會從下一次按鍵開始生效。

踏板、旋鈕與 MIDI LEARN — 0.2.0

預設控制為：CC11 控制表情、CC1 控制旋轉速度（0–63 為 SLOW，64–127 為 FAST），CC64 切換 SLOW/FAST。這些預設控制會回應指派給三個聲部的通道。CC64 在這裡是速度開關，不是鋼琴延音踏板：踩下時切換速度，放開不會切回。

  1. 開啟 SET → MIDI LEARN，或按住拉桿、EXP、REV、ROTARY 或 ROTOR 約 0.6 秒 且不移動，以開啟該項目的指派畫面。打擊音和顫音請使用 SET 的清單。
  2. 若從 SET 開啟清單，請選擇要控制的項目列。若透過長按開啟，該項目已選取並開始學習；不要再次點選同一列，因為這會取消學習。接著操作 MIDI 裝置上的旋鈕、滑桿或按鈕。
  3. 確認該列顯示 CH … · CC …，再關閉清單並試用控制項。

可指派拉桿、EXP、REV、打擊音、顫音及旋轉控制。使用該列的 × 按鈕可移除一項指派；Clear All（全部清除）會移除所有已學習的指派。指派會儲存在本機。將相同通道／CC 學習至另一個目標時，指派會移至該目標。

CC1、CC64 和 CC120–127 無法學習。CC11 只能指派給 EXP。當數值由 63 以下跨至 64 以上時，SLOW/FAST 和 ROTOR 會切換；放開不會再切換。其他已學習的開關以 64–127 為 ON，0–63 為 OFF。

會儲存哪些設定

Tonrad 會在下次啟動時還原拉桿位置、打擊音、顫音、旋轉揚聲器設定、殘響、可見鍵盤範圍及 OUTPUT。0.2.0 還會儲存 MIDI 通道、分區、八度移調、音域折返／短促腳踏音設定，以及 MIDI LEARN 指派。

EXP 不會儲存，每次都從最大值開始。沒有可命名的預設音色，也沒有設定匯出或雲端同步功能。設定保留在您的裝置上，刪除 App 時也會一併刪除。

與其他 iOS 風琴 App 比較

查核日期為 2026 年 11 月 15 日。本節比較 Tonrad 與三款適用於 iOS/iPadOS 的拉桿風琴 App：Hammond B-3X、VB3m 和 Galileo Organ 2。這是依據官方文件整理的功能比較，不是聽感測試，也不是音質、延遲或 CPU 用量的排名。

主要表格以目前在 App Store 公開的 Tonrad 0.1.0 為準。MIDI 和背景音訊已在 0.2.0 開發版本實作，但 0.1.0 無法使用。最後一個表格會區分這兩個版本。四款 App 都可獨立運作；使用 AUv3 需要相容的主機 App。

價格為查核當日日本 App Store 的價格，以日圓（JPY）表示；各地價格及優惠可能不同。「未確認」表示所查閱的官方資料未能證實該功能，不代表 App 沒有這項功能。來源連結列於下方。

疑難排解

沒有聲音
請檢查裝置音量、SET 顯示的輸出裝置、EXP 及 OUTPUT。將正在演奏的聲部至少一支拉桿提高。PERC 開啟時，只使用 UPPER 的 1′ 拉桿無法產生持續音。若音訊曾中斷，請回到 Tonrad 再試一次。
音符無法停止
點一下 SET → PANIC。若使用 MIDI，請先確認鍵盤連接，再繼續演奏。
MIDI 裝置未顯示或沒有聲音
先確認您使用的是 0.2.0。在 SET 尋找裝置，檢查電源／資料連接，並讓傳送與接收通道相符。也請檢查目標聲部的分區分界、OCT 和拉桿。
高音或低音 MIDI 音符沒有聲音
請檢查 OCT 和分割界線。在 0.2.0，可對超出風琴可演奏音域的音符試用音域折返功能。
聽不到旋轉的變化
0.1.0 請將 SPEAKER 設為 ON。0.2.0 請先關閉 SET 的 SPEAKER OFF，再將 HOME 的 ROTOR 設為 ON。SLOW 的變化比 FAST 更細微。
畫面無法轉為直向
僅支援橫向操作是預期設計。
找不到 PRESET、TUNE 或錄音功能
App Store 版本不提供這些功能。

尋求協助時，請提供 Tonrad 版本、裝置、iOS/iPadOS 版本、相關畫面／控制項，以及問題發生前的操作步驟。若是 MIDI 問題，也請提供鍵盤型號和連接方式。
