はじめに

Tonrad は、iOS／iPadOS 18 以降の iPhone・iPad で使える単体のトーンホイールオルガンです。端末を横向きにして使います。画面は HOME、DRAWBARS、SET の3つ。アプリの表示言語は日本語と英語、このマニュアルは11言語に対応しています。

お使いのバージョンを確認してください。2026年11月15日時点で、App Store の公開版は 0.1.0 です。このマニュアルでは 0.2.0 の更新内容も説明しています。0.2.0 と書かれた機能は 0.1.0 では使えません。掲載している画面写真は 0.1.0 です。

プリセット、録音、アカウント、広告、アプリ内課金はありません。Audio Unit プラグインとしては使えません。App Store 版に PRESET と TUNE の画面はありません。

まず音を出してみる

  1. 端末を横向きにして Tonrad を開き、端末の音量を無理のない大きさにします。
  2. HOME のいちばん上にある UPPER の鍵盤を弾きます。初期状態で音が出るようにドローバーが設定されています。外部の鍵盤は不要です。
  3. 小さすぎるときは、右端の EXP を上へ動かします。まだ聞こえなければ、SET → AUDIO → OUTPUT と、表示されている出力先を確認します。
  4. DRAWBARS を開きます。単純な音から試すなら、UPPER の 8′ を 8、残りの8本を 0、PERC を OFF にします。HOME に戻って弾いてみてください。
  5. UPPER の 16′ と 5⅓′ を足し、ROTARY → SLOW / FAST も切り替えてみます。

LOWER と PEDAL には、それぞれ専用のドローバーがあります。UPPER のドローバーを上げても、ほかの鍵盤の音は変わりません。

HOME：鍵盤とエクスプレッション

上から UPPER（上鍵盤）、LOWER（下鍵盤）、PEDAL（足鍵盤）が並びます。押すと鳴り、指を離すと止まります。鍵盤の上で指を滑らせると次の音へ移り、複数の指を使えば和音も弾けます。

小さな画面では、上下の鍵盤のすぐ上に細い帯が出ます。この帯を左右へドラッグするか、帯の中をタップすると、見える鍵盤の範囲を動かせます。音程を変える操作ではありません。広い画面で全鍵が収まる場合、帯は表示されません。足鍵盤は別の段に並びます。

EXP はオルガン全体のエクスプレッションです。上へドラッグすると大きく、下へ動かすと小さくなります。タップだけではその位置へ飛びません。二度タップすると最大に戻ります。起動時は毎回最大で、位置は保存されません。演奏中の抑揚には EXP、全体の出力レベルには SET → OUTPUT を使います。

DRAWBARS：音色を作る

ドローバーを下へ引くと音が大きくなり、上へ戻すと小さくなります。位置は 0〜8。0 は音なし、8 は最大です。UPPER と LOWER は9本ずつ、PEDAL は2本あります。

鍵盤左からの並び
UPPER / LOWER16′ · 5⅓′ · 8′ · 4′ · 2⅔′ · 2′ · 1⅗′ · 1⅓′ · 1′
PEDAL16′ · 8′

8′ は弾いた鍵盤の音程、16′ はその1オクターブ下、4′ は1オクターブ上の音を加えます。短い数字や分数の付いたものは、さらに高い倍音を加えます。それぞれの量を組み合わせて音色を作ります。

まず UPPER を 8 8 8 0 0 0 0 0 0 にして試せます。数字は左からの位置を表しています。選択できるプリセットではなく、自分でドローバーを動かすための例です。音を重ねて大きくなりすぎたら、OUTPUT を下げてください。

パーカッション：上鍵盤にアタックを付ける

パーカッションは、上鍵盤に減衰するアクセントを加えます。ドローバーの上に次のスイッチがあります。

  • PERC — ON / OFF：パーカッションの入／切。
  • VOLUME — SOFT / NORMAL：パーカッションの大きさ。
  • DECAY — FAST / SLOW：アクセントが消える速さ。
  • HARMONIC — 2ND / 3RD：第2倍音／第3倍音の選択。

上鍵盤の鍵をすべて離してから弾くと、再びパーカッションが鳴ります。鍵を押さえたまま次の音へつなぐレガートでは、毎音にアクセントが付きません。PERC が ON の間は UPPER の 1′ が薄く表示され、音に加わりません。位置は保持され、PERC を OFF にすると再び使われます。

ビブラートとコーラス

VIB UPPER は上鍵盤、VIB LOWER は下鍵盤と足鍵盤への入／切です。効果の種類は、共通の V1、V2、V3、C1、C2、C3 から選びます。

V はビブラート、C は原音とビブラートの音を混ぜるコーラスです。数字によって深さが変わります。種類を選ぶだけでは、OFF になっている鍵盤のスイッチは ON になりません。VIB LOWER は PEDAL にもかかります。パーカッションにはこのビブラートはかかりません。

ロータリースピーカーとリバーブ

HOME の大きな ROTARY をタップすると、SLOW と FAST が切り替わります。回転の速さはすぐに飛ぶのではなく、加速・減速しながら変わります。

  • 0.1.0：その下にある SPEAKER ON / OFF で、ロータリースピーカー全体を通すかどうかを切り替えます。OFF はバイパスです。
  • 0.2.0：ROTOR ON / OFF は、スピーカーの音色を保ったまま回転だけを止める／動かすスイッチです。スピーカー全体を通さないときは SET → AUDIO → SPEAKER OFF をオンにします。スピーカーを再び使うときは、この設定をオフに戻します。

DRAWBARS の PEDAL の右にある REV は、スプリングリバーブの量です。0〜8 で調整でき、0 で切になります。まず 2 から試し、好みに合わせて動かしてみてください。リバーブはロータリースピーカーとは別の効果です。

SET：出力、PANIC、オーディオ情報

AUDIO に現在の出力先と OUTPUT スライダーが表示されます。OUTPUT で全体の出力レベルを調整します。OUTPUT の文字と数値のある行を二度タップすると既定値に戻ります。スライダーそのものを二度タップしても、このリセットは働きません。

PANIC は鳴っているすべての音を止めます。MIDI 鍵盤を外したあとなどに音が鳴り続ける場合に使います。

NUMBERS はサンプルレート、バッファーサイズ、処理状況などの表示です。音声の設定を変更する操作子ではありません。RESET はホスト側の計測値をリセットするボタンで、音色や保存した設定を初期化するものではありません。ENGINE DROPS と REPAIRS は、オーディオエンジンが再起動するまで残ります。

プライバシーポリシーのリンクはブラウザで開きます。0.2.0 では、SET に下記の MIDI 設定もあります。項目が隠れている場合はスクロールしてください。

USB MIDI 鍵盤をつなぐ — 0.2.0

  1. データ通信に対応したケーブルやアダプターで、USB MIDI 鍵盤を iPhone・iPad につなぎます。必要な電力が大きい機器には、電源付きハブが必要な場合があります。
  2. SET → MIDI の「つながっている機器」に名前が出ているか確認します。
  3. 初期設定では、CH 1 が UPPER、CH 2 が LOWER、CH 3 が PEDAL です。
  4. 必要なら SET で各段の受信チャンネルを変更します。チャンネルは重複せず、ほかの段が使っている番号を選ぶと、その段と番号が入れ替わります。
  5. OCT は、次の節で説明する分割した音域を −3〜+3オクターブ 動かします。UPPER の入力チャンネルから振り分けた音に働き、画面鍵盤や LOWER／PEDAL の専用チャンネルから直接送った音には働きません。

Tonrad は iOS から利用できる MIDI 入力を受け取ります。アプリ内に Bluetooth MIDI の接続画面はありません。0.2.0 では、ほかのアプリを前に出していても音声と MIDI が動作します。0.1.0 は MIDI 入力に対応せず、バックグラウンドへ移すと音声が止まります。

1台の鍵盤を3つに分ける — 0.2.0

1台の鍵盤を使うときは、UPPER に割り当てたチャンネルで送信します。画面の上の帯で、その入力を BASS / LOWER / UPPER に分けられます。2つの境界が左端にある間は、すべて UPPER です。

  1. 帯の左端から右へドラッグし、LOWER と UPPER の境界を作ります。
  2. 左端に残っている境界を右へ動かすと、BASS ができます。左から BASS、LOWER、UPPER の順です。
  3. 区画を上下にドラッグするか、SET の OCT でオクターブを調整します。この移調は UPPER の入力チャンネルから振り分けた音に働きます。

SET の「音域外を折り返す」は、各段の演奏範囲から外れた MIDI ノートを、同じ音名のままオクターブ単位で戻す機能です。LOWER／PEDAL の専用チャンネルにも働きます。変更は次の押鍵から有効です。

「左手ベースに足鍵盤を重ねる」をオンにすると、BASS の音を LOWER へ送り、同じ音名の足鍵盤の音を短く重ねます。LOWER の BASS 境界より低い鍵にも働きます。BASS 境界が左端のままでは働かないので、右へ動かしてください。重ねる音は PEDAL のドローバーで調整し、SET の「一撃の長さ」で長さを変えます。変更は次の押鍵から有効です。

ペダル・つまみと MIDI LEARN — 0.2.0

標準では CC11 が EXP、CC1 が回転速度（0〜63 は SLOW、64〜127 は FAST）、CC64 が SLOW／FAST の切り替えです。これらは3段に割り当てたチャンネルで受け付けます。CC64 はピアノのように音を保持するペダルではありません。踏むと回転速度が切り替わり、離しても元に戻りません。

  1. SET → MIDI LEARN を開きます。ドローバー、EXP、REV、ROTARY、ROTOR は、その場所を動かさずに約 0.6秒 長押しして開くこともできます。パーカッションとビブラートは SET の一覧から選びます。
  2. SET から開いた場合は操作したい行を選びます。長押しで開いた場合は、すでにその項目の学習待ちになっています。行を押し直すと待機が解除されるため、そのまま外部機器のつまみ・スライダー・ボタンを動かします。
  3. 行に CH … · CC … が表示されたら「完了」で一覧を閉じ、操作してみます。

ドローバー、EXP、REV、パーカッション、ビブラート、ロータリーの操作を割り当てられます。行の × でその割り当てを削除し、「全部消す」ですべての学習済み割り当てを削除できます。割り当ては端末に保存されます。同じチャンネルと CC 番号を別の項目に覚えさせると、割り当てがそちらへ移ります。

CC1・CC64・CC120〜127 は学習できません。CC11 を割り当てられるのは EXP だけです。SLOW／FAST と ROTOR は、値が63以下から64以上に変わったときに切り替わり、離しても戻りません。ほかの学習したスイッチは、64〜127 で ON、0〜63 で OFF になります。

保存されるもの

ドローバー、パーカッション、ビブラート、ロータリースピーカー、リバーブ、見える鍵盤の範囲、OUTPUT は、次に起動したときに復元されます。0.2.0 では、MIDI チャンネル、境界、オクターブ、音域の折り返し、足鍵盤を重ねる設定と長さ、MIDI LEARN の割り当ても保存されます。

EXP の位置は保存されず、起動時は最大です。名前付きプリセットや、設定の書き出し・クラウド同期はありません。設定は端末内にあり、アプリを削除すると消えます。

トーンホイールの仕組みとTonradの音源

トーンホイールオルガンは、歯のある金属の円盤を回し、その近くに置いた電磁ピックアップで周期的な電気信号を取り出す楽器です。鍵を押すと、回り続けているホイールの音が接点を通じて出力へつながります。鍵を押してからホイールが回り始めるわけではありません。ドローバーは各成分の混ざる量を決めます。手鍵盤の1鍵にある9個の接点は必ずしも同時に閉じず、短い開閉も繰り返します。これがキークリックの成り立ちに関わります。

仕組みを詳しく読むための資料: Moro, McPherson & Sandler (2017) · Werner & Abel (2016).

Tonradはこの流れをソフトウェアでモデル化しています。91枚のホイールに相当する音源を、上鍵盤・下鍵盤・ペダルで共有します。押した鍵ごとに91個の発振器を新しく作る構造ではありません。手鍵盤は1鍵に9接点、ペダルは8接点から4本のバスバーへ集め、2本のドローバーへ混ぜます。発音範囲の端では、別のオクターブのホイールを使うフォールドバックも配線に含まれます。

Tonradでの実装の工夫

回転を続け、軸を共有する
オーディオ処理が動いている間、48本の軸の位相を進めます。同じ軸に載るモデル上のホイールは、回転とゆっくりした音高の揺れを共有します。押鍵で位相をリセットしないので、同じ鍵を繰り返し弾いても、波形の異なる位置で接点がつながり得ます。
ギア比から周波数を求める
すべてを平均律の周波数にそろえず、モーターの回転数・ギア比・歯数から計算します。例えば毎秒20回転 × 88/64 × 16歯で440 Hzです。
ホイール1回転ぶんの波形を作る
倍音、ホイールごとの音量差、振幅の揺れ、歯の位相の小さなずれを組み合わせ、周期波形を生成します。低い12枚には奇数次倍音を多く含む形を使います。弾いた音全体を録音して再生する方式ではありません。
不規則さを分けて扱う
固定シードでホイールや鍵ごとの癖を保ちます。接点の乱数列は鍵盤ごとに分かれ、一方の鍵盤を弾いても、ほかの鍵盤の跳ね方の乱数列は進みません。ホイール波形の帯域制限と接点の切替補正は別々に行います。隣接ホイールからの漏れ込みや、同時に接続される鍵が増えたときの音量の沈みも、混ざった音に反映します。

これは設計したデジタルモデルであり、特定の実機の全構成部品を測定したものではありません。特に、以下の接点時間の既定値はTonradの音作りとして選んだ値で、機械式オルガン全般に共通する規格値ではありません。

アタックの時間差：接点・ベロシティ・キークリック

Tonradは接点ごとに開閉する時刻を持っています。そのため、低いドローバーの成分が高い成分より遅れて加わり、音の出だしで倍音構成が変わります。完成した音全体に1本の音量エンベロープを掛ける処理とは異なります。ベロシティが変えるのは接点の時間差であり、ピアノのように持続音の音量へ直接倍率を掛けるものではありません。

押鍵のベロシティVが1〜127の場合、最初の接点から最後の接点までの時間差Sを、次の式でミリ秒単位で求めます。ベロシティ0は離鍵として扱います。

v = (V − 1) / 126
S = slow × (fast / slow) ^ (v ^ curve)

slowはspread_slow_ms、fastはspread_fast_ms、curveはspread_curveです。V = 1ではS = slow、V = 127ではS = fastになります。slowがfastより大きい通常の設定では、curveを大きくすると中間のベロシティでも時間差が長めに残ります。既定値は順に91.9 ms、4.55 ms、1.52です。 Sは各接点が最初に閉じる時刻の先頭から末尾までで、すべての接点が安定するまでの時間ではありません。最後の接点もSの後に跳ねることがあります。

この値は接点どうしの間隔であり、指を動かしてからスピーカーで音が出るまでの総遅延を測ったものではありません。画面鍵盤はベロシティ100を送り、時間差は約11.44 msです。指で強く押しても変わりません。開発版0.2.0では外部MIDIのベロシティが音源へ届きます。公開版0.1.0は外部MIDIに対応していません。

どの接点から閉じるか

上鍵盤
基本の順番は接点9 → 1、つまり1′ → 1⅓′ → 1⅗′ → 2′ → 2⅔′ → 4′ → 8′ → 5⅓′ → 16′です。key_jitter = 0なら、接点cが閉じる時刻はt = (9 − c) / 8 × Sです。8′はSの6/8、16′はSの時点でつながります。16′だけの音色なら、時間差の全量だけ発音開始が遅れます。
下鍵盤
接点6（2′）が最初、接点1（16′）が最後です。基準位置は|c − 6| / 5です。接点5/7、4/8、3/9は同じ基準位置を持ち、鍵ごとのばらつきで各組の前後が変わります。途中の間隔はモデル上の設計値です。
足鍵盤
8個の接点に基準位置(8 − c) / 7を使い、接点8が最初、基音を運ぶ接点1が最後に閉じます。この順番は設計上の仮定で、機械式足鍵盤の時間差を測定して得たものではありません。

既定のkey_jitter = 0.5では、途中の接点位置を鍵ごとに決まった量だけずらします。最初と最後の接点は動きません。上鍵盤と足鍵盤では接点の順番も保たれます。この「鍵ごとの癖」と、弾くたびに変わり得る「接点の跳ね」は別の仕組みです。

跳ね・離鍵とアタックの音

回り続ける波形が0以外の値にある瞬間につながると、信号に急な変化が生じます。いったん開いて閉じ直す短い跳ねが加わると、変化がさらに増えます。Tonradは録音したクリックを別に足すのでなく、この開閉からクリックを作ります。値の段差と傾きの変化を補正し、出だしの成分を保ちながらデジタル処理の折り返し雑音を抑えます。

初期の跳ねは既定で最大4組です。開くまで・閉じ直すまでの間隔は20〜400 µsから選び、2 msの群れに収まるものを使います。これとは別に、確率0.15で最初の閉接点から3〜8 ms後にもう一度開く「遅い跳ね」があります。これらの確率分布もモデル上の設計です。

離鍵すると、まだ起きていない閉接点を取り消し、すでにつながった接点をモデル上の逆順で開きます。既定の広がりは12 msです。ごく短い音では、後から加わる低い成分がつながる前に演奏が終わることもあります。素早い再打鍵でも、まだ開いていない接点の状態を引き継ぎます。毎回まったく同じアタック波形を先頭から再生する構造ではありません。

内部の接点時刻はサンプル間の小数位置まで保持します。切替補正による音源直出力の遅れは8サンプルで、48 kHzなら約0.167 msです。これは接点の時間差、オーディオのバッファー、スピーカー経路の遅れとは別です。現在のiOS版のMIDI経路はオーディオ処理ブロックの先頭でイベントを処理し、受信MIDIのタイムスタンプをサンプル位置としては引き継ぎません。

アプリで聴き比べられること

  1. 出だしを聴き取りやすくするには、PERCと両方のVIBをOFF、REVを0にします。スピーカーを通さない設定は、0.1.0ではHOME → SPEAKER OFF、0.2.0ではSET → AUDIO → SPEAKER OFFをオンです。EXPとOUTPUTは、無理のない同じ音量に保ちます。
  2. UPPERの8′だけ、16′だけ、高いドローバーを混ぜた音を比べます。長く伸ばした音と、短いタップも比べてください。成分ごとにつながる時刻が違い、ドローバーを変えると、その過程のどこが聞こえるかも変わります。PERCは別の減衰するアクセントを足す機能で、接点時間差の設定ではありません。
  3. 0.2.0では、異なるベロシティを送れる外部MIDI鍵盤で、同じドローバー設定のまま弱打と強打を比べられます。0.1.0と、両バージョンの画面鍵盤はベロシティ100固定なので、指で押す強さを変えてもこの比較にはなりません。

TUNEを備えた開発ビルド向けの参考

Pro開発モードで起動したDEBUGビルドだけに、TUNE → 接点があります。既定値から始め、同じ鍵・同じベロシティを繰り返しながら、1項目ずつ変えます。まず弱打の時間差、次に強打の時間差と曲線を比べます。跳ねを除いて時間差だけを確かめる場合はbounce_max = 0とlate_bounce_prob = 0にします。bounce_burst_ms = 0だけでは遅い跳ねが残ります。公開アプリでこの画面を購入・解除する手順はありません。

実装の確認日：2026年11月15日。対象はTonrad 0.1.0と0.2.0 build 2で、共通の接点モデルと既定値は同じです。下の研究資料は実機の背景を説明するものです。Tonradの計算式・確率分布・調整値は実装上の選択であり、論文がその数値を規定しているという意味ではありません。

困ったときは

音が出ない
端末の音量、SET の出力先、EXP、OUTPUT を確認します。弾いている段のドローバーを少なくとも1本上げてください。PERC が ON のとき、UPPER の 1′ だけでは持続音は鳴りません。音声が中断された場合は、Tonrad に戻って弾き直してください。
音が鳴り続ける
SET → PANIC を押します。MIDI を使っている場合は接続を確認してから、もう一度弾きます。
MIDI 機器が出ない・鳴らない
まずバージョンが 0.2.0 か確認します。SET の機器名、電源とデータ接続、送受信チャンネルを確認してください。送り先の音域の境界、OCT、ドローバーも確認します。
MIDI の高い音・低い音だけ鳴らない
OCT と境界を確認します。0.2.0 では、オルガンの演奏範囲を外れた音に「音域外を折り返す」を試せます。
回転感がなくなった
0.1.0 は SPEAKER を ON にします。0.2.0 は SET の SPEAKER OFF をオフに戻し、HOME の ROTOR を ON にします。SLOW の揺れは FAST より穏やかです。
縦向きにならない
横向き専用の仕様です。
PRESET・TUNE・録音が見つからない
App Store 版では使えません。
