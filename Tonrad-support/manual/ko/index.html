시작하기 전에

Tonrad는 iOS/iPadOS 18 이상을 사용하는 iPhone과 iPad에서 단독으로 실행되는 톤휠 오르간입니다. 기기를 가로로 돌려 주세요. 앱은 가로 방향으로만 작동합니다. 화면은 HOME, DRAWBARS, SET의 세 가지입니다. 앱 화면은 일본어와 영어를 지원하며, 이 설명서는 11개 언어로 제공됩니다.

버전을 확인하세요. 2026년 11월 15일 기준 App Store 버전은 0.1.0입니다. 이 설명서에는 0.2.0 업데이트도 설명되어 있습니다. 0.2.0으로 표시된 기능은 0.1.0에서 사용할 수 없습니다. 스크린샷은 0.1.0 화면입니다.

처음 소리 내기

  1. 기기를 가로로 놓고 Tonrad를 엽니다. 기기의 음량은 듣기 편한 수준에서 시작하세요.
  2. HOME에서 UPPER라고 표시된 맨 위 건반을 연주합니다. 초기 드로바 설정만으로 소리가 나며, 외부 건반은 필요하지 않습니다.
  3. 소리가 너무 작으면 오른쪽의 EXP 슬라이더를 위로 움직입니다. 여전히 소리가 나지 않으면 SET → AUDIO → OUTPUT과 표시된 출력 기기를 확인합니다.
  4. DRAWBARS를 탭합니다. 단순한 음색을 시험하려면 UPPER의 8′ 드로바를 8로, 나머지 여덟 개의 UPPER 드로바를 0으로, PERC를 OFF로 설정합니다. HOME으로 돌아가 연주합니다.
  5. UPPER의 16′와 5⅓′ 드로바를 더한 다음 ROTARY → SLOW / FAST를 시험해 보세요.

LOWER와 PEDAL에는 각각 별도의 드로바가 있습니다. UPPER 드로바를 높여도 다른 건반의 소리가 켜지지는 않습니다.

HOME: 건반과 익스프레션

세 단의 건반은 UPPER, LOWER, PEDAL입니다. 건반을 누르면 소리가 나고 놓으면 멈춥니다. 건반 위에서 손가락을 미끄러뜨리면 음이 바뀝니다. 여러 손가락으로 동시에 연주할 수 있습니다.

작은 화면에서는 각 손 건반 위의 가느다란 막대가 현재 보이는 음역을 나타냅니다. 더 낮거나 높은 음을 보려면 이 막대를 탭하거나 좌우로 드래그하세요. 보이는 건반의 범위를 움직이는 것이며 조율을 바꾸지는 않습니다. 넓은 화면에서는 손 건반 전체를 표시할 수 있으므로 음역 막대가 사라집니다. 페달 건반은 별도의 단으로 표시됩니다.

EXP는 오르간 전체의 익스프레션 조절기입니다. 위로 드래그하면 소리가 커지고 아래로 드래그하면 작아집니다. 한 번 탭하는 것만으로 그 위치의 값으로 바뀌지는 않습니다. EXP를 두 번 탭하면 최대로 돌아갑니다. 앱을 실행할 때마다 최대에서 시작하며 위치는 저장되지 않습니다. 연주 중 음량의 흐름을 만들 때 사용하고, 전체 출력 레벨은 SET → OUTPUT에서 조절하세요.

DRAWBARS: 음색 만들기

드로바를 아래로 드래그하면 레벨이 높아지고 위로 드래그하면 낮아집니다. 각 드로바는 0–8 위치를 가집니다. 0은 무음, 8은 최대입니다. UPPER와 LOWER에는 각각 아홉 개, PEDAL에는 두 개의 드로바가 있습니다.

그룹왼쪽부터 오른쪽으로 나열한 드로바
UPPER / LOWER16′ · 5⅓′ · 8′ · 4′ · 2⅔′ · 2′ · 1⅗′ · 1⅓′ · 1′
PEDAL16′ · 8′

8′ 드로바는 연주한 음의 높이를 내며, 16′는 한 옥타브 아래를, 4′는 한 옥타브 위를 더합니다. 더 짧거나 분수로 표시된 길이의 드로바는 높은 배음을 더합니다. 각 레벨을 조합해 음색을 만드세요.

시작할 때 UPPER를 8 8 8 0 0 0 0 0 0으로 설정해 보세요. 이 숫자는 왼쪽부터 오른쪽까지의 드로바 위치이며, 직접 설정하는 예시입니다. 선택해서 불러오는 프리셋은 아닙니다. 더 많은 성분을 섞어 소리가 너무 커지면 OUTPUT을 낮추세요.

퍼커션: UPPER에 어택 더하기

퍼커션은 상단 건반에 시간이 지나면서 감쇠하는 어택을 더합니다. 조절기는 드로바 위에 있습니다.

  • PERC — ON / OFF: 어택을 켜거나 끕니다.
  • VOLUME — SOFT / NORMAL: 어택의 레벨을 선택합니다.
  • DECAY — FAST / SLOW: 어택이 사라지는 속도를 선택합니다.
  • HARMONIC — 2ND / 3RD: 두 번째 또는 세 번째 배음을 선택합니다.

모든 UPPER 건반을 놓은 뒤 다시 연주하면 퍼커션이 다시 발생합니다. 건반을 누른 채 레가토로 연주하면 음마다 다시 발생하지 않습니다. PERC가 ON일 때 UPPER의 1′ 드로바는 흐리게 표시되며 소리가 나지 않습니다. 그 위치는 유지되어 퍼커션을 끄면 다시 적용됩니다.

비브라토와 코러스

VIB UPPER는 UPPER에, VIB LOWER는 LOWER/PEDAL에 효과를 켭니다. V1, V2, V3, C1, C2, C3 중 하나의 공통 모드를 선택합니다.

V 모드는 비브라토를 더하고, C 모드는 원음과 비브라토 신호를 섞어 코러스를 만듭니다. 세 숫자는 서로 다른 깊이를 선택합니다. 모드를 선택해도 OFF 상태인 건반의 스위치가 켜지지는 않습니다. VIB LOWER는 PEDAL에도 적용됩니다. 퍼커션은 이 비브라토 효과를 통과하지 않습니다.

로터리 스피커와 스프링 리버브

HOME에서 큰 ROTARY 조절기를 탭하면 SLOW와 FAST가 번갈아 선택됩니다. 속도는 즉시 바뀌지 않고 가속하거나 감속합니다.

  • 0.1.0: 별도의 SPEAKER ON / OFF 버튼을 OFF로 하면 로터리 스피커 전체를 우회합니다.
  • 0.2.0: ROTOR ON / OFF는 스피커 음색을 유지하면서 회전을 멈추거나 시작합니다. 스피커 전체를 우회하려면 SET → AUDIO → SPEAKER OFF를 켭니다. 스피커 소리를 다시 들으려면 이 스위치를 끕니다.

DRAWBARS에서 PEDAL 오른쪽의 REV 드로바는 스프링 리버브를 조절합니다. 범위는 0–8이며 0이면 꺼집니다. 2에서 시작해 취향에 맞게 조절하세요. 리버브는 로터리 스피커와 별개입니다.

SET: 출력, PANIC, 오디오 정보

AUDIO에는 현재 출력 기기와 OUTPUT 슬라이더가 표시됩니다. 전체 레벨은 이 슬라이더로 조절합니다. OUTPUT의 이름/값 영역을 두 번 탭하면 기본값으로 돌아갑니다. 슬라이더 자체에서는 이 초기화 제스처가 작동하지 않습니다.

PANIC은 현재 울리는 모든 음을 멈춥니다. 건반 연결을 끊거나 오디오 연결을 변경한 뒤 음이 계속 남을 때 사용하세요.

NUMBERS에는 샘플 레이트, 버퍼 크기, 처리 카운터 등의 오디오 정보가 표시됩니다. 이는 측정값이며 오디오 설정을 바꾸는 조절기가 아닙니다. RESET은 호스트의 진단 측정값을 초기화하며 음색이나 저장된 설정은 초기화하지 않습니다. ENGINE DROPS와 REPAIRS는 오디오 엔진을 다시 시작할 때까지 유지됩니다.

개인정보 처리방침 링크를 누르면 브라우저에서 웹사이트가 열립니다. 0.2.0의 SET에는 아래에서 설명하는 MIDI 설정도 있습니다. 모두 보려면 스크롤해야 할 수 있습니다.

USB MIDI 건반 — 0.2.0

  1. 적절한 데이터 케이블이나 어댑터로 USB MIDI 건반을 iPhone 또는 iPad에 연결합니다. 전력이 더 필요한 기기에는 외부 전원이 있는 허브가 필요할 수 있습니다.
  2. SET → MIDI를 열고 연결된 기기 목록을 확인합니다.
  3. 기본값은 UPPER에 CH 1, LOWER에 CH 2, PEDAL에 CH 3으로 전송하는 것입니다.
  4. 필요하면 SET에서 각 파트의 수신 채널을 설정합니다. 채널은 서로 다르게 유지됩니다. 다른 파트가 사용하는 채널을 선택하면 두 파트의 채널 할당이 서로 바뀝니다.
  5. OCT를 사용하면 아래에서 설명하는 영역을 −3부터 +3옥타브까지 이동할 수 있습니다. UPPER 입력 채널에서 영역으로 분배된 음에 적용되며, 화면 건반이나 LOWER/PEDAL 채널로 직접 들어오는 음에는 적용되지 않습니다.

Tonrad는 iOS에서 사용 가능한 MIDI 입력을 받습니다. 앱 안에는 Bluetooth MIDI 페어링 화면이 없습니다. 0.2.0에서는 다른 앱을 보고 있는 동안에도 오디오와 MIDI를 계속 사용할 수 있습니다. 0.1.0은 MIDI 입력을 받지 않으며 백그라운드로 이동하면 오디오가 멈춥니다.

하나의 건반을 세 영역으로 나누기 — 0.2.0

건반 하나를 사용할 때는 UPPER에 할당된 채널로 전송합니다. 맨 위의 띠가 이 입력을 BASS / LOWER / UPPER로 나눕니다. 두 경계가 모두 맨 왼쪽에 있으면 전체 음역이 UPPER로 갑니다.

  1. 띠의 왼쪽 끝에서 오른쪽으로 드래그해 LOWER/UPPER 경계를 만듭니다.
  2. 아직 왼쪽 끝에 남아 있는 경계를 오른쪽으로 드래그해 BASS 영역을 만듭니다. 순서는 BASS, LOWER, UPPER입니다.
  3. 영역을 위아래로 드래그하거나 SET의 해당 OCT 조절기를 사용해 옥타브를 조절합니다. 이 옥타브 이동은 UPPER 입력 채널에서 들어오는 음에 적용됩니다.

SET의 Fold notes into range(음역 안으로 되돌리기)는 파트의 연주 가능 음역을 벗어난 MIDI 음을 같은 음 이름을 유지하면서 옥타브 단위로 되돌립니다. LOWER/PEDAL 채널로 직접 들어오는 입력에도 적용됩니다. 변경 사항은 다음에 누르는 음부터 적용됩니다.

Add a pedal tap to left-hand bass(왼손 베이스에 짧은 페달 음 더하기)는 BASS 영역을 LOWER로 보내고 같은 음 이름의 짧은 페달 음을 더합니다. BASS 경계보다 낮은 LOWER 음에도 적용됩니다. 사용하려면 이 경계를 맨 왼쪽에서 오른쪽으로 옮기세요. PEDAL 드로바로 더해지는 음의 음색을 만들고, SET의 Tap length(짧은 페달 음의 길이)로 길이를 조절합니다. 변경 사항은 다음에 누르는 음부터 적용됩니다.

페달, 노브, MIDI LEARN — 0.2.0

기본 조작은 익스프레션용 CC11, 로터리 속도용 CC1(0–63은 SLOW, 64–127은 FAST), SLOW/FAST 전환용 CC64입니다. 이 기본 조작은 세 파트에 할당된 채널에서 반응합니다. 여기서 CC64는 피아노의 서스테인 페달이 아니라 속도 스위치입니다. 누르면 속도가 전환되고 놓아도 원래 속도로 돌아가지 않습니다.

  1. SET → MIDI LEARN을 열거나, 드로바, EXP, REV, ROTARY 또는 ROTOR를 움직이지 않고 약 0.6초 동안 길게 눌러 해당 항목의 할당 화면을 엽니다. 퍼커션과 비브라토는 SET의 목록을 사용하세요.
  2. SET에서 목록을 열었다면 조작할 항목의 행을 선택합니다. 길게 눌러 열었다면 이미 선택되어 학습이 시작된 상태입니다. 그 행을 다시 탭하면 학습이 취소되므로 다시 누르지 마세요. MIDI 기기의 노브, 슬라이더 또는 버튼을 조작합니다.
  3. 행에 CH … · CC …가 표시되는지 확인한 다음 목록을 닫고 조작해 봅니다.

드로바, EXP, REV, 퍼커션, 비브라토, 로터리 조절기를 할당할 수 있습니다. 행의 × 버튼은 해당 할당을 삭제하고, Clear All(모두 지우기)은 학습된 모든 할당을 삭제합니다. 할당은 기기에 저장됩니다. 같은 채널/CC를 다른 대상에 학습시키면 할당이 그 대상으로 이동합니다.

CC1, CC64, CC120–127은 학습할 수 없습니다. CC11은 EXP에만 할당할 수 있습니다. SLOW/FAST와 ROTOR는 값이 63 이하에서 64 이상으로 바뀔 때 전환되며, 놓아도 다시 전환되지 않습니다. 그 밖의 학습된 스위치는 64–127에서 ON, 0–63에서 OFF가 됩니다.

저장되는 항목

Tonrad는 다음 실행 시 드로바 위치, 퍼커션, 비브라토, 로터리 스피커 설정, 리버브, 화면에 보이는 건반 범위, OUTPUT을 복원합니다. 0.2.0에서는 MIDI 채널, 영역, 옥타브 이동, 음역 되돌리기/짧은 페달 음 설정, MIDI LEARN 할당도 저장됩니다.

EXP는 저장되지 않으며 최대에서 시작합니다. 이름을 붙인 프리셋이나 설정 내보내기/클라우드 동기화 기능은 없습니다. 설정은 기기에 남으며 앱을 삭제하면 함께 삭제됩니다.

문제 해결

소리가 나지 않습니다
기기 음량, SET에 표시된 출력 기기, EXP, OUTPUT을 확인하세요. 연주 중인 파트의 드로바를 적어도 하나 높이세요. PERC가 켜져 있으면 UPPER의 1′ 드로바만으로는 지속되는 음이 나지 않습니다. 오디오가 중단되었다면 Tonrad로 돌아와 다시 시도하세요.
음이 멈추지 않습니다
SET → PANIC을 탭하세요. MIDI를 사용한다면 다시 연주하기 전에 건반 연결을 확인하세요.
MIDI 기기가 보이지 않거나 소리가 나지 않습니다
먼저 0.2.0을 사용 중인지 확인하세요. SET에서 기기를 찾아보고 전원/데이터 연결을 확인한 뒤 송신 채널과 수신 채널을 맞추세요. 대상 파트의 영역 경계, OCT, 드로바도 확인하세요.
높거나 낮은 MIDI 음이 나오지 않습니다
OCT와 분할 경계를 확인하세요. 0.2.0에서는 오르간의 연주 가능 음역을 벗어난 음에 음역 되돌리기 기능을 사용해 보세요.
로터리의 움직임이 사라졌습니다
0.1.0에서는 SPEAKER를 ON으로 설정하세요. 0.2.0에서는 SET의 SPEAKER OFF를 끄고 HOME의 ROTOR를 ON으로 설정하세요. SLOW의 움직임은 FAST보다 미묘합니다.
화면이 세로로 돌아가지 않습니다
가로 방향으로만 작동하도록 설계되어 있습니다.
PRESET, TUNE, 녹음 기능을 찾을 수 없습니다
App Store 버전에서는 제공하지 않는 기능입니다.

도움을 요청할 때는 Tonrad 버전, 기기, iOS/iPadOS 버전, 관련 화면/조절기, 문제가 발생하기까지의 단계를 알려 주세요. MIDI 문제라면 건반 모델과 연결 방법도 포함해 주세요.
