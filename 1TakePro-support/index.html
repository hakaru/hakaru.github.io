Welcome to 1TakePro — the professional recording app that adds camera recording and multi-device sync to everything you love about 1Take.

All Pro features are included with no in-app purchases. Record audio, capture video, and sync multiple devices simultaneously.

Features

All 1Take Audio Features

Everything in 1Take is included: real-time EQ, Compressor, Noise Gate, and Limiter. Three professional presets (Studio, Studio+, Live), pre-roll recording, VU/GR metering, and 24-bit studio quality.

Camera Recording Pro

Record video with synchronized high-quality audio using the same DSP chain. The camera tab lets you capture performances with professional sound — ideal for instrument demos, rehearsal reviews, and live session footage.

Multi-Device Sync Pro

Start recordings simultaneously across multiple iPhones and iPads using PeerClock NTP synchronization. Sub-millisecond accuracy ensures all devices are in perfect time, so you can capture different perspectives of the same performance without manual alignment in post.

No In-App Purchases

1TakePro is a separate app with all Pro features fully unlocked. No subscriptions, no paywalls.

FAQ

What is the difference between 1Take and 1TakePro?

1Take is the audio-only version available on the App Store. 1TakePro adds camera recording and multi-device sync. Both share the same core audio engine and presets.

How does Multi-Device Sync work?

Open 1TakePro on multiple devices connected to the same Wi-Fi network. Go to the Multi tab, and all devices will synchronize their clocks using PeerClock NTP. When you start recording on one device, all others start at the same instant.

Is the beta stable enough to use?

Yes. The core audio engine is the same as 1Take, which is already on the App Store. Camera and multi-device sync are the new areas being tested in this beta.
