M2DX-Core: 음표에서 오디오까지

M2DX-Core는 앱 및 플러그인 래퍼와 분리된 Swift 6 합성 라이브러리입니다. 오퍼레이터, 알고리즘 32개, 엔벌로프, 피치와 스케일링, 보이스 할당, 패치 구조 및 합성 측 컨트롤러 처리를 구현합니다. 앱은 연결, MIDI-CI/PE, 인터페이스, 구매, 저장 및 이펙트를 제공합니다.

Modern, Mark I, Depth 및 Vintage DAC

Modern은 MSFA 방식 참조 모델과 연관된 정수 사인/게인 커널을 사용합니다. 별도의 “Clean Float32” 엔진이 아닙니다. Mark I은 원래 OPS 동작에 관한 공개 설명을 참고한 로그 사인/지수 모델을 사용합니다. 위상을 한 사분면으로 접고 로그 감쇠를 결합한 후 다시 진폭으로 변환합니다. 원래 칩의 모든 동작을 사이클 단위로 정확하게 시뮬레이션하는 것은 아닙니다.

Core에는 Modern 정수 계산을 Apache 라이선스의 MSFA/Dexed 참조 구현과 샘플 단위로 비교하는 테스트가 있습니다. 일부 테스트는 커널만 분리하기 위해 참조 위상 증가량을 주입하며, 실제 제품의 피치 계산은 별도 경로입니다. Mark I 테스트는 독립적으로 작성한 C 대응 구현과 비교하며 앱 기본값 ÷1과 다른 ÷8 테스트 조건도 포함합니다. 이 테스트가 모든 최종 앱 출력, Dexed 설정 또는 실제 DX7 녹음이 비트 단위로 동일함을 증명하지는 않습니다.

라이선스: M2DX-Core는 Apache-2.0, MIDI2Kit은 MIT이며 M2DX 앱은 별도의 독점 라이선스를 사용합니다. 테스트 전용 C 참조 구현은 제품의 Swift 라이브러리가 아닙니다. Core LICENSE, NOTICE, Mark I 커널 및 비교 테스트 조건을 참조하세요.
