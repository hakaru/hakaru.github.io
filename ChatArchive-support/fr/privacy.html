ChatArchive

Outil de sauvegarde et d'archivage des discussions LINE pour Mac

Politique de confidentialité

Dernière mise à jour : février 2025

ChatArchive (ci-après "l'Application") est conçu avec la confidentialité de l'utilisateur comme priorité absolue. Cette politique de confidentialité explique comment les données sont gérées dans l'Application.

1. Collecte de données

L'Application ne collecte aucune information personnelle ni donnée de chat.

  • Aucune donnée analytique n'est collectée
  • Aucun rapport de plantage n'est envoyé automatiquement
  • Aucun identifiant publicitaire n'est obtenu
  • Aucun suivi du comportement des utilisateurs n'est effectué

2. Communication réseau

L'Application n'effectue aucune communication réseau. Tout le traitement des données est effectué localement sur votre appareil. Toutes les fonctionnalités sont disponibles même sans connexion Internet.

3. Traitement des données

L'Application peut accéder aux données suivantes. Toutes ces données sont traitées uniquement sur votre appareil et ne sont jamais transmises à l'extérieur.

  • Fichiers de base de données de chat : Accès en lecture seule à la base de données locale de l'application de messagerie
  • Fichiers média : Accès aux images, autocollants, etc. en cache localement
  • Fichiers .chatarchive : Traitement des fichiers d'archive exportés et importés par les utilisateurs

4. Gestion des clés de chiffrement

Les clés de chiffrement utilisées pour le déchiffrement de la base de données de chat sont gérées de manière sécurisée comme suit :

  • Les clés de chiffrement ne sont utilisées qu'en mémoire pendant le traitement
  • Elles ne sont jamais sauvegardées sur disque ou dans tout autre stockage persistant
  • Elles sont libérées de la mémoire à la fermeture de l'application

5. Stockage des données

Les données de chat traitées par l'Application sont stockées uniquement dans le stockage local de votre appareil. Aucune synchronisation automatique avec iCloud ou d'autres services cloud n'est effectuée.

6. Partage avec des tiers

Nous ne fournissons, ne partageons ni ne vendons les données des utilisateurs à des tiers.

7. Confidentialité des enfants

L'Application ne collecte pas intentionnellement de données d'enfants de moins de 13 ans.

8. Modifications de cette politique

Cette politique de confidentialité peut être mise à jour si nécessaire. En cas de modifications, la dernière version sera publiée sur cette page.

9. Contact

Pour toute question concernant la confidentialité, veuillez nous contacter via le formulaire de contact.
