ChatArchive

Mac용 LINE 채팅 백업 및 아카이브 도구

macOS 14.0+
다운로드 라이선스 구매

주요 기능

iPhone 및 Mac용 LINE과 호환됩니다. Android용 LINE은 지원되지 않습니다.

🔓

암호화된 DB 복호화

메시징 앱의 암호화된 데이터베이스를 자동으로 복호화합니다.

🖱

원클릭 자동 가져오기

복잡한 설정 없이 클릭 한 번으로 채팅 데이터를 자동 감지하고 가져옵니다.

💬

채팅 UI

친숙한 채팅 인터페이스에서 기록을 탐색합니다.

🔍

전체 텍스트 검색

모든 채팅 기록을 검색합니다. 과거 메시지를 빠르게 찾을 수 있습니다.

🔒

완전한 로컬 처리

모든 데이터 처리는 기기에서만 이루어집니다. 네트워크 통신이 전혀 없습니다.

사용 방법

3단계로 채팅 기록을 탐색하세요

1

앱 실행

ChatArchive를 실행합니다. Mac용 LINE이 설치되어 있는지 확인하세요.

2

「가져오기」 클릭

가져오기 버튼을 클릭합니다. 앱이 자동으로 데이터베이스를 감지하고 복호화하여 가져옵니다.

3

채팅 기록 탐색

가져오기가 완료되면 채팅 UI에서 기록을 탐색하고 검색할 수 있습니다.

자주 묻는 질문

「데이터를 찾을 수 없습니다」 메시지가 표시됩니다

Mac용 LINE이 설치되어 있고 최소 한 번 로그인했는지 확인하세요.

「액세스 권한이 필요합니다」 메시지가 표시됩니다

시스템 설정 > 개인정보 보호 및 보안 > 전체 디스크 접근에서 권한을 부여하세요.

내 데이터는 안전한가요?

네. ChatArchive는 모든 데이터를 로컬에서 처리합니다. 네트워크 통신 없음, 외부 서버로 데이터 전송 없음.

어떤 메시지 형식이 지원되나요?

텍스트 메시지, 이미지, 스티커, 동영상, 음성 메시지, 파일, 위치 데이터, 연락처.

이미지와 스티커가 표시되나요?

앱에 캐시된 이미지와 스티커가 표시됩니다. 캐시가 삭제된 경우 썸네일이 표시됩니다.

인터넷 연결이 필요한가요?

아니요. ChatArchive는 완전히 오프라인으로 작동합니다. 네트워크 통신이 없습니다.

개인정보 처리방침 (요약)

데이터 수집

ChatArchive는 개인정보나 채팅 데이터를 수집하지 않습니다. 모든 처리는 로컬에서 수행됩니다.

네트워크 통신

이 앱은 네트워크 통신을 수행하지 않습니다. 인터넷 연결 없이도 완전히 작동합니다.

제3자 공유

사용자 데이터를 제3자에게 제공, 공유 또는 판매하지 않습니다.
