ChatArchive

Mac용 LINE 채팅 백업 및 아카이브 도구

macOS 14.0+
다운로드 내보내기 라이선스 구매와 활성화

ChatArchive를 소개할 파트너를 찾습니다

블로그, 동영상, SNS에서 Mac으로 LINE 대화를 다시 읽는 방법을 소개해 주세요.

승인된 파트너의 전용 링크를 통해 Gumroad에서 적격 ChatArchive 구매가 이루어지면, 수수료 공제 전 구매 금액의 30%를 소개 보상으로 받습니다.

US$6 구매 시 수수료 공제 전 보상은 US$1.80입니다. Gumroad 수수료는 보상 비율에 따라 분담하며, 구매가 환불되면 해당 보상도 취소됩니다.

Gumroad 계정으로 신청하고 웹사이트나 SNS 주소, 앱 소개 방법을 알려 주세요. 신청 내용을 검토한 뒤 승인되면 전용 링크를 보내 드립니다.

Gumroad에서 파트너 신청 보상과 수수료 안내

ChatArchive 전체 설명서 읽기

먼저 확인할 사항: 버전과 용도

ChatArchive는 LINE 대화를 읽을 수 있는 사본으로 보관하는 Mac 앱입니다. 가져오기 원본에 남아 있는 기록을 자체 로컬 데이터베이스로 가져와 대화를 표시하고 메시지 본문을 검색합니다. LINE으로 대화를 복원하거나, LINE 계정을 이전하거나, 메시지를 보내거나, 원본에 없는 내용을 복구하는 도구는 아닙니다.

이 설명서는 2026년 11월 15일에 확인했습니다. 배포 파일을 확인한 릴리스는 1.0.0(build 1)이며 macOS 14.0 이상이 필요합니다. 디스크 이미지의 버전 정보와 해당 소스를 검토했습니다. 현재 Gumroad 판매 페이지에는 제공되는 실행 파일의 버전이 없으므로, 해당 다운로드가 이 릴리스와 같은지는 확인되지 않았습니다.

별도의 2.0.0(build 2) 소스에서 추가된 기능은 아래에서 “앱에 2.0 화면이 있는 경우”로 구분합니다. 개발 버전 번호만으로 구매 시 그 기능이 제공된다고 판단할 수는 없습니다. Finder의 정보 가져오기에서 설치한 앱 버전을 확인하고 실제 표시되는 조작에 맞춰 진행하세요.

앱 인터페이스는 영어, 일본어, 중국어 번체, 태국어를 지원합니다. 이 설명서의 제공 언어와는 별개입니다. 소스 관련 설명은 개발자가 비공개 저장소를 검토한 결과이며, 공개 코드 다운로드 링크를 뜻하지 않습니다.

ChatArchive 전체 설명서 읽기

설치와 원본 선택

  1. 공식 구매·다운로드 경로에서 ChatArchive를 받습니다. DMG로 제공되면 열어서 ChatArchive를 응용 프로그램 폴더에 복사한 뒤 실행합니다.
  2. 가져온 데이터베이스, 임시 압축 해제 파일, 내보내기 파일을 위한 Mac 저장 공간을 확보합니다. 필요한 용량은 기록마다 다릅니다.
  3. Mac용 LINE의 로컬 데이터베이스 또는 호환되는 iPhone용 LINE의 iCloud 백업을 선택합니다. 두 원본에 담긴 기간과 메시지 수는 다를 수 있습니다.
  4. 기존 ChatArchive 라이브러리를 교체하기 전에 백업과 데이터 삭제 절차를 따르세요.

Mac에서 가져오려면 Mac용 LINE을 설치하고 LINE에서 로그인한 뒤 실행 상태로 둡니다. iCloud에서 가져오려면 Mac의 iCloud Drive 계정으로 해당 백업에 접근할 수 있어야 합니다. ChatArchive 자체에는 LINE 또는 Apple 계정 로그인 화면이 없습니다.

검토한 앱은 macOS 전용입니다. Android/Google Drive 백업, Finder의 일반 iPhone 기기 백업, 임의 ZIP 파일은 읽지 않습니다. 이후 모든 LINE 데이터베이스나 백업 형식과의 호환성을 보장하지 않습니다.

1.0.0에서 Mac용 LINE 기록 가져오기

  1. Mac용 LINE을 열고 로그인을 완료합니다. 원하는 계정인지 확인한 뒤 LINE을 열어 둡니다.
  2. 권한을 요청하면 macOS 시스템 설정 → 개인정보 보호 및 보안 → 개발자 도구에서 ChatArchive를 허용합니다. 실행 중인 LINE 프로세스에 접근하기 위한 권한입니다.
  3. ChatArchive에서 Import from LINE을 선택한 뒤 Import from LINE for Mac을 선택합니다.
  4. 탐색, 키 가져오기, 데이터베이스 읽기, 가져오기가 끝날 때까지 기다립니다. 도중에 계정을 바꾸거나 LINE을 종료하지 마세요.
  5. 완료 건수를 확인하고 창을 닫은 뒤 여러 대화와 날짜를 살펴봅니다.

앱은 실행 중인 프로세스에서 얻은 키로 LINE의 로컬 암호화 데이터베이스를 읽습니다. 원본 데이터베이스는 읽기 전용으로 엽니다. LINE 서버에 전체 과거 대화를 요청하는 방식은 아닙니다. 후보 데이터베이스가 여러 개라면 큰 데이터베이스를 우선 탐색하며, 일반적인 계정 선택 화면은 없습니다.

전체 디스크 접근 권한은 개발자 도구 권한을 대신하지 않습니다. 안내된 권한을 허용한 후에도 접근이나 복호화가 실패하면 시스템 보호를 끄지 말고 지원팀에 문의하세요. 2.0 화면에서 Mac 가져오기는 숨겨진 개발자 기능입니다. 그 버전에서는 일반 iCloud 경로를 이용하세요.

iPhone LINE의 iCloud 백업 가져오기

이 경로는 검토한 1.0.0 화면에서도 제공되며 2.0 화면에서는 기본 가져오기 경로입니다. 기기 전체 iCloud 백업이 아니라 LINE 전용 archive.zip을 읽습니다.

  1. iPhone의 LINE에 목적에 맞는 표준 백업이 완료되어 있는지 확인합니다. 현재 휴대전화 조작은 LINE 공식 백업 안내를 따르세요.
  2. Mac에서 해당 백업에 접근할 수 있는 Apple 계정을 사용하고 iCloud Drive를 켭니다. 인터넷에 연결한 뒤 파일을 사용할 수 있을 때까지 기다립니다.
  3. Import from LINE → Import from iCloud Backup을 선택합니다.
  4. 다운로드, 압축 해제, 가져오기가 끝나면 건수·이름·날짜를 확인합니다. 이후 인터페이스에는 Imported from도 표시됩니다.

탐색 위치는 ~/Library/Mobile Documents/iCloud~com~linecorp~line/Data-*/Backup/archive.zip입니다. 날짜나 계정 선택 화면 없이 처음 발견한 백업을 사용하며, 최신 백업을 고른다고 보장하지 않습니다. 이 경로에서는 Mac용 LINE을 실행할 필요가 없고, iCloud 읽기에 개발자 도구 권한도 사용하지 않습니다.

기록 업데이트: 누적이 아닌 교체

Mac/iCloud에서 가져올 때마다 ChatArchive의 연락처, 채팅, 메시지 라이브러리 전체를 교체합니다. 검토한 두 버전 모두에 해당합니다. 더 새롭거나 오래된 원본 또는 다른 원본을 가져오기 전에 별도 사본을 저장하세요. 병합 모드, 증분 다운로드, 자동 예약 동기화는 없습니다.

가져오기는 하나의 데이터베이스 트랜잭션 안에서 실행됩니다. 그 안에서 데이터베이스 오류가 발생하면 변경 사항을 되돌립니다. 유용한 보호 장치지만 사용자 백업을 대신하지는 않습니다.

내보내기 라이선스 구매와 활성화

검토한 코드에서는 읽기, 검색, 채팅 하나의 텍스트 저장에 내보내기 활성화가 필요하지 않습니다. 텍스트 일괄 내보내기는 활성화가 필요합니다. 2.0 추가 형식의 조건은 앞의 표를 확인하세요. 구매와 활성화 성공은 별개의 단계입니다.

  1. 현재 상품 페이지에서 구매와 제공 내용을 확인합니다.
  2. ChatArchive의 Activate License를 열고 제품용으로 제공된 호환 라이선스 키를 입력합니다.
  3. 온라인에서 활성화한 뒤 결과 상태를 확인합니다. 구매 영수증은 비공개로 보관하세요.

검토한 두 버전 모두 Lemon Squeezy 라이선스 서비스를 사용하며, 이후 구매 링크가 Gumroad를 가리켜도 이 점은 같습니다. Gumroad 영수증만으로 키 호환성을 확인할 수는 없습니다. 키가 없거나 거절되면 주문 정보를 첨부해 지원팀에 문의하고, 문제 해결만을 위해 다시 구매하지 마세요.

License Management에서는 이 설치의 활성화를 해제할 수 있습니다. 대화를 삭제하거나 환불하는 기능은 아닙니다. 해제하려면 서비스의 정상 응답이 필요합니다.

로컬 저장과 네트워크 통신

채팅을 로컬에서 처리한다고 앱이 전혀 통신하지 않는 것은 아닙니다. 검토한 구현에는 다음 동작이 있습니다.

통신이 발생할 수 있는 경우
작업동작
대화 읽기와 검색저장된 대화를 Mac 안에서 처리합니다. 검토한 경로에서는 채팅 업로드 대상이 발견되지 않았습니다.
iCloud 가져오기macOS가 iCloud에서 LINE 백업을 다운로드할 수 있습니다. Apple 계정과 iCloud 동작은 Apple 서비스가 처리합니다.
라이선스 서비스활성화 시 키와 Mac 컴퓨터 이름을 Lemon Squeezy에 보냅니다. 검증·해제 시에는 키와 활성화 인스턴스 식별자를 보냅니다.
2.0 스티커 불러오기LINE CDN 요청은 스티커를 식별합니다. 서버는 IP 주소 같은 일반 접속 정보도 받습니다.
링크와 저장 파일웹사이트 열기, 앱 구매, 동기화 폴더 저장에는 외부 서비스가 관여할 수 있습니다.

활성화된 설치에서는 활성화 또는 마지막 검증 성공 이후 7일이 지나면 시작 시 라이선스를 검증할 수 있습니다. 검토한 구현에서 네트워크 실패는 이전 활성화 상태를 유지하지만, 유효하지 않은 라이선스라는 응답은 유료 내보내기를 막을 수 있습니다. 영구적인 오프라인 활성화를 보장하는 동작으로 해석하지 마세요.

라이선스 자격 증명은 macOS 키체인에 보관됩니다. 대화 데이터베이스는 별도 로컬 파일입니다. 이미 가져온 본문은 원본을 다시 받지 않고 읽을 수 있지만, 첫 iCloud 다운로드, 활성화, 캐시되지 않은 2.0 스티커에는 연결이 필요할 수 있습니다.
