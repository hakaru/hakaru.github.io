ChatArchive

Mac용 LINE 채팅 백업 및 아카이브 도구

개인정보 처리방침 (영어)

2026년 11월 15일 확인 · 확인된 릴리스 1.0.0 (1) · 2.0 화면 기능 별도 표시

채팅을 로컬에서 처리한다고 앱이 전혀 통신하지 않는 것은 아닙니다. 검토한 구현에는 다음 동작이 있습니다.

통신이 발생할 수 있는 경우
작업동작
대화 읽기와 검색저장된 대화를 Mac 안에서 처리합니다. 검토한 경로에서는 채팅 업로드 대상이 발견되지 않았습니다.
iCloud 가져오기macOS가 iCloud에서 LINE 백업을 다운로드할 수 있습니다. Apple 계정과 iCloud 동작은 Apple 서비스가 처리합니다.
라이선스 서비스활성화 시 키와 Mac 컴퓨터 이름을 Lemon Squeezy에 보냅니다. 검증·해제 시에는 키와 활성화 인스턴스 식별자를 보냅니다.
2.0 스티커 불러오기LINE CDN 요청은 스티커를 식별합니다. 서버는 IP 주소 같은 일반 접속 정보도 받습니다.
링크와 저장 파일웹사이트 열기, 앱 구매, 동기화 폴더 저장에는 외부 서비스가 관여할 수 있습니다.

활성화된 설치에서는 활성화 또는 마지막 검증 성공 이후 7일이 지나면 시작 시 라이선스를 검증할 수 있습니다. 검토한 구현에서 네트워크 실패는 이전 활성화 상태를 유지하지만, 유효하지 않은 라이선스라는 응답은 유료 내보내기를 막을 수 있습니다. 영구적인 오프라인 활성화를 보장하는 동작으로 해석하지 마세요.

라이선스 자격 증명은 macOS 키체인에 보관됩니다. 대화 데이터베이스는 별도 로컬 파일입니다. 이미 가져온 본문은 원본을 다시 받지 않고 읽을 수 있지만, 첫 iCloud 다운로드, 활성화, 캐시되지 않은 2.0 스티커에는 연결이 필요할 수 있습니다.

아카이브 저장 위치

가져온 기록은 ~/Library/Application Support/ChatArchive/chatarchive.sqlite에 자동 저장됩니다. 일반 가져오기에서는 데이터베이스 위치를 묻지 않습니다. 데이터베이스에는 -wal과 -shm 동반 파일이 있을 수 있으므로 백업할 때 폴더를 함께 보관하세요.

2.0에서 내려받은 스티커 PNG는 ~/Library/Application Support/ChatArchive/StickerCache/에 저장됩니다. 내보내기 파일은 저장 대화상자에서 선택한 위치에 별도 사본으로 저장되며, 다시 가져와도 갱신되지 않습니다.

로컬 데이터베이스와 읽기용 내보내기 파일에는 ChatArchive 전용 암호화나 앱 암호가 적용되지 않습니다. Mac 계정, 기기 암호화, 적절한 백업 위치로 보호하세요. 클라우드 동기화 폴더에 저장하면 해당 서비스가 파일을 업로드할 수 있습니다.

앱의 데이터베이스는 작업용 라이브러리이며 LINE 호환 복원 패키지가 아닙니다. 오래된 문서의 .chatarchive 또는 .linearchive 언급만으로 검토한 Mac 화면에 가져오기·복원 명령이 있다고 판단할 수 없습니다.

백업과 데이터 삭제

다시 가져오거나 Mac을 옮기기 전에

  1. ChatArchive를 완전히 종료합니다.
  2. Finder에서 이동 → 폴더로 이동을 열고 ~/Library/Application Support/ChatArchive/를 입력합니다.
  3. 폴더 전체를 날짜를 붙인 보호된 백업 위치에 복사합니다. 데이터베이스 동반 파일과 스티커 캐시도 포함하세요.
  4. 중요한 읽기용 파일과 원본 백업은 별도로 보관합니다. 다음 단계로 넘어가기 전에 백업 사본이 실제로 있는지 확인합니다.

이는 로컬 파일을 보존하는 절차입니다. 검토한 UI에는 지원되는 데이터베이스 복원 마법사나 라이브러리 병합 기능이 없습니다. 이전·복구 시 원본 사본을 변경하지 말고 버전 호환성을 지원팀에 문의하세요. 다른 Mac에서는 라이선스도 별도로 활성화해야 할 수 있습니다.

로컬 기록 삭제

검토한 인터페이스에는 채팅별 삭제 명령이 없습니다. 종료하고 필요한 백업을 만든 뒤 Finder에서 Application Support의 ChatArchive 폴더를 휴지통으로 옮길 수 있습니다. 실제 파일을 삭제하면 로컬 작업용 라이브러리가 없어지고, 다음 실행 때 새 빈 라이브러리를 만듭니다. 내보낸 파일과 백업은 필요하면 따로 삭제하세요.

앱만 삭제해도 Application Support 파일이나 키체인 라이선스가 반드시 삭제되는 것은 아닙니다. ChatArchive 파일 삭제는 원래 LINE 대화나 iCloud 백업을 지우지 않습니다. 휴지통, 시스템 백업, 클라우드 사본에는 각자의 보존 방식이 있으므로 안전한 완전 삭제 기능은 아닙니다.
