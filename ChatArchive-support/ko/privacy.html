ChatArchive

Mac용 LINE 채팅 백업 및 아카이브 도구

개인정보 처리방침

마지막 업데이트: 2025년 2월

ChatArchive(이하 '앱')는 사용자 개인정보 보호를 최우선으로 설계되었습니다. 이 개인정보 처리방침은 앱 내에서 데이터가 어떻게 처리되는지 설명합니다.

1. 데이터 수집

앱은 어떠한 개인정보나 채팅 데이터도 수집하지 않습니다.

  • 분석 데이터 수집 없음
  • 충돌 보고서 자동 전송 없음
  • 광고 식별자 획득 없음
  • 사용자 행동 추적 없음

2. 네트워크 통신

앱은 어떠한 네트워크 통신도 수행하지 않습니다. 모든 데이터 처리는 디바이스에서 로컈로 완료됩니다. 인터넷 연결 없이도 모든 기능을 사용할 수 있습니다.

3. 데이터 처리

앱은 다음 데이터에 액세스할 수 있습니다. 이 모든 데이터는 디바이스에서만 처리되며 외부로 전송되지 않습니다.

  • 채팅 데이터베이스 파일: 메시징 앱의 로컈 데이터베이스에 대한 읽기 전용 액세스
  • 미디어 파일: 로컈에 캐시된 이미지, 스티커 등에 대한 액세스
  • .chatarchive 파일: 사용자가 내보내고 가져오는 아카이브 파일 처리

4. 암호화 키 처리

채팅 데이터베이스 복호화에 사용되는 암호화 키는 다음과 같이 안전하게 처리됩니다:

  • 암호화 키는 처리 중 메모리에서만 사용됩니다
  • 디스크나 다른 영구 저장소에 저장되지 않습니다
  • 앱이 닫힌 때 메모리에서 제거됩니다

5. 데이터 저장

앱에서 처리된 채팅 데이터는 디바이스의 로컈 저장소에만 저장됩니다. iCloud 또는 다른 클라우드 서비스와의 자동 동기화는 수행되지 않습니다.

6. 제3자 공유

사용자 데이터를 제3자에게 제공, 공유 또는 판매하지 않습니다.

7. 아동 개인정보 보호

앱은 13세 미만 아동에게서 의도적으로 데이터를 수집하지 않습니다.

8. 방침 변경

이 개인정보 처리방침은 필요에 따라 업데이트될 수 있습니다. 변경 시 최신 버전이 이 페이지에 게시됩니다.

9. 문의

개인정보에 관한 질문이 있으시면 문의 양식을 통해 연락해 주세요.
