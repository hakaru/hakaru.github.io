開始前請先確認：版本與用途

ChatArchive 是將 LINE 對話保存為可閱讀副本的 Mac App。它把來源中仍可取得的紀錄匯入自己的本機資料庫，顯示對話並搜尋訊息文字。它不能將對話還原至 LINE、轉移 LINE 帳號、傳送訊息，或復原來源中不存在的內容。

本指南於 2026 年 11 月 15 日確認。已驗證的發行下載為 1.0.0（build 1），需要 macOS 14.0 以上版本。本次檢視了磁碟映像檔內的版本資訊及對應原始碼。目前的 Gumroad 商品頁未標明交付的執行檔版本，因此尚未確認其下載內容與此發行版本相同。

另一份 2.0.0（build 2） 原始碼新增的功能，僅在下文標示「若您的 App 有 2.0 介面」時說明。開發版本號不代表購買時一定取得那些功能。請在 Finder 的「取得資訊」確認已安裝版本，並依實際可見的控制項操作。

App 介面提供英文、日文、繁體中文與泰文，與本手冊的提供語言不同。本指南對原始碼的說明來自開發者對私人儲存庫的檢視，並非公開程式碼下載連結。

安裝與選擇來源

  1. 從官方購買或下載管道取得 ChatArchive。若以 DMG 提供，請開啟並將 ChatArchive 複製到「應用程式」後再執行。
  2. 為匯入的資料庫、暫存解壓縮檔及匯出檔預留足夠的 Mac 空間。不同紀錄需要的容量不同，沒有適用所有情況的固定值。
  3. 選擇 Mac 版 LINE 本機資料庫，或相容的 iPhone 版 LINE iCloud 備份。兩者可能包含不同期間與不同數量的訊息。
  4. 取代現有 ChatArchive 資料庫前，請先依備份與移除資料的步驟處理。

從 Mac 匯入時，請安裝 Mac 版 LINE、在 LINE 登入並保持執行。從 iCloud 匯入時，必須能透過 Mac 的 iCloud Drive 帳號存取該備份。ChatArchive 本身不提供 LINE 或 Apple 帳號登入表單。

本次檢視的 App 僅適用 macOS，不讀取 Android／Google Drive 備份、一般 Finder iPhone 裝置備份或任意 ZIP 檔。無法保證支援日後每一種 LINE 資料庫或備份格式。

在 1.0.0 從 Mac 版 LINE 匯入

  1. 開啟 Mac 版 LINE 並完成登入。確認使用的是目標帳號，然後保持 LINE 開啟。
  2. 若要求權限，請在 macOS「系統設定」→「隱私權與安全性」→「開發者工具」允許 ChatArchive。此權限用於存取執行中的 LINE 程序。
  3. 在 ChatArchive 選擇 Import from LINE，再選擇 Import from LINE for Mac。
  4. 等待偵測、取得金鑰、讀取資料庫及匯入完成。期間請勿切換帳號或結束 LINE。
  5. 檢查完成筆數、關閉操作視窗，再查看數個對話與日期。

App 使用從執行中程序取得的金鑰，讀取 LINE 的本機加密資料庫。來源資料庫以唯讀方式開啟，不會向 LINE 伺服器要求所有歷史對話。若有多個候選資料庫，自動偵測會優先選較大的資料庫；此處沒有一般帳號選擇器。

「完整磁碟存取」不能取代「開發者工具」權限。依說明允許後仍無法存取或解密時，請聯絡支援，不要停用系統保護。2.0 介面的 Mac 匯入是隱藏的開發者功能。該版本請使用一般 iCloud 路徑。

匯入 iPhone LINE 的 iCloud 備份

本次檢視的 1.0.0 介面提供此路徑，2.0 介面則以此為一般匯入方式。它讀取 LINE 專用的 archive.zip，不是整部裝置的 iCloud 備份。

  1. 確認 iPhone 上的 LINE 已完成適合用途的標準備份。手機端目前的操作請參閱 LINE 官方備份說明。
  2. Mac 使用可存取該備份的 Apple 帳號，並啟用 iCloud Drive。保持網路連線，等待檔案可供使用。
  3. 選擇 Import from LINE → Import from iCloud Backup。
  4. 等待下載、解壓縮與匯入完成，檢查筆數、名稱及日期。較新的介面也會顯示 Imported from。

偵測位置為 ~/Library/Mobile Documents/iCloud~com~linecorp~line/Data-*/Backup/archive.zip。程式採用第一個符合的備份，沒有日期或帳號選擇畫面，也不保證選到最新一份。此路徑不需要執行 Mac 版 LINE，iCloud 讀取也不使用開發者工具權限。

匯入紀錄包含的範圍

封存內容反映匯入當下所選來源中的紀錄。匯入成功不代表帳號曾經交換的每段對話都在其中。先前刪除的訊息、無法取得的舊紀錄，以及來源缺少的媒體都無法重建。

iCloud 讀取器在預期資料表存在時，可處理個人聊天、多人聊天、群組、官方帳號與 Keep Memo。若缺少聯絡人資訊，名稱可能以識別碼或一般標籤代替。未知訊息類型可能顯示為類型編號。

Mac 與 iCloud 是獨立來源。手機上顯示的紀錄可能從未儲存於 Mac。匯入另一來源會取代目前的 ChatArchive 資料庫，不會合併兩者涵蓋範圍。

若完整性很重要，請另行保留原始備份。App 只讀取選定欄位，不是 LINE 資料庫的每張表或每個中繼資料欄位。尤其 2.0 的表情回應擷取不包含備份中的 SQLite 日誌檔，因此不保證所有回應都齊全。

更新紀錄：取代而非累加

每次從 Mac／iCloud 匯入，都會取代 ChatArchive 內全部聯絡人、聊天與訊息資料。本次檢視的兩個版本皆如此。匯入較新、較舊或不同來源前，請先保存獨立副本。沒有合併模式、增量下載或自動排程同步。

  1. 備份目前的本機資料庫，並保存需要的閱讀副本。
  2. 確認目標來源及備份期間。
  3. 再次執行相同匯入步驟。
  4. 比較最早與最新日期、重要對話及完成筆數是否符合預期。

匯入在單一資料庫交易中執行；交易內若發生資料庫錯誤，會回復該次變更。這是有用的保護，但不能取代自行備份。

重新匯入不會刻意為每則既有訊息附加第二份副本，而是依來源重建資料庫。來源本身已有的重複紀錄仍可能出現。較小的來源可能產生較小的資料庫，並移除先前可見的紀錄。

瀏覽對話與較舊訊息

左側側邊欄包含匯入、匯出與授權操作。中間欄按最後訊息時間排列聊天，選取後在右欄閱讀。聊天列表的搜尋欄只篩選聊天名稱，不搜尋訊息本文。

開啟對話時先載入最新 200 則訊息。使用上方 Load older messages 載入較早頁面，每次最多 200 則。因此，畫面只見近期內容不代表較舊的已匯入訊息不存在。

訊息依日期分組，並區分自己與其他發訊者。文字可選取及複製。2.0 介面中，偵測到的連結可開啟系統瀏覽器或對應 App。開啟連結與閱讀本機封存是不同操作。

若日期不合理，請保留來源並回報版本及匯入路徑。1.0.0 之後的原始碼更改了 iCloud 時間轉換，因此依賴初版匯出內容前應先確認日期。

跨對話搜尋訊息文字

  1. 點選工具列的放大鏡，開啟 Full-Text Search。
  2. 輸入一個或多個詞並按 Return。本次檢視的搜尋在提交輸入時執行。
  3. 查看發訊者、日期及訊息預覽，選取結果即可開啟該聊天。

搜尋涵蓋已儲存的訊息本文與發訊者名稱，使用詞彙／前綴索引，最多回傳最新 100 筆。它不是任意位置的子字串搜尋；片語的一部分、標點符號，以及詞間沒有空格的語言，可能與預期不同。可試用較長且具辨識度的表達，或改換關鍵詞。

選取結果會選到對話，不會直接定位該則符合的訊息。較舊結果請依日期載入先前頁面尋找。搜尋不檢查照片、錄音、附件內容或貼圖圖片中的文字。結果為空不代表原始備份缺少該對話。

圖片、附件、貼圖與表情回應

辨認訊息類型與保存附件本體是兩件事。1.0.0 將照片、影片、音訊、檔案、位置、聯絡人及貼圖表示為文字或類型標籤。本次檢視的介面沒有通用附件下載、照片檢視器或影音播放器。

若您的 App 有 2.0 介面

對相容的 iCloud 貼圖紀錄，App 會讀取貼圖識別碼並向 LINE 貼圖 CDN 要求 PNG。成功載入的圖片會快取於本機。這是靜態圖片表示，不保證動畫、聲音、已無法取得的貼圖或所有較新格式。

已有快取可離線重用，未快取圖片則需要成功的網路請求。替代圖示可能表示缺少中繼資料、沒有連線或 CDN 圖片不可用。單純匯入紀錄不會預先下載所有貼圖。

支援的表情回應可從 iCloud 輔助資料庫顯示為表情符號徽章與數量，但並非誰在何時回應的完整紀錄。貼圖與回應功能也不使 ChatArchive 成為完整媒體備份。

封存資料的儲存位置

匯入紀錄會自動儲存在 ~/Library/Application Support/ChatArchive/chatarchive.sqlite。一般匯入不會要求選擇資料庫位置。資料庫可能有 -wal 和 -shm 伴隨檔案，備份時請一起保留整個資料夾。

2.0 將下載的貼圖 PNG 儲存在 ~/Library/Application Support/ChatArchive/StickerCache/。匯出檔儲存於對話框中選定的位置，是獨立副本，不會隨再次匯入而更新。

本機資料庫與閱讀用匯出檔沒有 ChatArchive 專屬加密或 App 密碼。請使用 Mac 帳號、裝置加密及合適的備份位置保護它們。存入雲端同步資料夾的檔案可能由該服務上傳。

App 資料庫是工作用資料庫，不是相容 LINE 的還原套件。舊資料提到 .chatarchive 或 .linearchive，不代表本次檢視的 Mac 介面提供匯入或還原指令。

在 1.0.0 儲存文字副本

單一對話

選取聊天，使用訊息上方的 Save as Text，再指定名稱與位置。此操作不需啟用匯出授權，會讀取該聊天所有已匯入訊息，包括尚未顯示的舊頁面。

所有對話

選擇側邊欄的 Export All，需要已啟用的授權。檢視的 1.0.0 介面會要求選擇目標資料夾，為每個非空聊天建立文字檔。2.0 介面的同一側邊欄操作，則儲存包含各聊天文字檔的 chatarchive-export.tar.gz。

文字輸出包含日期、時間、發訊者名稱及儲存的本文，不嵌入附件二進位資料、貼圖圖片或表情回應徽章。因此，沒有儲存本文的非文字訊息可能幾乎沒有有用內容。

請先檢查重要對話的匯出內容再依賴它。聊天名稱會成為檔名：同名聊天，或經禁止字元替換、長名稱縮短後變成同名者，可能產生衝突。這類聊天請以不同檔名個別儲存。

HTML 與 Markdown：僅限有 2.0 介面時

HTML 注意事項：在檢視的 2.0 實作中，對話文字內的 HTML 片段可能影響匯出頁面的行為。在確認修正版前，請改用文字或 Markdown。以下步驟僅說明介面，不代表建議開啟此實作產生的 HTML 匯出檔。

這些格式存在於檢視的 2.0 原始碼中，不在已驗證的 1.0.0 發行介面內。若工具列有 Export Chat 按鈕，請先選取聊天，再開啟該按鈕選擇格式與範圍。

2.0 匯出選項
選項授權輸出
Selected Chat → HTML不需已啟用的授權一個可由瀏覽器閱讀的 HTML 檔
All Chats → HTML需要已啟用的授權包含聊天列表的一個 HTML 檔
Markdown (ZIP)需要已啟用的授權所有聊天的 Markdown 及已快取貼圖檔

HTML 預設範圍為 All Chats。只匯出一個聊天時，請明確選擇 Selected Chat。儲存並等候完成後，App 會用關聯程式開啟結果。

HTML 只嵌入快取中已有的貼圖。需要圖片時，請先成功顯示相關貼圖再匯出。搜尋欄只篩選聊天名稱，不搜尋全部訊息本文；顯示對話需要 JavaScript。

Markdown ZIP 包含 attachments/stickers/ 資料夾及 Obsidian 形式的圖片參照。一般 Markdown 閱讀器可能需要調整路徑或語法。請檢查缺失圖片及同名聊天檔案。兩種格式都不是完整保存副本或 LINE 匯入檔，請同時保留資料庫備份。

購買與啟用匯出授權

檢視的程式碼允許在未啟用匯出授權時閱讀、搜尋，以及將單一聊天儲存為文字。批次文字匯出需要啟用。2.0 新增格式的規則見前表。購買與成功啟用是不同步驟。

  1. 在目前的商品頁確認購買與交付內容。
  2. 開啟 ChatArchive 的 Activate License，輸入該產品提供的相容授權金鑰。
  3. 連線啟用並檢查結果狀態。購買收據請私下保管。

本次檢視的兩個版本都使用 Lemon Squeezy 授權服務，即使較新購買連結指向 Gumroad 也一樣。僅有 Gumroad 收據不能確認金鑰相容。若沒有收到金鑰或被拒絕，請附訂單參考資料聯絡支援，不要只為排除問題而再次購買。

License Management 可解除這次安裝的啟用狀態，不會刪除對話或辦理退款。停用需要服務回傳成功回應。

本機儲存與網路活動

在本機處理聊天，不表示 App 完全不會通訊。檢視的實作有以下行為。

可能發生通訊的情況
操作行為
閱讀與搜尋聊天已儲存對話在 Mac 上處理；檢視的路徑中未發現上傳聊天的端點。
iCloud 匯入macOS 可能從 iCloud 下載 LINE 備份。Apple 帳號與 iCloud 活動由 Apple 服務處理。
授權服務啟用時將金鑰與 Mac 電腦名稱傳給 Lemon Squeezy；驗證及停用時傳送金鑰與啟用執行個體識別碼。
2.0 貼圖載入對 LINE CDN 的請求會識別貼圖；伺服器也會收到 IP 位址等一般連線資訊。
連結與儲存檔案開啟網站、購買 App 或存入同步資料夾可能涉及其他服務。

已啟用的安裝在啟用或上次驗證成功後經過 7 天，可能於啟動時再次驗證。檢視的實作在網路失敗時保留先前狀態，但無效授權回應可能停用付費匯出。這不代表永久離線啟用的承諾。

授權憑證保存在 macOS 鑰匙圈，對話資料庫則是另一個本機檔案。已匯入文字不必再次取得來源即可閱讀，但首次 iCloud 下載、啟用，以及未快取的 2.0 貼圖可能需要連線。

備份與移除資料

再次匯入或移轉 Mac 前

  1. 完全結束 ChatArchive。
  2. 在 Finder 使用「前往」→「前往檔案夾」，輸入 ~/Library/Application Support/ChatArchive/。
  3. 將整個資料夾複製到有日期標記且受保護的備份位置，包含資料庫伴隨檔案與貼圖快取。
  4. 重要閱讀副本與原始備份請另行保管。繼續前確認備份副本確實存在。

此程序保存本機檔案；檢視的 UI 沒有支援的資料庫還原精靈或資料庫合併功能。移轉或復原時，請保留原始副本不變，並向支援確認版本相容性。另一台 Mac 可能也需要另外啟用授權。

移除本機紀錄

檢視的介面沒有逐一聊天刪除指令。結束並完成必要備份後，可在 Finder 將 Application Support 內的 ChatArchive 資料夾移到垃圾桶。實際刪除檔案後，本機工作資料庫即被移除；之後啟動會建立新的空資料庫。需要時請另外移除匯出檔與備份副本。

只刪除 App 不一定會刪除其 Application Support 檔案或鑰匙圈授權。移除 ChatArchive 檔案不會刪除原來的 LINE 對話或 iCloud 備份。垃圾桶、系統備份及雲端副本各有保留機制；這不是安全抹除功能。
