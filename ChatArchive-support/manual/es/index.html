Lea primero: versión y finalidad

ChatArchive es una aplicación para Mac que permite conservar una copia legible de las conversaciones de LINE. Importa el historial disponible a su propia base de datos local, muestra conversaciones y busca en el texto de los mensajes. No restaura conversaciones en LINE, transfiere cuentas de LINE, envía mensajes ni recupera contenido ausente en la fuente.

Este manual se comprobó el 15 de noviembre de 2026. La descarga de la versión verificada es 1.0.0 (compilación 1), que requiere macOS 14.0 o posterior. Se revisaron los metadatos de la imagen de disco y el código fuente correspondiente. La página actual de Gumroad no identifica la versión del archivo entregado, por lo que no se ha establecido que su descarga sea idéntica a esa versión.

El código independiente de 2.0.0 (compilación 2) añade funciones que se describen abajo únicamente donde se indica «Si su aplicación tiene la interfaz de 2.0». Un número de versión en desarrollo no demuestra que esas funciones se incluyan en una compra. Consulte la versión instalada mediante Obtener información en Finder y siga los controles que realmente tenga.

La interfaz de la aplicación incluye inglés, japonés, chino tradicional y tailandés. Los idiomas de este manual son independientes. Las referencias al código describen la revisión de un repositorio privado por el desarrollador; no son enlaces públicos de descarga del código.

Instalar y elegir la fuente

  1. Obtenga ChatArchive mediante el canal oficial de compra o descarga. Si se entrega como DMG, ábralo y copie ChatArchive a Aplicaciones antes de iniciar la aplicación.
  2. Reserve espacio libre en el Mac para la base importada, la extracción temporal y las exportaciones. Una cantidad fija de almacenamiento no puede cubrir todos los historiales.
  3. Elija entre la base local de LINE para Mac y una copia de seguridad compatible de LINE para iPhone en iCloud. Pueden contener períodos y cantidades de mensajes diferentes.
  4. Antes de sustituir una biblioteca existente de ChatArchive, siga Crear copias de seguridad y eliminar datos.

Para importar del Mac, instale LINE para Mac, inicie sesión en LINE y manténgalo abierto. Para importar de iCloud, la copia correspondiente debe estar accesible mediante la cuenta de iCloud Drive del Mac. ChatArchive no proporciona su propio formulario de inicio de sesión en LINE o la Cuenta de Apple.

La aplicación revisada es exclusiva de macOS. No lee copias de Android/Google Drive, copias generales del iPhone creadas con Finder ni archivos ZIP arbitrarios. No se garantiza la compatibilidad con todos los formatos futuros de bases de datos o copias de seguridad de LINE.

Importar desde LINE para Mac en 1.0.0

  1. Abra LINE para Mac y complete el inicio de sesión. Confirme que la cuenta deseada está activa y deje LINE abierto.
  2. Si se solicita, autorice ChatArchive en Ajustes del Sistema de macOS → Privacidad y seguridad → Herramientas de desarrollo. Este permiso permite acceder al proceso de LINE en ejecución.
  3. En ChatArchive, seleccione Import from LINE y después Import from LINE for Mac.
  4. Espere a que terminen la detección, la obtención de la clave, la lectura de la base y la importación. Evite cambiar de cuenta o cerrar LINE durante el proceso.
  5. Compruebe las cantidades finales, cierre la ventana y revise varias conversaciones y fechas.

La aplicación lee la base local cifrada de LINE con una clave obtenida del proceso en ejecución. Abre la base de origen en modo de solo lectura. No solicita a los servidores de LINE todas las conversaciones históricas. Cuando existen varias bases candidatas, la detección automática prioriza una base más grande; aquí no hay un selector normal de cuentas.

Acceso total al disco no sustituye al permiso de Herramientas de desarrollo. Si el acceso o descifrado sigue fallando después de conceder el permiso indicado, contacte con soporte en vez de desactivar las protecciones del sistema. En la interfaz de 2.0, la importación del Mac está oculta como función para desarrolladores. Utilice allí la ruta normal de iCloud.

Importar una copia de LINE para iPhone desde iCloud

Esta ruta está disponible en la interfaz revisada de 1.0.0 y es la ruta normal en 2.0. Lee el archivo archive.zip específico de LINE, no una copia de iCloud de todo el dispositivo.

  1. Compruebe que LINE en el iPhone dispone de una copia estándar terminada y adecuada. Siga las instrucciones oficiales de copia de seguridad de LINE para la interfaz actual del teléfono.
  2. En el Mac, utilice la Cuenta de Apple que permita acceder a esa copia y active iCloud Drive. Espere el tiempo necesario y mantenga una conexión a internet para que el archivo esté disponible.
  3. Seleccione Import from LINE → Import from iCloud Backup.
  4. Espere a la descarga, extracción e importación. Revise las cantidades, los nombres y las fechas. Las interfaces posteriores también muestran Imported from.

La detección busca en ~/Library/Mobile Documents/iCloud~com~linecorp~line/Data-*/Backup/archive.zip. Utiliza la primera copia coincidente que encuentra, sin una pantalla para elegir fecha o cuenta; no promete seleccionar la más reciente. LINE para Mac no necesita estar abierto para esta ruta y el lector de iCloud no utiliza el permiso de Herramientas de desarrollo.

Qué incluye el historial importado

El archivo refleja los registros presentes en la fuente elegida al importar. Una importación correcta no demuestra que se hayan incluido todas las conversaciones intercambiadas alguna vez por la cuenta. No se pueden reconstruir mensajes eliminados anteriormente, historiales antiguos no disponibles ni medios ausentes en la fuente.

El lector de iCloud procesa chats individuales, chats con varias personas, grupos, cuentas oficiales y registros de Keep Memo cuando existen las tablas esperadas. Si faltan datos de contacto, pueden aparecer identificadores o etiquetas genéricas en lugar de nombres. Los tipos de mensaje desconocidos pueden mostrarse como un número de tipo.

Las copias del Mac y de iCloud son fuentes independientes. El teléfono puede mostrar historial que nunca se almacenó en el Mac. Importar la otra fuente sustituye la biblioteca actual de ChatArchive; no combina el contenido de ambas.

Conserve la copia de origen por separado si la integridad del conjunto es importante. La aplicación lee campos seleccionados, no todas las tablas ni todos los metadatos de LINE. En particular, la extracción de reacciones de 2.0 no incorpora los archivos de diario de SQLite incluidos en la copia, por lo que no se garantiza que las reacciones estén completas.

Actualizar el historial: sustituir, no acumular

Cada importación del Mac/iCloud sustituye toda la biblioteca de contactos, chats y mensajes de ChatArchive. Esto se aplica a ambas versiones revisadas. Guarde una copia independiente antes de importar una fuente más reciente, más antigua o diferente. No hay modo de combinación, descarga incremental ni sincronización automática programada.

  1. Haga una copia de la biblioteca local actual y guarde las copias de lectura que necesite.
  2. Confirme la fuente deseada y el período de la copia.
  3. Ejecute de nuevo el mismo procedimiento de importación.
  4. Compare las fechas más antigua y reciente, las conversaciones importantes y las cantidades finales con lo esperado.

La importación se ejecuta en una sola transacción de base de datos: un error de base durante esa transacción revierte sus cambios. Es una protección útil, pero no sustituye a su copia de seguridad.

Reimportar una fuente no añade deliberadamente una segunda copia de cada mensaje existente. Reconstruye la biblioteca a partir de la fuente; los registros duplicados que ya existan en ella pueden seguir apareciendo. Una fuente menor puede producir una biblioteca menor y eliminar historial que antes estaba visible.

Leer conversaciones y mensajes antiguos

La barra lateral izquierda contiene los controles de importación, exportación y licencia. La columna central lista los chats por la fecha de su último mensaje. Seleccione un chat para leerlo en la columna derecha. La búsqueda de la lista filtra nombres de chats; no busca en el cuerpo de los mensajes.

Una conversación carga inicialmente sus 200 mensajes más recientes. Use Load older messages en la parte superior para cargar páginas anteriores, con hasta 200 mensajes cada vez. Ver solo un período reciente en pantalla no demuestra, por tanto, que falten mensajes antiguos importados.

Los mensajes se agrupan por fecha y distinguen los propios de los de otras personas. El texto se puede seleccionar y copiar. En la interfaz de 2.0, los enlaces detectados pueden abrir el navegador del sistema o la aplicación asociada. Abrir un enlace es una acción distinta de leer el archivo local.

Si una fecha parece incorrecta, conserve la fuente e indique la versión y la ruta de importación. El código posterior a 1.0.0 cambia la conversión de las marcas de tiempo de iCloud; compruebe las fechas de la versión original antes de confiar en una exportación.

Buscar en el texto de todos los mensajes

  1. Pulse la lupa de la barra de herramientas para abrir Full-Text Search.
  2. Introduzca una o varias palabras y pulse Retorno. La búsqueda revisada se ejecuta al confirmar el campo.
  3. Lea el remitente, la fecha y la vista previa. Elija un resultado para abrir su chat.

La búsqueda cubre el texto almacenado y los nombres de remitentes mediante un índice de palabras y prefijos. Devuelve como máximo las 100 coincidencias más recientes. No es una búsqueda ilimitada de fragmentos en cualquier posición: frases parciales, puntuación e idiomas sin espacios entre palabras pueden funcionar de forma distinta a la esperada. Pruebe una expresión distintiva más larga u otro término.

Elegir un resultado selecciona la conversación, no el mensaje exacto encontrado. Para un resultado antiguo, utilice su fecha como referencia y cargue páginas anteriores. La búsqueda no examina fotografías, grabaciones de voz, contenido de adjuntos ni texto dibujado en stickers. Un resultado vacío no demuestra que la conversación falte en la copia de origen.

Imágenes, adjuntos, stickers y reacciones

Reconocer un tipo de mensaje no equivale a conservar su adjunto. En 1.0.0, fotos, vídeos, audio, archivos, ubicaciones, contactos y stickers se representan mediante texto o etiquetas de tipo. La interfaz revisada no ofrece descarga general de adjuntos, visor de fotos ni reproductor de audio/vídeo.

Si su aplicación tiene la interfaz de 2.0

Para registros de stickers compatibles de iCloud, la aplicación lee sus identificadores y solicita un PNG a la CDN de stickers de LINE. Las imágenes cargadas correctamente se guardan en la caché local. Es una representación estática; no se garantizan animación, sonido, stickers no disponibles ni todos los formatos más recientes.

Las imágenes que ya están en caché se pueden reutilizar sin conexión; las que faltan requieren una solicitud de red correcta. Un marcador puede indicar metadatos ausentes, falta de conexión o una imagen no disponible en la CDN. Importar el historial no descarga previamente todos los stickers.

Los tipos de reacción compatibles pueden mostrarse como emojis y cantidades desde la base complementaria de iCloud. Estos indicadores no son un registro completo de quién reaccionó o cuándo. Ni los stickers ni las reacciones convierten ChatArchive en una copia completa de medios.

Dónde se almacena el archivo

El historial importado se guarda automáticamente en ~/Library/Application Support/ChatArchive/chatarchive.sqlite. La importación normal no solicita elegir la ubicación de la base. Esta puede tener archivos auxiliares -wal y -shm. Mantenga la carpeta completa al hacer una copia.

En 2.0, los PNG de stickers descargados se almacenan en ~/Library/Application Support/ChatArchive/StickerCache/. Las exportaciones se guardan donde elija en el diálogo; son copias independientes y no se actualizan al importar de nuevo.

La base local y las exportaciones de lectura no están protegidas por cifrado propio de ChatArchive ni una contraseña de la aplicación. Protéjalas mediante la cuenta del Mac, el cifrado del dispositivo y un destino apropiado para copias. Un archivo guardado en una carpeta sincronizada con la nube puede ser subido por ese servicio.

La base de la aplicación es una biblioteca de trabajo, no un paquete de restauración compatible con LINE. Las referencias históricas a .chatarchive o .linearchive no demuestran que exista un comando de importación/restauración en estas interfaces de Mac revisadas.

Guardar copias en texto en 1.0.0

Una conversación

Seleccione un chat y elija Save as Text encima de los mensajes. Indique el nombre y el destino. Esta operación no necesita una licencia de exportación activada y lee todos los mensajes importados de ese chat, incluidas las páginas antiguas aún no mostradas.

Todas las conversaciones

Elija Export All en la barra lateral. Se requiere una licencia activada. La interfaz revisada de 1.0.0 pide una carpeta de destino y escribe un archivo de texto por cada chat no vacío. En la interfaz de 2.0, la misma operación guarda chatarchive-export.tar.gz, que contiene archivos de texto por chat.

El texto exportado contiene fechas, horas, nombres de remitentes y el texto almacenado. No incorpora los archivos binarios adjuntos, las imágenes de stickers ni los indicadores de reacciones. Por ello, un mensaje no textual sin texto almacenado puede dejar poco contenido útil.

Revise las conversaciones importantes exportadas antes de confiar en ellas. Los nombres de chats se convierten en nombres de archivos: nombres idénticos, o que resulten idénticos tras sustituir caracteres prohibidos o acortar nombres largos, pueden entrar en conflicto. Guarde esos chats por separado con nombres de archivo distintos.

HTML y Markdown: solo con la interfaz de 2.0

Precaución con HTML: En la implementación revisada de 2.0, los fragmentos HTML del texto de las conversaciones pueden afectar al comportamiento de la página exportada. Use texto o Markdown hasta que se confirme una versión corregida. Los pasos siguientes describen la interfaz, no recomiendan abrir una exportación HTML de esta implementación.

Estos formatos existen en el código revisado de 2.0, no en la interfaz de la versión verificada 1.0.0. Si su aplicación tiene el botón Export Chat en la barra de herramientas, seleccione primero un chat, abra ese botón y elija formato y alcance.

Opciones de exportación de 2.0
OpciónLicenciaResultado
Chat seleccionado → HTMLNo requiere licencia activadaUn archivo HTML legible en un navegador
Todos los chats → HTMLRequiere licencia activadaUn archivo HTML con una lista de chats
Markdown (ZIP)Requiere licencia activadaTodos los chats en Markdown con archivos de stickers en caché

HTML utiliza All Chats por defecto. Para exportar un solo chat, elija explícitamente Selected Chat. Guarde el archivo y espere a que termine; la aplicación abre el resultado con el programa asociado.

HTML incorpora solo las imágenes de stickers que ya estén en caché. Si necesita esas imágenes, visualice correctamente los stickers pertinentes antes de exportar. Su campo de búsqueda filtra nombres de chats, no el cuerpo de todos los mensajes, y requiere JavaScript para mostrar las conversaciones.

Markdown ZIP incluye una carpeta attachments/stickers/ y referencias de imágenes al estilo de Obsidian. Los lectores generales de Markdown pueden requerir ajustes de rutas o sintaxis. Compruebe imágenes ausentes y archivos de chats con el mismo nombre. Ningún formato es una copia completa de preservación ni un archivo de importación para LINE. Conserve también la copia de la base de datos.

Comprar y activar una licencia de exportación

El código revisado permite leer, buscar y guardar un chat como texto sin activar la exportación. La exportación masiva de texto requiere activación. Las reglas de los formatos adicionales de 2.0 se indican arriba. La compra y la activación correcta son pasos separados.

  1. Consulte los detalles de compra y entrega en la página actual del producto.
  2. Abra Activate License en ChatArchive e introduzca la clave compatible proporcionada para el producto.
  3. Active con conexión a internet y compruebe el estado obtenido. Guarde el recibo de compra de forma privada.

Ambas versiones revisadas usan el servicio de licencias de Lemon Squeezy, aunque el enlace de compra posterior apunta a Gumroad. Un recibo de Gumroad por sí solo no demuestra la compatibilidad de la clave. Si no tiene clave o se rechaza, contacte con soporte con la referencia del pedido; no compre otra vez solo para intentar solucionar el problema.

License Management permite desactivar esta instalación para liberar su activación. No elimina conversaciones ni emite reembolsos. La desactivación requiere una respuesta correcta del servicio.

Almacenamiento local y actividad de red

Procesar los chats localmente no significa que la aplicación nunca se comunique. La implementación revisada contiene los siguientes comportamientos.

Cuándo puede producirse comunicación
OperaciónComportamiento
Lectura y búsqueda de chatsLas conversaciones almacenadas se procesan en el Mac; no se encontró un destino de subida de chats en las rutas revisadas.
Importación de iCloudmacOS puede descargar la copia de LINE desde iCloud. La Cuenta de Apple y la actividad de iCloud son gestionadas por los servicios de Apple.
Servicio de licenciasLa activación envía la clave y el nombre del ordenador Mac a Lemon Squeezy. La validación/desactivación envía la clave y el identificador de la instancia de activación.
Carga de stickers en 2.0Las solicitudes a la CDN de LINE identifican el sticker; el servidor recibe también datos normales de conexión, como la dirección IP.
Enlaces y archivos guardadosAbrir sitios web, comprar la aplicación o guardar en carpetas sincronizadas puede implicar otros servicios.

Una instalación activada puede validar su licencia al iniciarse después de 7 días desde la activación o la última validación correcta. En la implementación revisada, un fallo de red conserva el estado previo de activación; una respuesta de licencia inválida puede desactivar exportaciones de pago. Esto no promete una activación sin conexión permanente.

Las credenciales de licencia se guardan en el Llavero de macOS. La base de conversaciones es un archivo local separado. El texto ya importado se puede leer sin obtener otra vez la fuente, pero las primeras descargas de iCloud, la activación y los stickers de 2.0 aún no guardados pueden necesitar conexión.

Crear copias de seguridad y eliminar datos

Antes de otra importación o de cambiar de Mac

  1. Salga por completo de ChatArchive.
  2. En Finder, use Ir → Ir a la carpeta e introduzca ~/Library/Application Support/ChatArchive/.
  3. Copie toda la carpeta a un destino protegido e identificado por fecha. Incluya archivos auxiliares de la base y la caché de stickers.
  4. Conserve por separado exportaciones de lectura importantes y la copia original de la fuente. Compruebe que la copia existe antes de continuar.

Esto conserva los archivos locales; la interfaz revisada no tiene un asistente de restauración de base de datos compatible ni combinación de bibliotecas. Para migrar o recuperar, mantenga la copia original intacta y consulte con soporte la compatibilidad entre versiones. Puede ser necesario activar la licencia por separado en otro Mac.

Eliminar el historial local

La interfaz revisada no tiene un comando para eliminar chats individuales. Tras salir y hacer la copia necesaria, puede mover la carpeta ChatArchive de Application Support a la Papelera desde Finder. Cuando los archivos se eliminen realmente, se borrará la biblioteca local de trabajo; al iniciar de nuevo se creará una biblioteca vacía. Elimine exportaciones y copias de seguridad por separado si lo desea.

Eliminar solo la aplicación no necesariamente borra sus archivos de Application Support o la licencia del Llavero. Eliminar archivos de ChatArchive no borra las conversaciones originales de LINE ni la copia de iCloud. La Papelera, las copias del sistema y las copias en la nube tienen sus propias reglas de conservación; esto no es una función de borrado seguro.

Contacte con hakaruapps-contact@hakaru.net indicando versión/compilación de ChatArchive, versión de macOS, versión de LINE cuando proceda, ruta de importación, error exacto y pasos breves para reproducirlo. Indique si el problema ocurre antes o después de que termine la importación.

Empiece con una descripción en lugar de enviar una base de conversaciones, un ZIP de copia, una clave de licencia o capturas privadas. Si hacen falta ejemplos, elimine nombres, textos de conversaciones, rutas con información personal y credenciales. Este manual se elaboró revisando metadatos de distribución y código fuente; no es una prueba de importación real con todas las versiones actuales de LINE.
