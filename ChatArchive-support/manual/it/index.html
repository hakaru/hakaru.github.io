Prima di iniziare: versione e scopo

ChatArchive è un’app per Mac che conserva una copia leggibile delle conversazioni LINE. Importa la cronologia disponibile nel proprio database locale, mostra le conversazioni e cerca nel testo dei messaggi. Non ripristina conversazioni in LINE, non trasferisce account LINE, non invia messaggi e non recupera contenuti assenti dalla fonte.

Questa guida è stata verificata il 15 novembre 2026. Il download della versione controllata è 1.0.0 (build 1), che richiede macOS 14.0 o successivo. Sono stati esaminati i metadati dell’immagine disco e il codice corrispondente. L’attuale pagina Gumroad non specifica la versione del file consegnato; non è quindi stato accertato che quel download sia identico alla versione verificata.

Il codice separato della 2.0.0 (build 2) aggiunge funzioni descritte sotto soltanto dove indicato «Se l’app ha l’interfaccia 2.0». Un numero di versione di sviluppo non dimostra che tali funzioni siano comprese nell’acquisto. Controllare la versione installata con Ottieni informazioni nel Finder e seguire i comandi effettivamente presenti.

L’interfaccia dell’app comprende inglese, giapponese, cinese tradizionale e thailandese. Le lingue disponibili per questo manuale sono una cosa distinta. I riferimenti al codice descrivono la verifica del repository privato dello sviluppatore e non sono link pubblici per scaricarlo.

Installare e scegliere la fonte

  1. Ottenere ChatArchive dal canale ufficiale di acquisto/download. Se distribuito come DMG, aprirlo e copiare ChatArchive in Applicazioni prima di avviarlo.
  2. Lasciare sul Mac spazio sufficiente per database importato, estrazione temporanea ed esportazioni. Nessuna quantità fissa di spazio è sufficiente per qualsiasi cronologia.
  3. Scegliere tra il database locale di LINE per Mac e un backup iCloud compatibile di LINE per iPhone. Possono coprire periodi e quantità di messaggi diversi.
  4. Prima di sostituire una libreria ChatArchive esistente, seguire Backup e rimozione dei dati.

Per importare dal Mac, installare LINE per Mac, accedere da LINE e lasciarlo in esecuzione. Per iCloud, il backup pertinente deve essere accessibile tramite l’account iCloud Drive del Mac. ChatArchive non fornisce un proprio modulo di accesso a LINE o all’Account Apple.

L’app esaminata è solo per macOS. Non legge backup Android/Google Drive, normali backup iPhone creati dal Finder o ZIP arbitrari. La compatibilità con ogni futuro database o formato di backup LINE non è garantita.

Importare da LINE per Mac in 1.0.0

  1. Aprire LINE per Mac e completare l’accesso. Verificare l’account desiderato e lasciare LINE aperto.
  2. In Impostazioni di Sistema di macOS → Privacy e sicurezza → Strumenti per sviluppatori, autorizzare ChatArchive se richiesto. Il permesso riguarda l’accesso al processo LINE in esecuzione.
  3. In ChatArchive scegliere Import from LINE, poi Import from LINE for Mac.
  4. Attendere rilevamento, acquisizione della chiave, lettura del database e importazione. Evitare di cambiare account o chiudere LINE durante l’operazione.
  5. Controllare i conteggi finali, chiudere il pannello ed esaminare varie conversazioni e date.

L’app legge il database locale cifrato di LINE usando una chiave ottenuta dal processo attivo. La fonte viene aperta in sola lettura. Non richiede ai server LINE tutte le conversazioni storiche. Se esistono più database candidati, il rilevamento automatico dà priorità a uno più grande; non è presente un normale selettore di account.

Accesso completo al disco non sostituisce Strumenti per sviluppatori. Se accesso o decifratura falliscono dopo aver concesso il permesso documentato, contattare l’assistenza anziché disattivare le protezioni del sistema. Nell’interfaccia 2.0, l’importazione dal Mac è nascosta come funzione per sviluppatori. Usare lì il normale percorso iCloud.

Importare da un backup iCloud

Questo percorso è disponibile nell’interfaccia 1.0.0 esaminata ed è quello normale nell’interfaccia 2.0. Legge il file archive.zip specifico di LINE, non un backup iCloud dell’intero dispositivo.

  1. Verificare che LINE su iPhone abbia completato un Backup standard adatto. Seguire le istruzioni ufficiali di backup LINE per l’interfaccia attuale del telefono.
  2. Sul Mac usare l’Account Apple che può accedere al backup e attivare iCloud Drive. Lasciare tempo e connessione internet perché il file diventi disponibile.
  3. Scegliere Import from LINE → Import from iCloud Backup.
  4. Attendere download, estrazione e importazione. Verificare conteggi, nomi e date. Le interfacce successive mostrano anche Imported from.

Il rilevamento cerca in ~/Library/Mobile Documents/iCloud~com~linecorp~line/Data-*/Backup/archive.zip. Usa il primo backup corrispondente trovato, senza scegliere data o account; non promette di usare il più recente. LINE per Mac non deve essere aperto per questo percorso e il lettore iCloud non usa il permesso Strumenti per sviluppatori.

Quale cronologia viene inclusa

L’archivio riflette i record presenti nella fonte selezionata al momento dell’importazione. Un’importazione riuscita non prova che includa ogni conversazione mai scambiata dall’account. Messaggi già eliminati, cronologia precedente non disponibile e contenuti multimediali assenti dalla fonte non possono essere ricostruiti.

Il lettore iCloud gestisce chat dirette, chat con più persone, gruppi, account ufficiali e record Keep Memo quando sono presenti le tabelle previste. Se mancano informazioni sui contatti, i nomi possono essere sostituiti da identificatori o etichette generiche. Tipi di messaggio sconosciuti possono apparire come un numero di tipo.

Le copie Mac e iCloud sono fonti indipendenti. Il telefono può mostrare una cronologia mai salvata sul Mac. Importare l’altra fonte sostituisce la libreria ChatArchive corrente, senza unire i rispettivi periodi.

Conservare separatamente il backup originale se la completezza è importante. L’app legge campi selezionati, non tutte le tabelle o i metadati LINE. In particolare, l’estrazione delle reazioni in 2.0 non incorpora i file journal SQLite del backup, quindi la loro completezza non è assicurata.

Aggiornare una libreria esistente

Ogni importazione Mac/iCloud sostituisce l’intera libreria di contatti, chat e messaggi di ChatArchive. Vale per entrambe le versioni esaminate. Salvare una copia separata prima di importare una fonte più recente, precedente o diversa. Non esistono modalità di unione, download incrementale o sincronizzazione automatica pianificata.

  1. Eseguire il backup della libreria locale e salvare le copie di lettura necessarie.
  2. Confermare la fonte desiderata e il periodo del backup.
  3. Ripetere la stessa procedura di importazione.
  4. Confrontare date più vecchie e recenti, conversazioni importanti e conteggi finali con quanto atteso.

L’importazione avviene in una sola transazione del database: un errore del database durante quella transazione annulla le sue modifiche. È una protezione utile, ma non sostituisce il backup.

Reimportare una fonte non aggiunge intenzionalmente una seconda copia di ogni messaggio. Ricostruisce la libreria dalla fonte; eventuali duplicati già presenti lì possono comunque apparire. Una fonte più piccola può produrre una libreria ridotta e rimuovere cronologia prima visibile.

Leggere conversazioni e messaggi precedenti

La barra laterale sinistra contiene comandi di importazione, esportazione e licenza. La colonna centrale elenca le chat per data dell’ultimo messaggio. Selezionarne una per leggerla a destra. La ricerca nell’elenco filtra i nomi delle chat, non il corpo dei messaggi.

All’apertura vengono caricati gli ultimi 200 messaggi della conversazione. Usare Load older messages in alto per caricare pagine precedenti, fino a 200 messaggi per volta. Vedere solo un periodo recente non dimostra quindi che manchino messaggi importati più vecchi.

I messaggi sono raggruppati per data e distinguono i propri dagli altri mittenti. Il testo può essere selezionato e copiato. Nell’interfaccia 2.0, i link rilevati possono aprire il browser o l’app associata. Aprire un link è un’azione distinta dalla lettura dell’archivio locale.

Se una data sembra impossibile, conservare la fonte e comunicare versione e percorso di importazione. Il codice successivo a 1.0.0 modifica la conversione dei timestamp iCloud; controllare quindi le date della versione originale prima di fare affidamento su un’esportazione.

Cercare nel testo dei messaggi

  1. Fare clic sulla lente nella barra degli strumenti per aprire Full-Text Search.
  2. Inserire una o più parole e premere Invio. La ricerca esaminata viene eseguita quando si conferma il campo.
  3. Leggere mittente, data e anteprima. Selezionare un risultato per aprire la chat.

La ricerca comprende testo salvato e nomi dei mittenti, con un indice per parole/prefissi. Restituisce al massimo i 100 risultati più recenti. Non è una ricerca libera di sottostringhe: frasi parziali, punteggiatura e lingue senza spazi fra parole possono comportarsi diversamente dal previsto. Provare un’espressione distintiva più lunga o un altro termine.

Selezionare un risultato apre la conversazione, non il messaggio preciso. Per un risultato vecchio, usare la data come guida e caricare pagine precedenti. La ricerca non esamina foto, registrazioni vocali, contenuti degli allegati o testo disegnato negli sticker. Un risultato vuoto non prova che la conversazione manchi dal backup originale.

Foto, allegati, sticker e reazioni

Riconoscere un tipo di messaggio non equivale a conservarne l’allegato. In 1.0.0, foto, video, audio, file, posizioni, contatti e sticker sono rappresentati da testo o etichette di tipo. L’interfaccia esaminata non include download generico degli allegati, visualizzatore di foto o lettore audio/video.

Se l’app ha l’interfaccia 2.0

Per record sticker iCloud compatibili, l’app legge gli identificatori e richiede un PNG al CDN degli sticker LINE. Le immagini caricate vengono memorizzate localmente nella cache. È una rappresentazione statica: animazioni, suoni, sticker non più disponibili e tutti i nuovi formati non sono garantiti.

Le immagini già in cache possono essere riutilizzate offline; quelle mancanti richiedono una richiesta di rete riuscita. Un segnaposto può indicare metadati assenti, nessuna connessione o immagine CDN non disponibile. Importare la cronologia non scarica in anticipo tutti gli sticker.

Le reazioni supportate possono comparire come badge emoji e conteggi dal database supplementare iCloud. Non costituiscono un registro completo di chi ha reagito o quando. Né sticker né reazioni rendono ChatArchive un backup multimediale completo.

Formato e posizione dei dati

La cronologia importata viene salvata automaticamente in ~/Library/Application Support/ChatArchive/chatarchive.sqlite. L’importazione normale non chiede di scegliere la posizione del database. Possono esistere file associati -wal e -shm. Conservare insieme l’intera cartella nel backup.

In 2.0, i PNG degli sticker scaricati sono in ~/Library/Application Support/ChatArchive/StickerCache/. Le esportazioni vanno nella posizione scelta nella finestra di salvataggio: sono copie separate e non si aggiornano quando si importa di nuovo.

Database locale ed esportazioni di lettura non hanno cifratura specifica di ChatArchive né una password dell’app. Proteggerli con l’account Mac, la cifratura del dispositivo e una destinazione di backup adatta. Un file salvato in una cartella sincronizzata nel cloud può essere caricato da quel servizio.

Il database dell’app è una libreria di lavoro, non un pacchetto di ripristino compatibile con LINE. Vecchi riferimenti a .chatarchive o .linearchive non dimostrano che nelle interfacce Mac esaminate esista un comando di importazione/ripristino.

Esportare testo in 1.0.0

Una conversazione

Selezionare una chat e scegliere Save as Text sopra i messaggi. Specificare nome e destinazione. L’operazione non richiede una licenza di esportazione attivata e legge tutti i messaggi importati della chat, comprese le pagine precedenti non ancora visualizzate.

Tutte le conversazioni

Scegliere Export All nella barra laterale. Serve una licenza attivata. L’interfaccia 1.0.0 esaminata richiede una cartella di destinazione e scrive un file di testo per ogni chat non vuota. Nell’interfaccia 2.0 la stessa operazione salva invece chatarchive-export.tar.gz, con file di testo separati per chat.

Il testo esportato contiene date, orari, nomi dei mittenti e testo salvato. Non incorpora allegati binari, immagini degli sticker o badge di reazione. Un messaggio non testuale senza testo salvato può quindi lasciare ben poco contenuto utile.

Controllare le conversazioni importanti esportate prima di farvi affidamento. I nomi delle chat diventano nomi di file: nomi identici, oppure resi identici dalla sostituzione di caratteri vietati o dall’accorciamento, possono entrare in conflitto. Salvare separatamente tali chat con nomi diversi.

HTML e Markdown: solo con l’interfaccia 2.0

Avvertenza HTML: nell’implementazione 2.0 esaminata, frammenti HTML nel testo delle conversazioni possono influenzare il comportamento della pagina esportata. Usare testo o Markdown finché non sia stata confermata una versione corretta. I passaggi seguenti descrivono l’interfaccia e non consigliano di aprire un’esportazione HTML prodotta da questa implementazione.

Questi formati sono presenti nel codice 2.0 esaminato, non nell’interfaccia della versione 1.0.0 verificata. Se l’app ha il pulsante Export Chat nella barra degli strumenti, selezionare prima una chat, aprire il pulsante e scegliere formato e ambito.

Opzioni di esportazione in 2.0
SceltaLicenzaRisultato
Selected Chat → HTMLNon richiede una licenza attivataUn file HTML leggibile nel browser
All Chats → HTMLRichiede una licenza attivataUn file HTML con elenco delle chat
Markdown (ZIP)Richiede una licenza attivataTutte le chat in Markdown e gli sticker presenti nella cache

Per HTML, l’opzione iniziale è All Chats. Per una sola chat scegliere esplicitamente Selected Chat. Salvare e attendere: al termine l’app apre il risultato nell’applicazione associata.

HTML incorpora solo immagini sticker già presenti nella cache. Se servono, verificare che gli sticker pertinenti siano visualizzati correttamente prima di esportare. Il campo di ricerca filtra i nomi delle chat, non tutti i messaggi; per visualizzare le conversazioni è necessario JavaScript.

Il file Markdown ZIP include la cartella attachments/stickers/ e riferimenti alle immagini in stile Obsidian. Lettori Markdown generici possono richiedere modifiche a percorsi o sintassi. Controllare immagini mancanti e file di chat con lo stesso nome. Nessuno dei due formati è una copia completa di conservazione o un file da importare in LINE. Conservare anche il backup del database.

Acquisto e attivazione della licenza di esportazione

Nel codice esaminato, lettura, ricerca e salvataggio di una chat come testo sono disponibili senza attivazione per l’esportazione. L’esportazione di testo in blocco richiede attivazione. Le regole dei formati aggiuntivi 2.0 sono riportate sopra. Acquistare e completare l’attivazione sono passaggi distinti.

  1. Consultare la pagina attuale del prodotto per dettagli di acquisto e consegna.
  2. Aprire Activate License in ChatArchive e inserire la chiave compatibile fornita per il prodotto.
  3. Attivare online e controllare lo stato risultante. Conservare privatamente la ricevuta.

Entrambe le versioni esaminate usano il servizio licenze Lemon Squeezy, anche se il successivo link d’acquisto porta a Gumroad. La sola ricevuta Gumroad non dimostra la compatibilità della chiave. Se manca o viene rifiutata, contattare l’assistenza con il riferimento dell’ordine; non acquistare di nuovo soltanto per risolvere il problema.

License Management offre la disattivazione per liberare l’attivazione di questa installazione. Non elimina conversazioni e non emette rimborsi. La disattivazione richiede una risposta positiva del servizio.

Dati locali e comunicazioni di rete

Elaborare le chat localmente non significa che l’app non comunichi mai. Nell’implementazione esaminata sono presenti i seguenti comportamenti.

Quando può avvenire una comunicazione
OperazioneComportamento
Lettura e ricerca nelle chatLe conversazioni salvate sono elaborate sul Mac; nei percorsi esaminati non è stato trovato un endpoint per caricare le chat.
Importazione iCloudmacOS può scaricare il backup LINE da iCloud. Account Apple e attività iCloud sono gestiti dai servizi Apple.
Servizio licenzeL’attivazione invia a Lemon Squeezy la chiave di licenza e il nome del computer Mac. Verifica e disattivazione inviano chiave e identificatore dell’istanza attivata.
Caricamento sticker in 2.0Le richieste al CDN di LINE identificano lo sticker; il server riceve anche normali informazioni di connessione, come l’indirizzo IP.
Link e file salvatiAprire siti, acquistare l’app o salvare in cartelle sincronizzate può coinvolgere altri servizi.

Un’installazione attivata può verificare la licenza all’avvio dopo 7 giorni dall’attivazione o dall’ultima verifica riuscita. Nel codice esaminato, un errore di rete mantiene lo stato precedente; una risposta di licenza non valida può disabilitare le esportazioni a pagamento. Non interpretare questo comportamento come una promessa di attivazione offline permanente.

Le credenziali di licenza sono conservate nel Portachiavi macOS. Il database delle conversazioni è un file locale separato. Il testo già importato è leggibile senza recuperare di nuovo la fonte, ma il primo download iCloud, l’attivazione e gli sticker 2.0 non in cache possono richiedere una connessione.

Backup e rimozione dei dati

Prima di importare di nuovo o cambiare Mac

  1. Chiudere completamente ChatArchive.
  2. Nel Finder scegliere Vai → Vai alla cartella e inserire ~/Library/Application Support/ChatArchive/.
  3. Copiare tutta la cartella in una posizione di backup protetta e contrassegnata con la data. Includere i file associati al database e la cache degli sticker.
  4. Conservare separatamente le esportazioni importanti e il backup originale. Verificare che la copia esista prima di procedere.

Questo conserva i file locali; l’interfaccia esaminata non offre una procedura supportata di ripristino del database o unione di librerie. Per migrazione o recupero, lasciare intatta la copia originale e chiedere all’assistenza la compatibilità delle versioni. Su un altro Mac potrebbe essere necessario attivare separatamente la licenza.

Rimuovere la cronologia locale

L’interfaccia esaminata non ha un comando di eliminazione per singola chat. Dopo aver chiuso l’app ed eseguito il backup necessario, si può spostare nel Cestino dal Finder la cartella ChatArchive in Application Support. Quando i file vengono effettivamente eliminati, si rimuove la libreria di lavoro locale; un avvio successivo crea una libreria vuota. Rimuovere separatamente esportazioni e copie di backup, se desiderato.

Eliminare solo l’app non elimina necessariamente i file in Application Support o la licenza nel Portachiavi. Rimuovere i file ChatArchive non elimina le conversazioni originali LINE né il backup iCloud. Cestino, backup di sistema e copie cloud hanno politiche proprie di conservazione; questa non è una funzione di cancellazione sicura.

Contattare hakaruapps-contact@hakaru.net indicando versione/build ChatArchive, versione macOS e, se pertinente, LINE, percorso d’importazione, errore esatto e brevi passi per riprodurlo. Specificare se accade prima o dopo il completamento dell’importazione.

Iniziare con una descrizione, senza inviare database delle conversazioni, ZIP di backup, chiavi di licenza o schermate private. Se servono esempi, rimuovere nomi, testo delle conversazioni, percorsi con dati personali e credenziali. Il manuale deriva dalla verifica dei metadati di distribuzione e del codice; non è una prova di importazione dal vivo con ogni versione attuale di LINE.
