App Store Review Monitor

A GitHub Action that watches your App Store review status and notifies you the moment something changes.

GitHub Action Open Source Free

The Problem

Before

Manually refreshing App Store Connect every few hours to check review status. Missing rejections for hours or days.

After

Automated monitoring every 3 hours. Instant notifications on Slack, Discord, Teams, or GitHub Issues.

Quick Start

Get up and running in 3 steps:

1. Create an API Key

Go to App Store Connect > Users and Access > Integrations and generate a Team Key. Download the .p8 file.

2. Add Secrets

Terminal
gh secret set ASC_KEY_ID --body "YOUR_KEY_ID" gh secret set ASC_ISSUER_ID --body "YOUR_ISSUER_ID" gh secret set ASC_PRIVATE_KEY < AuthKey_XXXXXXXX.p8 gh secret set APP_STORE_APP_ID --body "YOUR_APP_ID"

3. Add Workflow

.github/workflows/review-monitor.yml
name: App Store Review Monitor on: schedule: - cron: '0 */3 * * *' workflow_dispatch: {} jobs: check: runs-on: ubuntu-latest permissions: issues: write steps: - uses: hakaru/appstore-review-monitor@v1 with: app-id: ${{ secrets.APP_STORE_APP_ID }} asc-key-id: ${{ secrets.ASC_KEY_ID }} asc-issuer-id: ${{ secrets.ASC_ISSUER_ID }} asc-private-key: ${{ secrets.ASC_PRIVATE_KEY }} slack-webhook-url: ${{ secrets.SLACK_WEBHOOK }} # optional discord-webhook-url: ${{ secrets.DISCORD_WEBHOOK }} # optional teams-webhook-url: ${{ secrets.TEAMS_WEBHOOK }} # optional
