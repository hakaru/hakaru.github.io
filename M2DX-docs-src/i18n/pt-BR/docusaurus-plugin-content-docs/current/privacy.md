Sintetizador FM compatível com DX7 e MIDI 2.0

## Política de Privacidade

**Última atualização: 26 de abril de 2026**

## Introdução

O M2DX ("o aplicativo") leva a privacidade dos seus usuários a sério. Esta Política de Privacidade explica como as informações são tratadas durante o uso do aplicativo para iOS / iPadOS.

## Visão geral

Para melhorar a estabilidade do app, o M2DX coleta dados de diagnóstico anônimos somente quando ocorre uma falha. Nenhum dado musical, conteúdo de execução ou entrada de MIDI é enviado para servidores externos.

## Dados coletados

O M2DX usa o Firebase Crashlytics, fornecido pelo Google, para coletar dados de diagnóstico anônimos somente em caso de falha. Isso permite identificar e corrigir problemas com agilidade.

### Dados de falha (Firebase Crashlytics)

Quando o app trava, as seguintes informações são coletadas automaticamente:

* Modelo do dispositivo e versão do iOS / iPadOS
* Versão do app e número da build
* Log da falha e stack trace
* Uso de memória e armazenamento no momento da falha

### Resumo da coleta de dados

| Tipo de dado | Finalidade | Vinculado ao usuário |
| --- | --- | --- |
| Dados de falha | Correção de bugs | Não |
| Modelo do dispositivo | Correção de bugs | Não |
| Versão do SO | Correção de bugs | Não |

## Dados que NÃO coletamos

* Informações pessoais (nome, e-mail, localização, contatos, fotos)
* Conteúdo musical, de áudio ou MIDI
* Dados de execução ou conteúdo de presets
* Identificador de publicidade (IDFA)
* Dados para fins publicitários
* Dados vendidos a terceiros

## Rastreamento e publicidade

**Não fazemos rastreamento para fins publicitários.** O M2DX:

* Não usa o identificador de publicidade (IDFA)
* Não compartilha dados com anunciantes
* Não rastreia o usuário entre apps ou sites
* Não exige a permissão de App Tracking Transparency

## Serviços de terceiros

O M2DX utiliza os seguintes serviços de terceiros:

* **Firebase Crashlytics** — relatório de falhas e diagnóstico (Google)

Para mais informações, consulte:

* [Política de Privacidade do Firebase](https://firebase.google.com/support/privacy)

## Retenção de dados

Os dados de falha são retidos de acordo com a política de retenção padrão do Firebase. Esses dados são anônimos e não podem ser usados para identificar o usuário.

## Privacidade de crianças

O aplicativo não coleta intencionalmente informações pessoais de crianças menores de 13 anos. Os dados de diagnóstico anônimos coletados não são vinculados a usuários individuais.

## Alterações na política

Esta Política de Privacidade pode ser atualizada de tempos em tempos. Em caso de alterações, a nova versão será publicada nesta página e a "Última atualização" será revisada.
