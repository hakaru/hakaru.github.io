MIDI 2.0 지원 DX7 호환 FM 신디사이저

## 개인정보 처리방침

**최종 업데이트: 2026년 4월 26일**

## 들어가며

M2DX('당사 앱')는 사용자의 개인정보 보호를 중요하게 여깁니다. 본 개인정보 처리방침은 iOS / iPadOS 앱을 사용하실 때 정보를 어떻게 취급하는지 안내합니다.

## 개요

M2DX는 앱의 안정성을 높이기 위해 크래시가 발생한 경우에 한해 익명의 진단 데이터를 수집합니다. 음악 데이터, 연주 내용, MIDI 입력이 외부 서버로 전송되는 일은 없습니다.

## 수집하는 데이터

M2DX는 Google이 제공하는 Firebase Crashlytics를 사용하여, 크래시가 발생한 경우에 한해 익명의 진단 데이터를 수집합니다. 이를 통해 앱의 결함을 신속하게 파악하고 수정할 수 있습니다.

### 크래시 데이터 (Firebase Crashlytics)

앱이 크래시되었을 때 다음 항목이 자동으로 수집됩니다.

* 기기 종류 및 iOS / iPadOS 버전
* 앱 버전 및 빌드 번호
* 크래시 로그 및 스택 트레이스
* 크래시 발생 시점의 메모리 및 저장 공간 사용량

### 데이터 수집 요약

| 데이터 종류 | 목적 | 개인 식별 연결 |
| --- | --- | --- |
| 크래시 데이터 | 결함 수정 | 없음 |
| 기기 모델 | 결함 수정 | 없음 |
| OS 버전 | 결함 수정 | 없음 |

## 수집하지 않는 데이터

* 개인 정보 (이름, 이메일 주소, 위치 정보, 연락처, 사진)
* 음악, 음성, MIDI 콘텐츠
* 연주 데이터 및 프리셋 내용
* 광고 식별자 (IDFA)
* 광고 목적의 데이터
* 제삼자에게 판매되는 데이터

## 트래킹 및 광고

**광고 목적의 트래킹은 일절 수행하지 않습니다.** M2DX는

* 광고 식별자 (IDFA)를 사용하지 않습니다
* 광고주와 데이터를 공유하지 않습니다
* 다른 앱이나 웹사이트를 넘나들며 트래킹하지 않습니다
* App Tracking Transparency 권한을 요구하지 않습니다

## 제삼자 서비스

M2DX는 다음 제삼자 서비스를 사용합니다.

* **Firebase Crashlytics** — 크래시 리포트 및 진단 (Google)

자세한 내용은 아래 문서를 참고해 주세요.

* [Firebase 개인정보 처리방침](https://firebase.google.com/support/privacy)

## 데이터 보관

크래시 데이터는 Firebase의 표준 보관 정책에 따라 보관됩니다. 이 데이터는 익명이며, 특정 개인을 식별하는 용도로 사용할 수 없습니다.

## 아동 개인정보 보호

당사 앱은 만 13세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다. 수집되는 익명 진단 데이터는 특정 사용자 개인과 연결되지 않습니다.

## 처리방침 변경
