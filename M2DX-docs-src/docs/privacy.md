MIDI 2.0 + DX7-compatible FM Synthesizer

## Privacy Policy

**Last updated: April 26, 2026**

## Introduction

M2DX ("the App") is committed to protecting your privacy. This privacy policy explains how we handle information when you use our iOS / iPadOS application.

## Overview

M2DX collects anonymous diagnostic data only when the app crashes, in order to improve stability. No music data, performance content, or MIDI input is ever sent to external servers.

## Data We Collect

M2DX uses Firebase Crashlytics, provided by Google, to collect anonymous diagnostic data only at the moment of a crash. This lets us identify and fix bugs quickly.

### Crash Data (Firebase Crashlytics)

When the app crashes, the following is collected automatically:

* Device model and iOS / iPadOS version
* App version and build number
* Crash logs and stack traces
* Memory and storage usage at the time of the crash

### Summary of Data Collection

| Data Type | Purpose | Linked to Identity |
| --- | --- | --- |
| Crash data | Bug fixes | No |
| Device model | Bug fixes | No |
| OS version | Bug fixes | No |

## Data We Do Not Collect

* Personal information (name, email, location, contacts, photos)
* Music, audio, or MIDI content
* Performance data or preset content
* Advertising identifier (IDFA)
* Data for advertising purposes
* Data sold to third parties

## Tracking and Advertising

**We do not track you for advertising purposes.** M2DX:

* Does not use the advertising identifier (IDFA)
* Does not share data with advertisers
* Does not track across other apps or websites
* Does not require App Tracking Transparency permission

## Third-Party Services

M2DX uses the following third-party services:

* **Firebase Crashlytics** — crash reporting and diagnostics (Google)

For more information, please see:

* [Firebase Privacy Policy](https://firebase.google.com/support/privacy)

## Data Retention

Crash data is retained according to Firebase's standard retention policy. The data is anonymous and cannot be used to identify any individual.

## Children's Privacy

The App does not knowingly collect personal information from children under 13. The anonymous diagnostic data we collect cannot be tied to any specific user.

## Changes to This Policy

We may update this privacy policy from time to time. Any changes will be reflected on this page along with an updated "Last updated" date.
