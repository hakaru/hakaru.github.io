GitInflow

GitHub Issue Kanban-Client für iOS

Datenschutzrichtlinie

Zuletzt aktualisiert:

GitInflow wird von hakaru entwickelt. Diese Datenschutzrichtlinie erklärt, wie wir mit Ihren Daten umgehen.

Daten, auf die wir zugreifen

GitHub-Kontodaten

  • Die App greift über OAuth-Authentifizierung mit dem repo-Scope auf Ihr GitHub-Konto zu
  • Dies bietet Lese-/Schreibzugriff auf Ihre Repositories, Issues, Labels, Meilensteine und Kommentare
  • Authentifizierungstoken werden sicher im iOS Keychain gespeichert
  • Der Token-Austausch erfolgt über einen sicheren serverseitigen Proxy (Cloudflare Workers)

Auf Ihrem Gerät gespeicherte Daten

  • OAuth-Token: Im iOS Keychain gespeichert (verschlüsselt, hardwaregeschützt)
  • Repository-Einstellungen: Ausgewählte Repositories in UserDefaults gespeichert
  • Issue-Cache: Temporärer Cache der Issue-Daten für Anzeigezwecke

Daten, die wir NICHT erfassen

  • Wir erfassen, speichern oder übertragen Ihre persönlichen Daten nicht an einen Server
  • Wir verwenden keine Analyse- oder Tracking-Dienste
  • Wir verwenden keine Werbung oder Werbe-Tracking (kein IDFA)
  • Wir greifen nicht für andere Zwecke als die Anzeige in der App auf Ihre GitHub-Daten zu

Drittanbieterdienste

  • GitHub API: Die App kommuniziert direkt mit der GitHub REST API. GitHubs Datenschutzrichtlinie gilt für auf GitHub gespeicherte Daten.
  • Cloudflare Workers: Nur für OAuth-Token-Austausch verwendet. Keine Benutzerdaten werden gespeichert oder protokolliert.

Datenweitergabe

Wir teilen Ihre Daten nicht mit Dritten.

Datenlöschung

  • Sie können den App-Zugriff jederzeit unter GitHub-Einstellungen > Anwendungen widerrufen
  • Die Deinstallation der App entfernt alle lokal gespeicherten Daten einschließlich des OAuth-Tokens
  • Sie können sich im Einstellungs-Tab der App abmelden, um das gespeicherte Token zu löschen

Datenschutz für Kinder

Die App richtet sich nicht an Kinder unter 13 Jahren.

Kontakt

Bei Fragen zu dieser Datenschutzrichtlinie:

  • Email: gitinflow@hakaru.net

Änderungen

Wir können diese Datenschutzrichtlinie von Zeit zu Zeit aktualisieren. Änderungen werden auf dieser Seite mit einem aktualisierten Datum veröffentlicht.
