GitInflow

GitHub Issue Kanban-klient för iOS

Ladda ner på
App Store

Välkommen till GitInflow supportsida.

GitInflow är en iOS kanban-klient för att hantera GitHub Issues. Hantera dina uppgifter över flera repositories med ett kanban-arbetsflöde.

Funktioner

  • Kanban-tavla — Statusflikar Backlog / Ready / In Progress / Done
  • Multi-repository — Välj upp till 5 repos och visa alla issues
  • Snabb triage — Svep för att ändra status, lägga till etiketter, milstolpar och kommentarer
  • Smart delningsblad — Skapa issues från vilken app som helst
  • Pull Requests — Dedikerad PR-flik
  • Widget — Startskärmswidget med issue-räknare
  • Lokala notiser — Få notiser om nya issues

Användarmanual

Den fullständiga manualen täcker alla funktioner i detalj — komma igång, kanban-arbetsflöde, svepåtgärder, Share Extension, widget-inställning med mera.

Vanliga frågor

Hur många repositories kan jag välja?

Upp till 5 repositories åt gången. Gå till Inställningar och tryck på repositories för att välja dem.

Vad händer med en GitHub issue när jag flyttar den till Done?

GitInflow lägger till etiketten status:done och stänger issuen på GitHub. Att flytta tillbaka den till valfri annan status öppnar den igen.

Kan jag använda GitInflow med privata repositories?

Ja. Privata repositories visas i Inställningar bredvid offentliga repos, så länge de auktoriserades vid inloggningen.

Share Extension visas inte i delningsbladet. Vad ska jag göra?

Tryck på Mer i delningsbladet, hitta "GitInflow Share" i listan och aktivera det.

Varför uppdateras inte min widget?

iOS styr widget-uppdateringsschemat. Öppna GitInflow en gång för att utlösa en datauppdatering — widgeten uppdateras strax efteråt.

Jag flyttade av misstag en issue till Done. Hur ångrar jag det?

På fliken Done, svep kortet åt höger och tryck på Retreat, eller håll in kortet och välj en status från snabbmenyn. Detta öppnar issuen igen på GitHub.
