GitInflow

GitHub Issue Kanban-klient för iOS

Integritetspolicy

Senast uppdaterad:

GitInflow utvecklas av hakaru. Denna integritetspolicy förklarar hur vi hanterar dina uppgifter.

Data vi har tillgång till

GitHub-kontodata

  • Appen kommer åt ditt GitHub-konto via OAuth-autentisering med repo-omfånget
  • Detta ger läs-/skrivåtkomst till dina repositories, issues, etiketter, milstolpar och kommentarer
  • Autentiseringstoken lagras säkert i iOS Keychain
  • Tokenutbyte sker via en säker server-side-proxy (Cloudflare Workers)

Data lagrad på din enhet

  • OAuth-token: Lagrad i iOS Keychain (krypterad, hårdvaruskyddad)
  • Repository-inställningar: Valda repositories lagrade i UserDefaults
  • Issue-cache: Temporär cache av issue-data för visningsändamål

Data vi INTE samlar in

  • Vi samlar inte in, lagrar eller överför dina personuppgifter till någon server
  • Vi använder inga analys- eller spårningstjänster
  • Vi använder ingen reklam eller reklamspårning (ingen IDFA)
  • Vi har inte tillgång till dina GitHub-data för andra ändamål än att visa dem i appen

Tredjepartstjänster

  • GitHub API: Appen kommunicerar direkt med GitHubs REST API. GitHubs integritetspolicy gäller för data lagrad på GitHub.
  • Cloudflare Workers: Används enbart för OAuth-tokenutbyte. Inga användardata lagras eller loggas.

Datadelning

Vi delar inte dina uppgifter med tredje part.

Radering av data

  • Du kan återkalla appens åtkomst till ditt GitHub-konto när som helst från GitHub-inställningar > Applikationer
  • Avinstallation av appen tar bort alla lokalt lagrade data inklusive OAuth-token
  • Du kan logga ut från appens inställningsflik för att radera det lagrade token

Barns integritet

Appen riktar sig inte till barn under 13 år.

Kontakt

Om du har frågor om denna integritetspolicy:

  • Email: gitinflow@hakaru.net

Ändringar

Vi kan uppdatera denna integritetspolicy från tid till annan. Ändringar publiceras på denna sida med ett uppdaterat datum.
