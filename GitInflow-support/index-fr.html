Bienvenue sur la page d'assistance de GitInflow.

GitInflow est un client iOS de gestion Kanban des GitHub Issues. Gérez vos tâches sur plusieurs dépôts avec un workflow de type kanban.

Fonctionnalités

  • Tableau Kanban — Onglets Backlog / Ready / In Progress / Done
  • Multi-dépôts — Sélectionnez jusqu'à 5 dépôts et affichez toutes les issues
  • Triage rapide — Glissez pour changer le statut, ajouter des labels, jalons et commentaires
  • Feuille de partage intelligente — Créez des issues depuis n'importe quelle app
  • Pull Requests — Onglet PR dédié
  • Widget — Widget d'écran d'accueil affichant les compteurs d'issues
  • Notifications locales — Soyez notifié des nouvelles issues

FAQ

Combien de dépôts puis-je sélectionner ?

Jusqu'à 5 dépôts à la fois. Allez dans Paramètres et appuyez sur les dépôts pour les sélectionner.

Que se passe-t-il quand je déplace une issue dans Done ?

GitInflow ajoute le label status:done et ferme l'issue sur GitHub. La déplacer vers un autre statut la réouvre.

Puis-je utiliser GitInflow avec des dépôts privés ?

Oui. Les dépôts privés apparaissent dans les Paramètres aux côtés des dépôts publics, à condition qu'ils aient été autorisés lors de la connexion.

La Share Extension n'apparaît pas dans la feuille de partage. Que faire ?

Appuyez sur Plus dans la feuille de partage, trouvez "GitInflow Share" dans la liste et activez-le.

Pourquoi mon widget ne se met-il pas à jour ?

iOS contrôle la planification de rafraîchissement des widgets. Ouvrez GitInflow une fois pour déclencher une actualisation — le widget se mettra à jour peu après.

J'ai accidentellement fermé une issue en la déplaçant dans Done. Comment annuler ?

Dans l'onglet Done, glissez la carte vers la droite et appuyez sur Retreat, ou appuyez longuement sur la carte et choisissez un statut dans le menu contextuel. Cela réouvre l'issue sur GitHub.
