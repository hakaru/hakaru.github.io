GitInflow

iOS용 GitHub Issue 칸반 클라이언트

다운로드
App Store

GitInflow 지원 페이지에 오신 것을 환영합니다.

GitInflow는 GitHub Issue를 칸반 방식으로 관리하는 iOS 클라이언트 앱입니다. 여러 리포지토리의 작업을 칸반 스타일 워크플로우로 관리하세요.

주요 기능

  • 칸반 보드 — Backlog / Ready / In Progress / Done 상태 탭
  • 멀티 리포지토리 — 최대 5개 리포지토리를 선택하고 모든 이슈를 통합 조회
  • 빠른 트리아지 — 스와이프로 상태 변경, 레이블, 마일스톤, 댓글 추가
  • 스마트 공유 시트 — 어떤 앱에서도 Share Extension으로 이슈 생성
  • Pull Requests — PR 전용 탭
  • 위젯 — 홈 화면에 이슈 수 표시
  • 로컬 알림 — 새 이슈 알림

사용자 매뉴얼

전체 매뉴얼에서 모든 기능을 자세히 설명합니다 — 시작하기, 칸반 워크플로우, 스와이프 액션, Share Extension, 위젯 설정 등.

자주 묻는 질문(FAQ)

리포지토리를 몇 개까지 선택할 수 있나요?

한 번에 최대 5개까지 선택할 수 있습니다. 설정으로 이동하여 리포지토리를 탭해 선택하세요.

이슈를 Done으로 이동하면 GitHub에서는 어떻게 되나요?

GitInflow가 status:done 레이블을 추가하고 GitHub의 이슈를 닫습니다. 다른 상태로 다시 이동하면 이슈가 다시 열립니다.

비공개 리포지토리에서도 사용할 수 있나요?

네. 로그인 시 승인된 리포지토리라면 비공개 리포지토리도 설정 화면에 표시됩니다.

Share Extension이 공유 시트에 표시되지 않습니다. 어떻게 해야 하나요?

공유 시트에서 더 보기를 탭하고, 목록에서 "GitInflow Share"를 찾아 활성화하세요.

위젯이 업데이트되지 않는 이유는 무엇인가요?

iOS가 위젯 새로고침 일정을 제어합니다. GitInflow를 한 번 열면 데이터 새로고침이 트리거되고 위젯이 곧 업데이트됩니다.

실수로 이슈를 Done으로 옮겼습니다. 어떻게 되돌리나요?

Done 탭에서 카드를 오른쪽으로 스와이프하고 Retreat을 탭하거나, 카드를 길게 눌러 컨텍스트 메뉴에서 상태를 선택하세요. 그러면 GitHub의 이슈가 다시 열립니다.
