iOS용 GitHub Issue 칸반 클라이언트

개인정보 처리방침

최종 업데이트:

GitInflow는 hakaru가 개발했습니다. 본 개인정보 처리방침은 귀하의 데이터 처리 방식을 설명합니다.

액세스하는 데이터

GitHub 계정 데이터

  • 앱은 repo 범위로 OAuth 인증을 통해 귀하의 GitHub 계정에 액세스합니다
  • 이를 통해 저장소, 이슈, 레이블, 마일스톤 및 댓글에 대한 읽기/쓰기 액세스가 제공됩니다
  • 인증 토큰은 iOS Keychain에 안전하게 저장됩니다
  • 토큰 교환은 보안 서버 측 프록시(Cloudflare Workers)를 통해 수행됩니다

기기에 저장된 데이터

  • OAuth 토큰: iOS Keychain에 저장(암호화, 하드웨어 보호)
  • 저장소 기본 설정: 선택한 저장소가 UserDefaults에 저장됨
  • 이슈 캐시: 표시 목적의 임시 이슈 데이터 캐시

수집하지 않는 데이터

  • 개인 데이터를 어떤 서버에도 수집, 저장 또는 전송하지 않습니다
  • 분석 또는 추적 서비스를 사용하지 않습니다
  • 광고 또는 광고 추적(IDFA 없음)을 사용하지 않습니다
  • 앱 내 표시 이외의 목적으로 GitHub 데이터에 액세스하지 않습니다

제3자 서비스

  • GitHub API: 앱은 GitHub REST API와 직접 통신합니다. GitHub에 저장된 데이터에는 GitHub의 개인정보 처리방침이 적용됩니다.
  • Cloudflare Workers: OAuth 토큰 교환에만 사용됩니다. 사용자 데이터는 저장되거나 기록되지 않습니다.

데이터 공유

제3자와 데이터를 공유하지 않습니다.

데이터 삭제

  • GitHub 설정 > 애플리케이션에서 언제든지 앱의 GitHub 액세스를 취소할 수 있습니다
  • 앱을 제거하면 OAuth 토큰을 포함한 모든 로컬 데이터가 삭제됩니다
  • 앱의 설정 탭에서 로그아웃하여 저장된 토큰을 삭제할 수 있습니다

아동 개인정보 보호

앱은 13세 미만 어린이를 대상으로 하지 않습니다.

연락처
