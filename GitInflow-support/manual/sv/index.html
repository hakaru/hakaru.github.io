GitInflow

GitHub Issues Kanban-klient för iOS

GitInflow Användarmanual

GitInflow är en GitHub Issues kanban-klient för iOS. Denna manual täcker alla funktioner i detalj.

Kom igång

Logga in

  1. Starta GitInflow.
  2. Tryck på "Logga in med GitHub" på inloggningsskärmen.
  3. Autentisera i webbläsaren eller via GitHub-appen. GitInflow använder OAuth och lagrar aldrig ditt lösenord.

Välj repositorier

  1. Gå till fliken Inställningar (kugghjulsikon) efter inloggning.
  2. Tryck på repositorier för att välja dem.
  3. Du kan välja upp till 5 repositorier åt gången.

Kanban-flikar

GitInflow organiserar ärenden i fyra statuskolumner:

FlikBeskrivningGitHub-etikett
BacklogÄrenden utan statusetikett — inkorg för nytt arbete(ingen etikett)
ReadyTriagerade ärenden redo att startastatus:ready
In ProgressAktivt bearbetade ärendenstatus:inProgress
DoneSlutförda ärenden — stängs automatiskt på GitHubstatus:done

Ändra status

Svep åt vänster — Lägg till / Framåt

  • Etikett — Öppna etikettväljare
  • Milstolpe — Öppna milstolpeväljare
  • Framåt — Flytta ärendet till nästa status

Svep åt höger — Bakåt / Kommentera

  • Bakåt — Flytta ärendet till föregående status
  • Kommentera — Öppna kommentarsark

Snabbmeny (långtryckning)

Håll in ett ärendekort för att öppna en snabbmeny med alla tillgängliga statusalternativ.

Sök

Varje kanban-flik har ett sökfält längst upp för realtidsfiltrering med nyckelord.

Repositoryfilter

Med två eller fler repositorier valda visas en rad filterchips under flikraden.

Skapa ärenden

  1. Navigera till en kanban-flik och tryck på +.
  2. Ange en titel (obligatorisk) och valfri brödtext.
  3. Tryck på Skicka för att skapa ärendet på GitHub.

Ärendedetaljer

Tryck på ett ärendekort för att se: titel, statusbricka, etiketter, milstolpe, brödtext, kommentarer och statusknappar.

Etiketter & Milstolpar

  1. Svep ett ärendekort åt vänster och tryck på Etikett eller Milstolpe.
  2. Välj i väljaren och tryck på Klar.
Obs: Skapa etiketter och milstolpar på GitHub.com först.

Kommentarer

  1. Svep ett ärendekort åt höger och tryck på Kommentera.
  2. Skriv din kommentar och tryck på Publicera.

Delningstillägg

Skapa eller uppdatera GitHub Issues från vilken app som helst. Tryck på Dela → GitInflow Share.

Pull Requests-flik

Tryck på fliken PRs för att se alla öppna pull requests. PR:er är skrivskyddade i GitInflow.

Widget

GitInflow erbjuder en hemskärmswidget (liten: In Progress-ärenden; medium: alla fyra statusar).

Aviseringar

GitInflow kan skicka lokala aviseringar när nya ärenden visas i dina valda repositorier.

Inställningar

Öppna fliken Inställningar för att hantera repositorier, ange standard och logga ut.

Felhantering

Om GitInflow inte kan läsa in ärenden visas en röd felbanner. Tryck på Försök igen.

Vanliga frågor

Hur många repositorier kan jag välja?

Upp till 5 åt gången.

Vad gör "Done"-statusen på GitHub?

GitInflow lägger till etiketten status:done och stänger ärendet på GitHub.

Kan jag använda GitInflow med privata repositorier?

Ja. GitInflow använder din GitHub OAuth-token med tillgång till alla auktoriserade repositorier.
