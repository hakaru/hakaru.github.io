GitInflow 使用手冊

GitInflow 是 iOS 的 GitHub Issues 看板客戶端。本手冊詳細介紹所有功能。

快速開始

登入

  1. 啟動 GitInflow。
  2. 在登入畫面點選 「以 GitHub 登入」。
  3. 在瀏覽器或 GitHub 應用程式中驗證身分。GitInflow 使用 OAuth，永不儲存您的密碼。

選擇儲存庫

  1. 登入後，前往 設定 分頁（齒輪圖示）。
  2. 點選儲存庫以選取。已選取的儲存庫會有勾選標記。
  3. 可同時選取 最多 5 個儲存庫。

設定預設儲存庫

在設定分頁中，點選儲存庫旁的 星形圖示 將其設為預設。

看板分頁

GitInflow 將 issue 整理為四個狀態欄：

分頁說明GitHub 標籤
Backlog無狀態標籤的 issue — 新工作收件匣（無標籤）
Ready已分類並準備開始的 issuestatus:ready
In Progress正在積極處理的 issuestatus:inProgress
Done已完成的 issue — 在 GitHub 上自動關閉status:done

變更狀態

向左滑動 — 新增 / 前進

  • 標籤 — 開啟標籤選擇器
  • 里程碑 — 開啟里程碑選擇器
  • 前進 — 將 issue 移至下一個狀態（例：Backlog → Ready → In Progress → Done）

向右滑動 — 後退 / 評論

  • 後退 — 將 issue 移至上一個狀態
  • 評論 — 開啟評論表

情境選單（長按）

長按任何 issue 卡片以開啟包含所有狀態選項的情境選單。

搜尋

每個看板分頁頂部都有 搜尋列。點選以即時依關鍵字篩選目前分頁的 issue。

儲存庫篩選器

選取 兩個或更多儲存庫 時，分頁列下方會出現一排 篩選器晶片。

建立 Issue

  1. 前往任意看板分頁並點選 +。
  2. 輸入 標題（必填）和選填內文。
  3. 點選 提交 以在 GitHub 上建立 issue。

Issue 詳情

點選 issue 卡片可查看：標題、狀態徽章、標籤、里程碑、內文、評論和狀態變更按鈕。

標籤與里程碑

  1. 將 issue 卡片 向左滑動，點選 標籤 或 里程碑。
  2. 在選擇器中選取後點選 完成。
注意：標籤和里程碑從 GitHub 取得。請先在 GitHub.com 建立它們。

評論

  1. 將 issue 卡片 向右滑動，點選 評論。
  2. 輸入評論並點選 發佈。

分享擴充功能

從任何應用程式建立或更新 GitHub Issues。點選 分享 → GitInflow Share。

Pull Request 分頁

點選 PRs 分頁以查看所選儲存庫中所有開啟的 pull request。PR 在 GitInflow 中為唯讀。

小工具

GitInflow 提供主畫面小工具（小型：In Progress issue 數量；中型：四個狀態的數量）。

通知

當所選儲存庫中出現新 issue 時，GitInflow 可傳送 本機通知。

設定

開啟 設定 分頁以管理儲存庫、設定預設值及登出。

錯誤處理

如果 GitInflow 無法載入 issue，頂部會出現 紅色錯誤橫幅。點選 重試。

常見問題

我可以選取多少個儲存庫？

一次最多 5 個。

「Done」狀態在 GitHub 上有什麼效果？

GitInflow 新增 status:done 標籤並在 GitHub 上 關閉 issue。

我可以在私人儲存庫中使用 GitInflow 嗎？

可以。GitInflow 使用您的 GitHub OAuth 令牌，可存取所有授權的儲存庫。
