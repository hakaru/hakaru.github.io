GitInflow

iOS용 GitHub Issues 칸반 클라이언트

GitInflow 사용자 매뉴얼

GitInflow는 iOS용 GitHub Issues 칸반 클라이언트입니다. 이 매뉴얼은 모든 기능을 자세히 다룹니다.

목차

  1. 시작하기
  2. 칸반 탭
  3. 상태 변경
  4. 검색
  5. 저장소 필터
  6. 이슈 생성
  7. 이슈 상세
  8. 레이블 & 마일스톤
  9. 댓글
  10. 공유 확장
  11. 풀 리퀘스트 탭
  12. 위젯
  13. 알림
  14. 설정
  15. 오류 처리
  16. 자주 묻는 질문

시작하기

로그인

  1. GitInflow를 실행합니다.
  2. 로그인 화면에서 "GitHub로 로그인"을 탭합니다.
  3. 브라우저 또는 GitHub 앱을 통해 인증합니다. GitInflow는 OAuth를 사용하며 비밀번호를 저장하지 않습니다.

저장소 선택

  1. 로그인 후 설정 탭(톱니바퀴 아이콘)으로 이동합니다.
  2. 저장소를 탭하여 선택합니다. 선택된 저장소는 체크 표시가 됩니다.
  3. 동시에 최대 5개의 저장소를 선택할 수 있습니다.

기본 저장소 설정

설정 탭에서 저장소 옆의 별표 아이콘을 탭하여 기본값으로 설정합니다.

칸반 탭

GitInflow는 이슈를 네 가지 상태 열로 정리합니다:

탭설명GitHub 레이블
Backlog상태 레이블 없는 이슈 — 새 작업 받은 편지함(레이블 없음)
Ready분류된 후 시작 준비된 이슈status:ready
In Progress활발히 진행 중인 이슈status:inProgress
Done완료된 이슈 — GitHub에서 자동 닫힘status:done

상태 변경

왼쪽으로 스와이프 — 추가 / 앞으로

  • 레이블 — 레이블 선택기 열기
  • 마일스톤 — 마일스톤 선택기 열기
  • 앞으로 — 이슈를 다음 상태로 이동 (예: Backlog → Ready → In Progress → Done)

오른쪽으로 스와이프 — 뒤로 / 댓글

  • 뒤로 — 이슈를 이전 상태로 이동
  • 댓글 — 댓글 시트 열기

컨텍스트 메뉴 (길게 누르기)

이슈 카드를 길게 눌러 모든 상태 옵션이 있는 컨텍스트 메뉴를 엽니다.

검색

각 칸반 탭 상단에 검색창이 있습니다. 탭하여 현재 탭의 이슈를 키워드로 실시간 필터링합니다.

저장소 필터

설정에서 2개 이상의 저장소를 선택하면 탭 바 아래에 필터 칩 행이 나타납니다.

이슈 생성

  1. 칸반 탭으로 이동하여 +를 탭합니다.
  2. 제목(필수)과 선택적 본문을 입력합니다.
  3. 제출을 탭하여 GitHub에 이슈를 생성합니다.

이슈 상세

이슈 카드를 탭하면 제목, 상태 배지, 레이블, 마일스톤, 본문, 댓글, 상태 변경 버튼이 표시됩니다.

레이블 & 마일스톤

  1. 이슈 카드를 왼쪽으로 스와이프합니다.
  2. 레이블 또는 마일스톤 액션을 탭합니다.
  3. 선택기에서 선택하고 완료를 탭합니다.
참고: 레이블과 마일스톤은 GitHub에서 가져옵니다. 먼저 GitHub.com에서 만드세요.

댓글

  1. 이슈 카드를 오른쪽으로 스와이프합니다.
  2. 댓글을 탭합니다.
  3. 댓글을 입력하고 게시를 탭합니다.

공유 확장

어느 앱에서나 GitHub Issues를 생성하거나 업데이트합니다. 공유 → GitInflow Share를 탭합니다.

풀 리퀘스트 탭

PRs 탭을 탭하여 선택한 저장소의 모든 열린 풀 리퀘스트를 봅니다. PR은 GitInflow에서 읽기 전용입니다.

위젯

GitInflow는 이슈 수를 한눈에 보여주는 홈 화면 위젯을 제공합니다 (소형: In Progress; 중형: 네 가지 상태 모두).

알림

선택한 저장소에 새 이슈가 나타나면 GitInflow가 로컬 알림을 보낼 수 있습니다.

설정

설정 탭을 열어 저장소를 관리하고, 기본값을 설정하고, 로그아웃합니다.

오류 처리

이슈를 로드할 수 없으면 빨간 오류 배너가 나타납니다. 다시 시도를 탭합니다.

자주 묻는 질문

저장소를 몇 개 선택할 수 있나요?

동시에 최대 5개.

"Done" 상태는 GitHub에서 어떻게 되나요?

GitInflow가 status:done 레이블을 추가하고 GitHub에서 이슈를 닫습니다.

비공개 저장소에서 GitInflow를 사용할 수 있나요?

네. GitInflow는 로그인 시 승인한 모든 저장소에 대한 액세스가 있는 GitHub OAuth 토큰을 사용합니다.
