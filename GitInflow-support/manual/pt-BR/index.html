GitInflow

Cliente Kanban de GitHub Issues para iOS

Manual do usuário GitInflow

GitInflow é um cliente kanban de GitHub Issues para iOS. Este manual cobre todos os recursos em detalhes.

Primeiros passos

Login

  1. Inicie o GitInflow.
  2. Toque em "Entrar com GitHub" na tela de login.
  3. Autentique no navegador ou pelo app do GitHub. O GitInflow usa OAuth e nunca armazena sua senha.

Selecionar repositórios

  1. Após o login, vá para a aba Configurações (ícone de engrenagem).
  2. Toque nos repositórios para selecioná-los.
  3. Você pode selecionar até 5 repositórios ao mesmo tempo.

Abas Kanban

GitInflow organiza issues em quatro colunas de status:

AbaDescriçãoEtiqueta GitHub
BacklogIssues sem etiqueta de status — caixa de entrada para novos trabalhos(sem etiqueta)
ReadyIssues triadas e prontas para começarstatus:ready
In ProgressIssues sendo trabalhadas ativamentestatus:inProgress
DoneIssues concluídas — fechadas automaticamente no GitHubstatus:done

Alterar status

Deslizar para a esquerda — Adicionar / Avançar

  • Etiqueta — Abrir seletor de etiquetas
  • Marco — Abrir seletor de marcos
  • Avançar — Mover issue para o próximo status

Deslizar para a direita — Voltar / Comentar

  • Voltar — Mover issue para o status anterior
  • Comentar — Abrir folha de comentário

Menu de contexto (pressão longa)

Pressione longamente qualquer cartão de issue para abrir um menu de contexto com todas as opções de status.

Pesquisa

Cada aba kanban tem uma barra de pesquisa no topo para filtragem em tempo real por palavra-chave.

Filtro de repositório

Com dois ou mais repositórios selecionados, uma linha de chips de filtro aparece abaixo da barra de abas.

Criar issues

  1. Navegue para qualquer aba kanban e toque em +.
  2. Insira um título (obrigatório) e um corpo opcional.
  3. Toque em Enviar para criar a issue no GitHub.

Detalhes da issue

Toque em um cartão de issue para ver: título, badge de status, etiquetas, marco, corpo, comentários e botões de alteração de status.

Etiquetas e Marcos

  1. Deslize um cartão para a esquerda e toque em Etiqueta ou Marco.
  2. Selecione no seletor e toque em Concluído.
Nota: Crie etiquetas e marcos no GitHub.com primeiro.

Comentários

  1. Deslize um cartão para a direita e toque em Comentar.
  2. Digite seu comentário e toque em Publicar.

Extensão de compartilhamento

Crie ou atualize GitHub Issues de qualquer app. Toque em Compartilhar → GitInflow Share.

Aba Pull Requests

Toque na aba PRs para ver todos os pull requests abertos. PRs são somente leitura no GitInflow.

Widget

GitInflow oferece um widget de tela inicial (pequeno: issues In Progress; médio: todos os quatro status).

Notificações

GitInflow pode enviar notificações locais quando novas issues aparecem nos repositórios selecionados.

Configurações

Abra a aba Configurações para gerenciar repositórios, definir o padrão e fazer logout.

Tratamento de erros

Se o GitInflow não conseguir carregar issues, um banner de erro vermelho aparece. Toque em Tentar novamente.

Perguntas frequentes

Quantos repositórios posso selecionar?

Até 5 ao mesmo tempo.

O que o status "Done" faz no GitHub?

GitInflow adiciona a etiqueta status:done e fecha a issue no GitHub.

Posso usar GitInflow com repositórios privados?

Sim. GitInflow usa seu token OAuth do GitHub com acesso a todos os repositórios autorizados.
