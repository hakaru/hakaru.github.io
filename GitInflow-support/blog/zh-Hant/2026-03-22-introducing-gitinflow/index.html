介紹 GitInflow：將 GitHub Issues 作為您的看板

2026年3月22日

我們很高興宣布 GitInflow，一款將 GitHub Issues 轉化為完整看板工作流程的新 iOS 應用程式。

為什麼選擇 GitInflow？

GitInflow 填補了這一空白。它直接在您的 iPhone 上提供 看板，完全由 GitHub Issues 和標籤驅動。

運作方式

  • Backlog — 無狀態標籤的 issue
  • Ready — status:ready
  • In Progress — status:inProgress
  • Done — status:done（自動關閉 issue）

快速開始

  1. 從 App Store 下載 GitInflow
  2. 使用 GitHub 帳號登入
  3. 在設定中選擇儲存庫
  4. 開始滑動！
