GitInflow

Client Kanban per GitHub Issues su iOS

Costruire GitInflow: Le decisioni tecniche dietro l'app

22 marzo 2026

GitInflow è passato dall'idea all'App Store in un solo sprint. Ecco le decisioni tecniche chiave.

Architettura: SwiftUI + MVVM + Nessun backend

L'intera app gira su due cose: SwiftUI e l'API REST di GitHub.

Kanban tramite etichette

Il sistema kanban usa etichette GitHub (status:ready, status:inProgress, status:done) invece di GitHub Projects.

Sicurezza OAuth: Scambio di token lato server

Lo scambio di token avviene tramite un Cloudflare Worker. L'app non vede mai il segreto del client.
