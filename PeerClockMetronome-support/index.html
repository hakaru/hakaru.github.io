PeerClock Metronome

P2P Synchronized Metronome for Apple Devices

Download on the App Store →

Welcome to the PeerClock Metronome support page.

PeerClock Metronome is a peer-to-peer synchronized metronome for Apple devices. Connect multiple iPhones or iPads to the same Wi-Fi network for automatic clock synchronization with ±2ms precision — no server required.

Features

Peer-to-Peer Sync (No Master/Slave)

All devices are equal peers. There is no designated "master" device — any device can join or leave without disrupting the others.

±2ms Clock Synchronization

Uses an NTP-inspired 4-timestamp algorithm with best-half filtering to achieve sub-millisecond precision across all connected devices.

Wi-Fi Only (No Server)

Sync happens entirely over your local Wi-Fi network. No data is sent to any external server. Works completely offline.

Auto-Discovery

Devices on the same Wi-Fi network discover each other automatically using Bonjour. No manual IP entry or pairing required.

Conductor Path Animation

A visual conductor path traces the beat pattern on screen, helping performers follow along at a glance.

Multiple Time Signatures

Supports 4/4, 3/4, 4/8, 3/8, 6/8, 9/8, and 12/8 time signatures.

Live BPM Changes

Tempo changes sync instantly across all connected devices — no delay, no drift.

FAQ

How do I sync multiple devices?

  1. Connect all devices to the same Wi-Fi network
  2. Open PeerClock Metronome on each device
  3. Devices discover each other automatically within a few seconds
  4. Start the metronome on any device — all synced devices will follow

What is the conductor path?

The conductor path is an animated line that traces the traditional conducting pattern for the selected time signature (e.g., a downbeat-upbeat motion for 2/4, a triangle for 3/4, a cross pattern for 4/4). It provides a visual reference so performers can stay in sync even without headphones.

How accurate is the sync?

PeerClock Metronome achieves ±2ms clock synchronization under typical Wi-Fi conditions. This is achieved by measuring round-trip times with 40 samples per sync cycle and discarding the noisiest half. For reference, human timing perception is around 10–20ms, so the sync is well within the threshold of perceptible difference.

Does it work without internet?

Yes. PeerClock Metronome uses only your local Wi-Fi network. No internet connection is required for sync.

Which devices are supported?

PeerClock Metronome requires iOS 17.0 or later. Any iPhone or iPad running iOS 17+ is supported.
