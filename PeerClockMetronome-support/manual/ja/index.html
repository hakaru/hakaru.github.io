対象バージョン・端末・使い方の範囲

PeerClock Metronomeは、規則的なクリック音と指揮の動きを表示するメトロノームです。1台で個人練習に使うほか、同じローカルWi-Fiにつないだ複数の端末でタイミングと再生操作を共有できます。

本書は、PeerClock 0.4.2を使うPeerClock Metronome 1.1.0（build 13）を対象にしています。公開版は2026年11月15日に確認しました。必要なOSはiPhoneではiOS 17以降、iPadではiPadOS 17以降です。App Storeの掲載情報にはApple Silicon MacとApple Visionの互換性もありますが、本書のタッチ操作はiPhoneとiPadを対象とし、他の環境での動作試験を意味しません。

アカウントや同期用サブスクリプションは不要です。アプリは無料で、広告を含みます。本書は公開版の画面構成と実装を確認したガイドです。端末間の音のずれ、Bluetooth性能、バックグラウンド動作を新たに測定したものではありません。

最初の練習を始める

  1. アプリを開き、端末の音量を聞きやすい大きさにします。他の端末と同期する場合は、ローカルネットワークへのアクセスを許可します。
  2. 一定テンポで練習する場合は、自動加速を開き、テンポを自動で上げるをオフにして完了を押します。
  3. 大きなBPMの数字を上へドラッグすると速く、下へドラッグすると遅くなります。その下の列から4/4を選びます。
  4. 丸い三角ボタンを押します。再生中は四角に変わります。クリック音と動く点を目安に演奏します。
  5. 四角ボタンを押すと停止します。接続中の端末がある場合は、その端末にも停止が送られます。

初めて複数台で使うときは、全員が接続して同期表示を確認してから、操作する人を1人決めて開始してください。一定テンポの再生は共有の拍グリッドに沿って始まるため、最初に聞こえる音が必ずカウントインや第1拍になるわけではありません。強い小節頭の音を確認してから演奏に入ります。

テンポを設定する

大きな数字はBPM単位のテンポです。範囲は30〜300 BPM。数字の上で縦にドラッグすると整数単位で変わり、上方向で速くなります。数字をダブルタップすると120 BPMに戻ります。数値入力欄やタップテンポ機能はありません。繰り返しタップしてもリズムは測定しません。

自動加速がオフなら、再生中でもテンポと拍子を変更でき、接続端末にも送られます。音への反映は共有時計上で約200 ms先に予約されるため、表示が先に変わる場合があります。瞬時の変更でも、次の小節まで待つ動作でもありません。

自動加速の再生中は、メイン画面のテンポと拍子を変更できません。先に停止してください。停止中に自動加速がオンの場合、大きなBPMの数字を変えると開始テンポが変わります。開始テンポが目標を超えた場合は、目標も開始テンポ以上に引き上げられます。

拍子と細分の数え方

BPMの下にある拍子のカプセルを押します。目的の拍子が見えない場合は、列を横にスワイプしてください。選択中の拍子が強調表示されます。選べるパターンは次のとおりです。

複合拍子では、主拍の中に3つのクリックが自動で入ります。6/8で60 BPMの場合、主拍は1秒で、その中に等間隔のクリックが3つ入り、1小節は2秒になります。BPMを各8分音符のクリック速度と読み替えないでください。

同じまとまりが指揮アニメーションと自動加速の小節数に使われます。細分とアクセントは拍子ごとに固定です。独立した細分選択、スウィング調整、独自拍子の編集はありません。

クリック音・アクセント・音量

小節の最初は、最も強く高いクリックです。他の主拍には中程度の音、複合拍子の細分には弱く低い音を使います。アクセントをプログラムしなくても、小節の区切りと拍のまとまりを聞き分けられます。

公開版の音色は、合成した固定のクリック音セットです。音色選択、拍ごとのミュート、アクセント編集、アプリ内の独立した音量スライダーはありません。音量とヘッドホン・スピーカーの選択は端末側で行ってください。音は各端末で生成するため、出力先と音量は端末ごとの設定です。

アプリの音声設定は他の音とのミックスを許可しています。相手アプリとシステムの音声状態によっては、伴奏とメトロノームを一緒に再生できます。ただし伴奏のテンポが同期するわけではありません。このアプリは楽器を録音せず、マイクでテンポを検出する機能もありません。

指揮表示を見る

画面中央には、指揮の軌跡、主拍の番号、移動する光が表示されます。主拍は拍子に応じて2・3・4拍になり、6/8は2、9/8は3、12/8は4です。小節頭では強く光り、他のクリックは弱い光で区別します。

拍の位置を見失わないための目安や、音を出さずに目で追う用途に使えます。表示はアニメーションであり、触って指揮する操作面ではありません。軌跡をドラッグしても、合奏を指揮したり拍を作ったりすることはできません。疑問符ボタンで内蔵ヘルプを開き、完了ボタンで戻れます。

画面更新と音の予約処理は別々です。表示はスピーカーから音が出る瞬間の精密な測定値ではなく、2台の点の動きを見比べるだけでは音の一致を確認できません。利用できる画面の形が変わっても、軌跡の縦横比は保たれます。

自動加速で練習する

自動加速は、指定した小節数を演奏するごとにテンポを上げ、目標に達した後はその速さを保ちます。再生を停止し、自動加速を開いてテンポを自動で上げるをオンにします。各項目の増減ボタンで次を設定します。

  • 開始テンポ：30〜300 BPM。
  • 目標テンポ：開始テンポ以上、300 BPM以下。
  • 上げ幅：1段階につき1〜270 BPM。
  • 上げる間隔（小節）：1〜64小節。

完了で保存し、キャンセルで設定画面の変更を破棄します。初期設定は80 → 120 BPM、4小節ごとに+2 BPMです。例えば80で4小節、82で4小節と進みます。最後の上げ幅は目標で止まるように調整され、再生自体は続きます。開始と目標を同じ値にすると一定テンポになります。

再生ボタンを押すたびに、開始テンポから新しく始まります。停止して再生し直す操作は最初からのやり直しで、小節数を一時停止して再開する操作ではありません。接続端末がある場合は、共有タイムラインを受け取るために少なくとも0.5秒の準備時間を置いて開始します。参加する全端末で、自動加速に対応するバージョンを使ってください。全員が停止中に設定し、1台から開始します。

保存される設定

自動加速の開始、目標、上げ幅、小節間隔、オン・オフは、完了を押すと端末に保存され、アプリを開き直したときに復元されます。オンの場合は開始BPMもメイン画面に戻ります。他の端末から受け取った自動加速設定も保存されるため、合奏後に次回の練習設定が変わっていることがあります。

通常のBPMと拍子は、練習プリセットとして個別に保存されません。新たに起動したときは通常120 BPM・4/4になり、自動加速がオンなら保存された開始BPMが使われます。再生そのものが自動で再開することはありません。

保存できる自動加速設定は1組です。名前付きプリセット集、セットリスト、曲順、書き出し、クラウドバックアップの画面はありません。同じ練習を再現したい場合は、拍子と練習内容を別途メモしてください。停止中の1台で自動加速を保存するだけでは、他の端末の再生は始まりません。

複数の端末を接続する

  1. すべての端末に対応版を入れ、同じローカルWi-Fiにつなぎます。
  2. 各端末でPeerClock Metronomeを開き、ローカルネットワークを許可します。準備中は全員が停止しておきます。
  3. 端末数とSynced表示を待ちます。数字は見つかった他の端末の数で、名前付きの参加者一覧ではありません。
  4. 操作する端末でテンポ、拍子、自動加速を決め、再生を押します。
  5. 全端末が意図したパターンを再生していることを確認してから練習します。

Bonjourを使って自動で検出します。Host、Join、参加コード、IP入力欄、部屋選択はありません。時計の基準となる端末は内部で自動選出されるため、演奏者がマスターを指定する必要はありません。

再生開始後に加わった端末には、その時点の再生状態と設定がすぐ届くとは限りません。確実に参加させるには、一度全員を停止し、同期を待って、使う設定を確認し、操作担当の端末から再開してください。再接続したときも全体の確認が必要です。

共有操作を理解する

共有される操作と端末ごとの設定
項目動作
再生・停止接続端末へ送られます。どの端末からも操作でき、指揮者専用の操作ロックはありません。
通常のBPM・拍子変更時に送られます。自動加速がオフなら、停止中の端末からの変更も含みます。
自動加速オンにした下書き設定は、再生時に共通の開始タイムラインとともに共有されます。
音量・出力先端末ごとに設定します。他の端末の音量や出力先を操作する機能はありません。
保存設定・広告・権限各端末で扱います。共通のユーザーアカウントとして共有されるものではありません。

1.1.0の自動加速には重要な制約があります。停止中の端末で自動加速をオフにすると、通常テンポの設定が送られ、別の端末で進行中の自動加速を中断する場合があります。グループの自動加速を変更するときは、全員を先に停止してください。他の人が練習を続けている間に、待機中の端末を編集しないでください。

同時に編集すると、互いの設定が置き換わることがあります。操作担当を1人決め、変更後はテンポと拍子の表示を見比べてください。Syncedは時計の状態を示すもので、すべての再生コマンドの到達確認ではありません。

同期表示の意味

  • Standalone：現在カウントされている接続端末がありません。単体での練習はできます。
  • Searching…：端末は見つかっていますが、現在は時計が同期済みの表示になっていません。
  • Synced：時計ライブラリが同期済みの状態を返しています。

横の±x.xmsの数字には注意が必要です。この版では、報告されたネットワーク往復遅延の半分を表示しています。実際に聞こえるクリック同士の差、補正後の時計のずれを測った値、誤差の保証範囲ではありません。

自動選出された基準端末は、基準として往復遅延がゼロと扱われるため±0.0msを表示することがあります。すべてのスピーカーが完全に一致している証拠にはなりません。表示と端末数で接続状態を確認した後、実際の出力を聞いてください。参加・退出・再接続時の移行中は、状態が落ち着くまで待って全員を再開する必要が生じる場合があります。

同期の仕組みと出力遅延

PeerClockは、4つのタイムスタンプを繰り返し交換して時計の差を推定します。標準では1回の同期処理で40回の測定を要求し、遅延の小さい半分を残して時刻差を平均します。同期は繰り返され、間隔は5〜30秒の範囲で変わります。各アプリは共通の時刻を基準に、その端末で作るクリックを予約します。1台の音声を他の端末へストリーミングする仕組みではありません。

宣伝にある±2 msは、適切なネットワーク条件で目指す時計同期の性能です。聞こえる音が無条件でその範囲に収まる保証ではありません。回線の混雑、送受信遅延の非対称性、端末の負荷、音声機器が結果に影響します。本書の作成にあたり、音の出口まで含めた新たなタイミング測定は行っていません。

OSが報告する出力遅延を使い、クリックを早めに予約する自動補正があります。手動の遅延スライダーや校正手順はありません。Bluetoothではバッファによる遅延が変わることがあり、出力先の変更中は一時的に音が途切れる場合もあります。練習前に各出力を聞き比べ、Bluetoothが遅く感じられたら内蔵スピーカーや有線ヘッドホンで確認してください。スピーカーとの距離も、耳に音が届く時刻に影響します。

ネットワークと権限を確認する

同期に必要なのは端末間のローカル通信で、インターネット接続ではありません。ゲストWi-Fi、端末間通信を隔離した学校や会場のネットワーク、別のサブネット、通信を制限するVPNでは、似たWi-Fi名でも互いを検出・接続できない場合があります。管理者にローカル検出と端末間通信を確認するか、共同利用に適したローカルネットワークを使ってください。

アクセスを拒否した場合は、設定 → プライバシーとセキュリティ → ローカルネットワークでPeerClock Metronomeをオンにし、アプリを開き直します。詳しくはAppleのローカルネットワーク権限の説明を参照してください。

公開版には、複数のグループを分ける部屋コード、参加承認リスト、パスワードはありません。信頼できる練習用ネットワークを使い、端末数を確認してください。インターネット越しの離れた場所はこの使い方の対象外です。ライブラリに他の通信方式があっても、このアプリでBluetoothだけ、携帯回線、遠隔セッションを使えることにはなりません。

バックグラウンドと割り込み

アプリはバックグラウンド音声に対応する設定で、再生用の音声セッションを使います。画面ロックや別アプリへの切り替え後も再生を続けられますが、OSの音声処理とアプリの状態に左右されます。あらゆるバックグラウンド条件で、端末検出・再接続・同期が途切れないことを保証するものではありません。

OSが再開を許可した割り込みの終了、出力構成の変更、音声サービスのリセット後には、エンジンの復旧を試みます。自動加速中の割り込みでは共有タイムラインが進み続けるため、復帰後は最後に聞いた位置より先のテンポになっている場合があります。

合奏の準備では、全員が同期するまでアプリを前面に出しておいてください。通話、出力先の変更、長いバックグラウンド移行の後は、テンポ表示と音を再確認します。無音や拍のずれが残る場合は、全員を停止して再開してください。共通の練習タイムラインを止める一時停止ボタンはありません。

広告・権限・プライバシー

確認した公開版は広告付きの無料アプリです。購入画面、サブスクリプション、購入を復元する操作、有料の広告解除はありません。広告が準備できていれば、その端末で開始した停止操作3回ごとに全画面広告が表示される場合があります。他端末から受け取った停止は回数に加算されません。表示の有無は配信状況によります。

データを扱う主体と目的

開発者のHakaru Hiroseは、広告配信、利用状況の分析、安定性の診断にGoogleのサービスを利用しています。Google AdMobは、広告の配信と効果測定のため、端末識別子、広告への反応、IPアドレス、診断情報を扱う場合があります。Firebase Analyticsは利用イベントやアプリ・端末の情報を扱い、アプリはトラッキング許可の状態、広告と同意処理のエラーも記録します。Firebase Crashlyticsは不具合調査のため、クラッシュ報告と関連するインストール・端末情報を扱います。これらは外部サーバーに接続することがあります。時計同期がローカルで動くことは、アプリ全体がインターネットを使わないことを意味しません。

権限と選択肢

ローカルネットワーク権限は近くの端末を検出して通信するためのものです。App Tracking Transparency（ATT）の要求は、トラッキングと広告識別子（IDFA）へのアクセスに関するものです。拒否してもメトロノームを使えます。設定 → プライバシーとセキュリティ → トラッキングで変更できますが、拒否はすべての広告や診断処理を無効にするスイッチではありません。詳しくはAppleのトラッキング設定の説明を参照してください。

アプリはGoogle User Messaging Platform（UMP）で同意情報を要求し、必要な場合に同意フォームを表示するよう依頼します。表示される選択肢は、サービスの地域・アカウント設定に依存します。フォームが出た場合は、その選択肢に回答してください。1.1.0には、フォームを再表示する独立したプライバシー設定画面や、分析・クラッシュ報告を切り替えるスイッチはありません。操作できない選択肢についてはサポートへお問い合わせください。UMPの資料はサービスの仕組みを説明していますが、推奨される設定のすべてをこのアプリから操作できるわけではありません。

位置情報・音声・保存設定

アプリはGPS・位置情報の権限を要求せず、マイク音声も録音しません。ただし、広告サービスがIPアドレスからおおまかな地域を推定する場合はあります。自動加速設定は端末に保存し、同期ではローカル端末間で時計と操作情報を交換します。録音を交換する仕組みではありません。メールで問い合わせる場合、内容とメールアドレスは対応する受信者に伝わります。

Google Mobile Adsのデータ開示、Firebaseのプライバシー情報、App Storeの開示も参照してください。本書では、このアプリ固有の保存期間を定めたり、アンインストールによるデータ削除を約束したりしていません。プライバシー、保存期間、削除に関する問い合わせ先はhirose@hakaru.netです。
