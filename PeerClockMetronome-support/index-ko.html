PeerClock Metronome

Apple 기기용 P2P 동기화 메트로놈

App Store에서 다운로드 →

PeerClock Metronome 지원 페이지에 오신 것을 환영합니다.

PeerClock Metronome은 Apple 기기를 위한 피어투피어 동기화 메트로놈입니다. 여러 iPhone 또는 iPad를 동일한 Wi-Fi 네트워크에 연결하면 서버 없이 ±2ms 정밀도의 자동 클록 동기화가 이루어집니다.

기능

피어투피어 동기화 (마스터/슬레이브 없음)

모든 기기는 동등한 피어입니다. 지정된 "마스터" 기기가 없으며, 어느 기기든 다른 기기에 영향을 주지 않고 자유롭게 참여하거나 나갈 수 있습니다.

±2ms 클록 동기화

NTP 기반의 4-타임스탬프 알고리즘과 최적 절반 필터링을 사용하여 연결된 모든 기기에서 서브밀리초 정밀도를 달성합니다.

Wi-Fi 전용 (서버 불필요)

동기화는 로컬 Wi-Fi 네트워크에서만 이루어집니다. 외부 서버로 데이터가 전송되지 않으며, 완전히 오프라인으로 작동합니다.

자동 기기 검색

동일한 Wi-Fi 네트워크의 기기는 Bonjour를 통해 자동으로 검색됩니다. IP 수동 입력이나 페어링이 필요 없습니다.

지휘자 경로 애니메이션

화면에 박자 패턴을 시각적으로 추적하는 지휘자 경로 애니메이션으로 연주자가 한눈에 박자를 따라갈 수 있습니다.

다양한 박자 지원

4/4, 3/4, 4/8, 3/8, 6/8, 9/8, 12/8 박자를 지원합니다.

실시간 BPM 변경

템포 변경은 연결된 모든 기기에 즉시 동기화됩니다. 지연이나 드리프트가 없습니다.

자주 묻는 질문

여러 기기를 동기화하는 방법은?

  1. 모든 기기를 동일한 Wi-Fi 네트워크에 연결합니다
  2. 각 기기에서 PeerClock Metronome을 엽니다
  3. 몇 초 내에 기기가 자동으로 검색됩니다
  4. 아무 기기에서나 메트로놈을 시작하면 동기화된 모든 기기가 따라갑니다

지휘자 경로란 무엇인가요?

지휘자 경로는 선택한 박자의 전통적인 지휘 패턴을 애니메이션으로 표시하는 기능입니다. 헤드폰 없이도 연주자가 동기화를 유지할 수 있도록 시각적 참조를 제공합니다.

동기화 정밀도는 어느 정도인가요?

PeerClock Metronome은 일반적인 Wi-Fi 환경에서 ±2ms의 클록 동기화를 달성합니다. 인간의 타이밍 지각은 약 10–20ms이므로, 이 동기화 정밀도는 지각 가능한 차이의 임계값보다 훨씬 낮습니다.

인터넷 없이도 작동하나요?

네. PeerClock Metronome은 로컬 Wi-Fi 네트워크만 사용합니다. 동기화에 인터넷 연결이 필요하지 않습니다.

지원 기기는 무엇인가요?

PeerClock Metronome은 iOS 17.0 이상이 필요합니다. iOS 17 이상을 실행하는 모든 iPhone 또는 iPad를 지원합니다.
