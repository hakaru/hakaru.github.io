PeerClock Metronome

Apple 기기용 P2P 동기화 메트로놈

개인정보 처리방침

최종 업데이트: 2026년 4월 22일

소개

PeerClock Metronome은 귀하의 개인정보 보호에 최선을 다하고 있습니다. 이 개인정보 처리방침은 iOS 앱을 사용할 때 정보를 어떻게 처리하는지 설명합니다.

요약

PeerClock Metronome은 앱 안정성 개선을 위해 익명 진단 데이터를 수집합니다. 로컬 네트워크는 기기 간 P2P 동기화에만 사용되며, 동기화 데이터는 외부 서버로 전송되지 않습니다.

로컬 네트워크 사용

  • 동기화 패킷은 동일한 로컬 네트워크의 기기 사이에서만 전송됩니다
  • 동기화 데이터는 외부 서버로 전송되지 않습니다
  • 동기화에 인터넷 연결이 필요하지 않습니다

수집하는 데이터

Firebase Analytics(익명 사용 통계)와 Firebase Crashlytics(충돌 보고서)를 사용합니다.

데이터 수집 요약

데이터 유형목적개인 연결
충돌 데이터앱 기능없음
사용 데이터분석없음
기기 ID분석없음

수집하지 않는 데이터

  • 개인정보 (이름, 이메일, 위치, 연락처, 사진)
  • 광고 식별자 (IDFA)
  • 제3자에게 판매되는 데이터

추적 및 광고

광고 목적으로 추적하지 않습니다. IDFA를 사용하지 않으며 광고주와 데이터를 공유하지 않습니다.

제3자 서비스

  • Firebase Analytics — 익명 사용 분석 (Google)
  • Firebase Crashlytics — 충돌 보고서 (Google)

Firebase 개인정보 처리방침

아동 개인정보

13세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다.

방침 변경

이 개인정보 처리방침은 수시로 업데이트될 수 있습니다. 변경 사항은 이 페이지에 게시됩니다.
