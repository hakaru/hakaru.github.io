M2DX Changelog

Published versions · Changes that affect playing and editing

Updated November 15, 2026 · Latest public version: 1.7.14

English日本語DeutschEspañolFrançaisItaliano한국어NederlandsPortuguês (Brasil)Svenska繁體中文

This page summarizes user-facing changes in published versions. Dates follow the Japanese App Store history and can differ from the date a build or source tag was prepared. Development and TestFlight-only versions, including 1.6.1 and 1.6.2, are not listed as public releases.

Release notes describe the change at that time. For current behavior and limitations, use the manual. In particular, the standalone Mark I Depth default became ÷1 in 1.7.12, but the current AU initialization and parameter default differ. Reception of a MIDI message does not establish audible support for it.

1.7.14

2026-10-08 · build 40

  • The AUv3 editor grows with a larger host window. Text, buttons and the keyboard scale together; smaller windows retain their previous layout.

1.7.13

2026-10-07 · build 39

  • CUSTOM voices now save and recall wheel, foot, breath and aftertouch routing plus EG MODE in both standalone and AUv3. Resave older CUSTOM voices to store these settings.

1.7.12

2026-10-05 · build 38

  • The standalone Mark I Depth default changed from ÷5 to ÷1. Previously chosen values remain. Added more apps to More from hakaru. See the manual for the current AU initial-value caveat.

1.7.11

2026-10-04 · build 37

  • Added EDIT → CONTROLLERS → EG MODE. DX7 retains the 1.7.10 bias behavior; BOOST restores the earlier behavior that raises all operators, including modulators.

1.7.10

2026-10-03 · build 36

  • Changed controller EG Bias to attenuate AMS-enabled operators at rest and open them toward their programmed level as the controller rises. Patches using EG Bias can sound different; zero EG range is unaffected.

1.7.9

2026-10-02 · build 35

  • Added stable CUSTOM Program Change addresses in Bank MSB 16 and shared CUSTOM/imported sound selection for AU hosts. Improved shared-library refresh and AU project restoration, including embedded voices, layers, tuning and edits.
  • Enabled AUv3 Program Change and Bank Select. Mark I Depth became free and expanded to ÷1–÷16; its default was still ÷5 in this version.
  • Fixed Logic Pro state restoration, full-scale MIDI 2.0 control conversion, live operator-level handling and Pro compressor switching artifacts.

1.7.8

2026-10-02 · build 34

  • Standalone remembers Mono/Poly per factory/imported sound. Added confirmed deletion of CUSTOM voices from LIVE. Cancelling Restore Purchases no longer produces an error alert.

1.7.7

2026-09-28 · build 33

  • Fixed a crash when opening an Apple Audio Unit effect’s controls while running the iPhone app on an Apple Silicon Mac. The effect keeps processing even when its custom interface is unavailable.

1.7.6

2026-09-18 · build 32

  • Fixed an EDIT-screen crash when running the iPhone app on an Apple Silicon Mac. EDIT uses −/+ controls on Mac; iPhone keeps its existing stepper controls.

1.7.5

2026-09-17 · build 31

  • Operator Level edits now follow the displayed DX7 0–99 value without changing the other operators, and affect sounding notes without retriggering. AUv3 now routes CC112–117 to OP1–OP6 levels.

1.7.4

2026-09-12 · build 30

  • Added Mono performance, legato, Fingered/Full-time portamento and semitone glissando. CUSTOM voices save Mono/Poly.
  • Added standalone Pro P73 preamp, TwinFET 1176 compressor and six-machine DigitalReverb. Standalone controller routing persists across voice changes and launches.
  • Improved MIDI Learn, sustain, TX816 layer preservation, AU state restoration and purchase/restore feedback.

1.7.3

2026-07-13

  • Improved MIDI input filtering and running-status handling, external AU effect loading, Pro purchase state, audio startup retries and preset persistence. Reduced overhead during heavy MIDI/automation activity.

1.7.2

2026-07-11

  • Added standalone Pro hosting of up to four external AU effects after the internal chain, with chain/state restoration. Corrected Analytics and Crashlytics activation on launch.

1.7.1

2026-07-04

  • Introduced the vintage FM-panel app icon, including dark and tinted variants for iOS 18.

1.7.0

2026-07-03

  • Introduced the optional one-time M2DX Pro purchase: TX816 layering, engine options, Vintage DAC and Voice Stack. Added purchase restoration and a dedicated FX screen; existing free features remained free.
  • Improved AU editing/host automation and shared banks. Maximizer became off by default. Engine access and Depth range changed again in later versions; consult the current manual.

1.5.5

2026-06-24

  • Fixed unwanted tone changes when navigating operator pages or recalling AUv3 presets. Improved common-ratio snapping, screen-keyboard note release and stability.

1.5.4

2026-06-23

  • Improved AUv3 preset recall, multi-touch keyboard polyphony and plug-in naming. Aligned the app and extension deployment requirements.

1.5.3

2026-06-22

  • Fixed AUv3 initialization and added seven-language in-app help, including guidance for finding and importing DX7 banks.

1.5.2

2026-06-18

  • Improved AU host automation, Maximizer bypass transitions, MIDI parsing, tuning display and safe SysEx-bank import/deletion. Receiving pressure messages did not establish the current engine’s audible poly-pressure support.

1.5.1

2026-06-16

  • Refreshed App Store screenshots and release packaging; no new performance feature was recorded.

1.5.0

2026-06-16 · build 9

  • Initial App Store release for iPhone on iOS 18 or later. Included six-operator FM, screen-keyboard performance, editing/custom saves, AUv3 and import of user-supplied 4104-byte DX7 32-voice banks.

Sources: App Store version history, the developer’s release records and the shipped-source review. App Store version history
