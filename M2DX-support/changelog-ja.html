M2DX 更新履歴

公開版の履歴・演奏と編集に関わる変更

更新日：2026年11月15日 · 最新公開版：1.7.14

English日本語DeutschEspañolFrançaisItaliano한국어NederlandsPortuguês (Brasil)Svenska繁體中文

公開版の利用者向け変更をまとめています。日付は日本のApp Store履歴に従い、ビルドやソースタグの作成日とは異なる場合があります。1.6.1／1.6.2など、開発・TestFlightのみの版を公開リリースとしては掲載していません。

各項目はその時点の変更です。現在の動作や制限はマニュアルをご覧ください。特にMark I Depthは1.7.12で単体版の既定が÷1になりましたが、現行AUでは内部初期値とパラメーター既定値に差があります。また、MIDIメッセージを受信することと音へ反映することは同じではありません。

1.7.14

2026-10-08 · build 40

  • AUv3画面が大きなホストウィンドウに合わせて拡大。文字・ボタン・鍵盤も大きくなり、小さいウィンドウは従来の表示を維持します。

1.7.13

2026-10-07 · build 39

  • 単体／AUv3のCUSTOM音色へ、ホイール・フット・ブレス・アフタータッチの割当とEG MODEを保存・復元。以前のCUSTOMで保持するには、もう一度保存します。

1.7.12

2026-10-05 · build 38

  • 単体版Mark I Depthの既定を÷5から÷1へ変更。利用者が選んだ値は保持します。More from hakaruのアプリを追加。現行AUの初期値の注意点はマニュアルを参照してください。

1.7.11

2026-10-04 · build 37

  • EDIT → CONTROLLERSへEG MODEを追加。DX7は1.7.10のBias動作、BOOSTはモジュレーターを含む全OPを持ち上げる以前の動作を選びます。

1.7.10

2026-10-03 · build 36

  • コントローラーEG Biasを、AMS設定OPを休止中に抑え、操作量とともに本来のレベルまで開く動作へ変更。EG Bias音色の鳴り方が変わる場合がありますが、EG範囲0は影響しません。

1.7.9

2026-10-02 · build 35

  • CUSTOMにBank MSB 16の固定Program Change番号を追加。AUホストから共有CUSTOM／取込音色を選べるようにし、ライブラリー再読込と音色・レイヤー・調律・編集を含むプロジェクト復元を改善。
  • AUv3のProgram Change／Bank Selectを有効化。Mark I Depthを無料にし÷1–÷16へ拡張。この版の既定はまだ÷5でした。
  • Logic Proの状態復元、MIDI 2.0最大値の変換、発音中のOPレベル変更、Proコンプレッサー切替時のノイズを修正。

1.7.8

2026-10-02 · build 34

  • 単体版で工場／取込音色ごとのMono/Polyを記憶。LIVEに名前確認付きCUSTOM削除を追加。購入復元のキャンセル時にエラーを出さないよう修正。

1.7.7

2026-09-28 · build 33

  • Apple Silicon MacでiPhone版を動かし、Apple製AUエフェクトの操作画面を開いた際の終了を修正。専用UIを表示できない場合も音声処理は続きます。

1.7.6

2026-09-18 · build 32

  • Apple Silicon Mac上のiPhone版でEDITを開くと終了する問題を修正。Macでは−/+操作を使い、iPhoneは従来のステッパーを維持します。

1.7.5

2026-09-17 · build 31

  • OP Levelを表示どおりのDX7 0–99で反映し、ほかのOPを変えず、発音中の音にも再トリガーなしで適用。AUv3でCC112–117をOP1–OP6レベルへ接続。

1.7.4

2026-09-12 · build 30

  • Mono演奏、レガート、Fingered/Full-timeポルタメント、半音グリッサンドを追加。CUSTOMへMono/Polyを保存。
  • 単体ProへP73、TwinFET 1176、6機種DigitalReverbを追加。単体のコントローラー割当を音色変更・再起動後も保持。
  • MIDI Learn、サステイン、TX816レイヤー保持、AU状態復元、購入・復元の案内を改善。

1.7.3

2026-07-13

  • MIDI入力選択とRunning Status処理、外部AU読込、Pro購入状態、音声起動の再試行、プリセット保存を改善。MIDI／自動化が多い場面の負荷を削減。

1.7.2

2026-07-11

  • 単体Proへ内蔵FX後段の最大4外部AUエフェクトとチェーン／状態復元を追加。起動時のAnalytics／Crashlytics有効化を修正。

1.7.1

2026-07-04

  • ヴィンテージFMパネル風の新アイコンを導入。iOS 18のダーク／色合い付き表示にも対応。

1.7.0

2026-07-03

  • 買い切りM2DX Proを導入し、TX816レイヤー、エンジン設定、Vintage DAC、Voice Stackを追加。購入復元と独立FX画面を追加し、従来の無料機能は無料のまま維持。
  • AU編集・ホスト自動化・共有バンクを改善し、Maximizerを既定OFFへ変更。エンジンの利用条件とDepth範囲は後の版でも変わっているため、現行マニュアルを参照してください。

1.5.5

2026-06-24

  • OP画面の移動やAUv3音色呼出しだけで音が変わる問題を修正。Ratioの定番比への吸着、画面鍵盤の離鍵、安定性を改善。

1.5.4

2026-06-23

  • AUv3の音色呼出し、画面鍵盤のマルチタッチ発音、プラグイン名を改善。アプリ本体と拡張の動作要件を統一。

1.5.3

2026-06-22

  • AUv3の初期化を修正。DX7バンクの入手・取込案内を含む7言語のアプリ内ヘルプを追加。

1.5.2

2026-06-18

  • AUホスト自動化、Maximizerバイパス時の切替、MIDI解析、調律表示、SysEx取込／削除を改善。Pressure受信の追加を、現行音源での可聴Poly Pressure対応と同一視しないでください。

1.5.1

2026-06-16

  • App Storeスクリーンショットとリリース用構成を更新。新しい演奏機能の記録はありません。

1.5.0

2026-06-16 · build 9

  • iOS 18以降のiPhone向けにApp Store初公開。6OP FM、画面鍵盤、編集／CUSTOM保存、AUv3、利用者の4104バイトDX7 32音色バンク取込を提供。
