Aan de slag

Vereisten

  • iPhone of iPad met iOS 17.0 of later
  • USB-audio-interface (klasseconform)
  • Lightning naar USB- of USB-C-adapter (indien nodig)
  • Audiokabels voor uw apparatuur

Eerste start

  1. Installeer SonicDNA Collector uit de App Store
  2. Verleen microfoontoestemming wanneer gevraagd
  3. Sluit uw audio-interface aan
  4. De app detecteert de interface automatisch

Apparatuurinstelling

Signaalstroom: iPhone uitgang → Interface uitgang → Apparatuur onder test → Interface ingang → iPhone ingang

Verbindingsstappen

  1. Sluit de audio-interface aan op iPhone/iPad
  2. Verbind interface uitgang met apparatuur ingang
  3. Verbind apparatuur uitgang met interface ingang
  4. Start SonicDNA Collector

Gain-kalibratie

  1. Verlaag eerst het monitorvolume
  2. Tik op de 0dBFS-knop
  3. Bevestig het waarschuwingsdialoogvenster
  4. Stel interfacegain in zodat INGANG -18 dB tot -12 dB toont
  5. Tik nogmaals op 0dBFS om te stoppen

Opname

5-stappen modus (Aanbevolen): -30 dB, -24 dB, -18 dB, -12 dB, -6 dB. Totale tijd: ~35 seconden.

11-stappen modus (Uitgebreid): -100 dB tot 0 dB in stappen van 10 dB. ~77 seconden.

Opnameproces

  1. Voer de naam van de apparatuur in
  2. Selecteer het aantal stappen
  3. Tik op de rode opnameknop
  4. Wacht op voltooiing
  5. Vind de opname in de bibliotheek

Analyse

Opnames → Selecteer een sessie → Analyse

  • Frequentierespons - Amplitude vs frequentiediagram
  • THD - Totale harmonische vervorming op elk niveau
  • Harmonischen - Individuele harmonische niveaus

Probleemoplossing

Geen audio-interface gedetecteerd

  1. Controleer de fysieke verbinding
  2. Probeer een andere USB-poort/adapter
  3. Herstart de app
  4. Controleer iOS-instellingen → Privacy → Microfoon
