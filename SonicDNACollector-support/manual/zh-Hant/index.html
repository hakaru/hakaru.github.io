入門

系統需求

  • 搭載 iOS 17.0 或更高版本的 iPhone 或 iPad
  • USB 音訊介面（符合類別標準）
  • Lightning 轉 USB 或 USB-C 轉接器（如需要）
  • 設備用音訊線纜

首次啟動

  1. 從 App Store 安裝 SonicDNA Collector
  2. 在提示時授予麥克風權限
  3. 連接您的音訊介面
  4. 應用程式將自動偵測介面

介面概述

控制項

控制項功能
5 步 / 11 步選擇增益階梯模式
錄音按鈕開始/停止錄音
0dBFS播放/停止 1kHz 測試音
[?]說明畫面
[📁]錄音資料庫

設備設定

訊號流程：iPhone 輸出 → 音訊介面輸出 → 被測設備 → 音訊介面輸入 → iPhone 輸入

連接步驟

  1. 將音訊介面連接至 iPhone/iPad
  2. 將介面輸出連接至設備輸入
  3. 將設備輸出連接至介面輸入
  4. 啟動 SonicDNA Collector

增益校準

  1. 先降低監聽音量
  2. 點擊 0dBFS 按鈕
  3. 確認警告對話框
  4. 調整介面增益，直至輸入顯示 -18dB 至 -12dB
  5. 再次點擊 0dBFS 以停止

錄音

5 步模式（推薦）：-30dB、-24dB、-18dB、-12dB、-6dB。總時間：約 35 秒。

11 步模式（完整）：-100dB 至 0dB，每步 10dB。約 77 秒。

錄音流程

  1. 輸入設備名稱
  2. 選擇步數
  3. 點擊紅色錄音按鈕
  4. 等待完成
  5. 在資料庫中找到錄音

分析

錄音 → 選擇工作階段 → 分析

  • 頻率響應 - 振幅與頻率的關係圖
  • THD - 每個電平的總諧波失真
  • 諧波 - 個別諧波電平

疑難排解

未偵測到音訊介面

  1. 檢查實體連接
  2. 嘗試不同的 USB 連接埠/轉接器
  3. 重新啟動應用程式
  4. 檢查 iOS 設定 → 隱私權 → 麥克風
