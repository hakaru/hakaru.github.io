Changelog

All notable changes to SonicDNA Collector will be documented in this file.

The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

[1.0.0] - 2026-01-25

Initial Release

First public release of SonicDNA Collector.

Added

Core Features

  • Logarithmic sweep generation (20Hz - 20kHz)
  • Gain staircase recording (5 or 11 steps)
  • Real-time VU meters for input/output
  • FFT spectrum analyzer
  • Clipping detection with visual indicators

Audio Engine

  • 96kHz sample rate support
  • USB audio interface support
  • Low-latency monitoring
  • Pre-roll buffer

User Interface

  • Dark mode design
  • Debug console with real-time logs
  • Optimized for iPhone
  • 0dBFS test tone generator

Recording Management

  • Organized session folders
  • JSON metadata export
  • WAV file output
  • Share via Files app

Analysis

  • Built-in frequency response viewer
  • THD measurement display
  • Harmonic analysis charts

[Unreleased]

Planned

  • iPad optimization
  • iCloud sync for recordings
  • More staircase presets
  • Real-time THD display during test tone
  • Audio unit plugin support
  • Export to REW format
